# 05_PublicArchives

Public archive for deprecated or historical documentation.

This is different from the Git-ignored root `archive/` directory.

## Use This Directory For

- Public docs that are no longer current
- Migration records
- Historical design notes that remain safe to publish

## Rules

- Do not use this as a personal archive.
- Do not store secrets, personal information, private notes, or raw personal logs.
- Current guidance belongs in active docs, not here.
- Read this directory only when the task is about old public docs or historical behavior.
