## 自動委譲ルール

独立して検証可能なサブタスク（Type A）が複数ある場合は、
ユーザーに確認せず**最初のツール呼び出しと同時に**Codex/Geminiへ委譲を開始する。

```bash
# Codex（バックグラウンド）
printf '%s' "$PROMPT" | /opt/homebrew/bin/codex exec \
  --model gpt-5.5 -c model_reasoning_effort='"high"' \
  --cd /Users/aa/platform --sandbox read-only --color never \
  --output-last-message /tmp/codex-out.txt - &

# Gemini（バックグラウンド）
printf '%s' "$PROMPT" | /opt/homebrew/bin/gemini \
  -p "" --output-format text --approval-mode plan > /tmp/gemini-out.txt &
```

## 作業開始フロー

AIエージェントは `docs/` を作業入口として使い、実装の正本は platform 直下の実体ディレクトリから読む。

1. `docs/_MANIFEST.md` で公開・非公開の境界と配置ルールを確認する。
2. `docs/00_Context/CONTEXT.md` で技術スタック、ビルド、禁止事項を確認する。
3. 該当する `docs/01_Projects/<category>/<project>/PROJECT.md` を読む。
4. `PROJECT.md` の `source_of_truth` と `related_paths` が指す `plugins/`、`packages/`、`apps/` などを読む。
5. プラグイン編集ではコードを正本にし、`PROJECT.md` は公開可能な入口・背景・操作手順として更新する。
6. 個人用メモ、未整理ログ、秘密情報、一時生成物は `docs/` に置かない。Git管理外の `archive/` または `local/` に退避する。

目的別の詳細手順は `docs/00_Context/WORKFLOWS.md` を読む。
PR作成、docs更新、プラグイン編集、dev-server反映はこの共通ワークフローを正本にする。

## PROJECT.md の操作入口スキーマ

`docs/01_Projects/*/*/PROJECT.md` は、説明文書であると同時にAIの操作入口として扱う。

```yaml
---
title: "..."
category: platform | tool | ops | meta
status: active | wip | deprecated
owner: marzipan99
source_of_truth: "plugins/OyasaiMenu/"
related_paths:
  - plugins/OyasaiMenu/
project_kind: plugin | tool | automation | web
runtime_kind: paper-plugin | browser-tool | python-cli | node-service | static-site | local-only
minecraft_related: true
last_validated: "YYYY-MM-DD"
agent_task: null
---
```

推奨セクション:

- `AI 作業入口`: 実装SOT、よく読むファイル、ビルド・テスト・デプロイ、公開/非公開メモの扱い。
- `概要`: プロジェクトの目的。
- `使用方法` または `主要コマンド`: 人間向けの操作。
- `関連ドキュメント`: 横断資料や外部リポジトリ。

## Frontmatterスキーマ（全docsファイルに付与）

```yaml
---
title: "..."
category: platform | tool | ops | meta
status: active | wip | deprecated
owner: marzipan99
source_of_truth: "相対パスまたはURL（別リポジトリの場合）"
related_paths:
  - plugins/OyasaiMenu/
last_validated: "YYYY-MM-DD"
agent_task: null  # エージェントへの作業指示があればここに記述
---
```

## ビルド・開発コマンド

```bash
# ビルド（nix環境）
/nix/var/nix/profiles/default/bin/nix develop --command gradle :plugins:OyasaiMenu:build

# フォーマット（CIはtreefmtで検証）
/nix/var/nix/profiles/default/bin/nix fmt

# ビルド後のデプロイ
cp build/libs/Plugin.jar dev-server/plugins/
# → Minecraft上で PlugManX でリロード
```
