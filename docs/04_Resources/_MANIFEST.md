# 04_Resources

小さな参照素材、設定例、サンプル入力を置く。

## 役割

公開可能で軽量な参照素材を置く。
個別プロジェクト固有の素材は、まず対象プロジェクトの `PROJECT.md` から辿れる場所に置く。

## 置いてよいもの

- サンプル設定ファイル
- 小さなテスト入力
- ドキュメント説明に必要な軽量素材

## 置かないもの

- PLATEAUなどの巨大データ本体
- ビルド成果物
- キャッシュやログ
- 外部から再取得できる大容量アセット
- 個人情報、秘密情報、個人用メモ

個人用・一時的・非公開の素材は Git管理外の `archive/` または `local/` に置く。
