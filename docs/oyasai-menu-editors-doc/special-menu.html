特殊メニューの概念

YAMLでは表現しきれない動的なデータ駆動メニューのための仕組み。 YAMLメニューのアクションから OPEN_SPECIAL でターゲットIDを指定して起動します。

提供される特殊メニュー

  • online_players / online-players / players — オンラインプレイヤー一覧
  • confirm — コマンド実行前の確認画面

呼び出しエントリポイント

plugin.specialMenuEngine.open(player, target, action)

OPでない場合は「&c特殊メニューはOP限定です。」と通知して終了。

YAML例

actions:
  - type: OPEN_SPECIAL
    target: online_players

  - type: OPEN_SPECIAL
    target: confirm
    command: "kick {player} 不正行為"
    mode: op

プレイヤーアイテム (playerHead)

  • Material: PLAYER_HEAD + SkullMeta.owningPlayer
  • 表示名: &a<name>
  • ロア: &7左クリックで /tp <name>

クリック動作

slot動作

OP保護

handleOnlinePlayersClick 冒頭で !player.isOp なら closeInventory + 通知。

ソート

プレイヤーリストは sortedBy { it.name.lowercase() } でアルファベット順。

背景: GRAY_STAINED_GLASS_PANE / タイトル: "&8コマンド実行確認"

表示内容

  • slot 13: 「実行予定」(COMMAND_BLOCK) — mode と command をロアに表示
  • slot 20: 「実行する」(LIME_CONCRETE)
  • slot 24: 「キャンセル」(RED_CONCRETE)

クリック動作

slot動作
20closeInventory + plugin.parameterCommandEngine.executeCommand(player, holder.command, holder.mode)
24player.closeInventory()

呼び出し元

  • YAML から OPEN_SPECIAL target=confirm + command/mode
  • GuiMakerの特殊メニューHubから「確認ボタンメニュー」 (サンプル: "say GuiMaker confirm sample")
  • ParameterCommandEngine の confirm=true 経由

InventoryHolder

private class ConfirmCommandHolder(val command: String, val mode: String) : InventoryHolder

command と mode を holder に保持し、clickハンドラから取り出して実行する。
