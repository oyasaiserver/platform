編集キャンバス (openCanvas)

通常GUIまたはPopupを編集する中央の対話的画面です。プレイヤーは自由にアイテムをスロットに配置・移動・削除できます。 アイテムを右クリックすると openContextMenu が呼ばれ、そのスロットの詳細編集に入ります。

動作モード

左クリック / Drag アイテム移動・配置。閉じた後 rebuildSlotsFromInventory が走り PDC からスロット情報を再構築する
右クリック / Shift+右 アイテムがあるスロットで openContextMenu(player, session, slot) を呼ぶ
Shift+左 event.isCancelled = true（インベントリへの転送を抑制）

サイズとタイトル

  • session.menuSize (9, 18, 27, 36, 45, 54 のいずれか) で初期化
  • 通常GUI: タイトルは session.menuTitle
  • テンプレート編集中: タイトルが "&d[テンプレート] <title>" になる
  • Popup編集中: applyPopupReservedSlots により slot 45-53 がナビバー予約として上書き

Popup予約スロットの保護

onInventoryDrag と handleCanvasClick で Popup の slot 45–53 にアイテムを置こうとすると event.isCancelled = true され、「&cPopup の slot 45-53 はナビバー予約です。」と通知されます。

関連クラス

class CanvasHolder(val session: GuiEditorSession) : InventoryHolder
class PreviewHolder(val session: GuiEditorSession) : InventoryHolder
class ContextHolder(val session: GuiEditorSession, val slot: Int) : InventoryHolder

プレビュー画面 (openPreview)

編集中のセッションをディープコピーし、アクションを実行可能な状態で表示するインタラクティブプレビューです。

挙動

  • タイトルは "&7[プレビュー] <menuTitle>"
  • クリック時 handlePreviewClick がアクションリストを実行
  • サポートされるアクション: PLAYER_CMD / CONSOLE_CMD / OP_PLAYER_CMD / MESSAGE / BROADCAST / SOUND / PARAM_COMMAND / CLOSE / OPEN_MENU / OPEN_POPUP / OPEN_SPECIAL / URL / CHAT_PASTE / SUGGEST_COMMAND
  • OP_PLAYER_CMD は一時OP化 (player.isOp = true) で実行され、finallyで戻す
  • OPEN_MENU/OPEN_POPUP は runTaskLater(1L) で /menu <target> を実行

編集に戻るには

  • 通常GUI: /guimaker edit <id> canvas
  • Popup: /guimaker popup edit <id>

PDC追従の仕組み (アイテム本位)

GuiMakerでは、スロットの情報（名前・ロア・権限・アクション・追加データ）をアイテム自身の PersistentDataContainer (PDC) に書き込みます。 プレイヤーがアイテムをドラッグして別スロットへ移したとき、PDCの情報も自然に追従するため、UX的に「設定がアイテムと一緒に移動する」体験になります。

PDCキー

キー型内容
gm_nameSTRING表示名 (&カラーコード可)
gm_loreSTRINGロア（改行区切り）
gm_permSTRING権限ノード or lpgroup:<name>
gm_actionsSTRINGTYPE key=value key=value\nTYPE ... 形式
gm_enchantedSTRING"1" でエンチャント表示ON
gm_extraSTRINGextras key/value (Popup向け fallback_icon等)
gm_funcSTRINGUI スキンエディタ専用: funcLabel識別
gm_screenSTRINGUI スキンエディタ専用: 所属screen識別
gm_skin_itemSTRINGUI スキンアイテムであることのマーク

シリアライズ仕様 (actions/extras)

// serializeActions
TYPE key1=value1 key2=value2
TYPE3 key3=value3

// 空白は \s に、改行は \n にエスケープされる

キャンバス → セッションへの逆変換

rebuildSlotsFromInventory(session) が呼ばれると、現在のキャンバスにあるアイテムをすべて走査し PDCから GuiSlotDef を復元します。Popupの場合は slot 45–53 はスキップ。
