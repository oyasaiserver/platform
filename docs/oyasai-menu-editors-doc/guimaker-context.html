アクションタイプ選択 (openActionTypeMenu)

新しいアクションを追加するときに、種別を選ぶ画面。お気に入り登録モードのときはタイトルが変わります。

カテゴリ別レイアウト

行カテゴリスロット範囲含まれるアクション
R1メニュー系9–16OPEN_MENU / OPEN_POPUP / CLOSE / OPEN_SPECIAL / OPEN_SHOP / OPEN_POINT_SHOP / OPEN_SELL
R2コマンド系18–23PLAYER_CMD / CONSOLE_CMD / OP_PLAYER_CMD / SUGGEST_COMMAND / PARAM_COMMAND
R3メッセージ系27–31MESSAGE / BROADCAST / URL / CHAT_PASTE
R4その他36–37SOUND

すべての行の 先頭スロット (9/18/27/36) はカテゴリラベル用のヘッダーアイテム。 slot 0 にはモード表示 (アクション追加 / お気に入り登録) と現在のアクション件数。

アクション種別一覧 (GuiActionCatalog.types)

OPEN_MENU, OPEN_POPUP, OPEN_SPECIAL, OPEN_SHOP, OPEN_POINT_SHOP, OPEN_SELL, OPEN_MACRO,
PLAYER_CMD, PARAM_COMMAND, CONSOLE_CMD, OP_PLAYER_CMD,
MESSAGE, BROADCAST, URL, CHAT_PASTE, SUGGEST_COMMAND,
SOUND, CLOSE

クリック動作 (handleActionTypeClick)

  • メニューを開く / ポップアップ / 特殊メニュー → ID選択用のサブGUI (openMenuPicker/openPopupPicker/openSpecialMenuPicker) を開く
  • ショップ / ポイントショップ → カテゴリIDをチャット入力 (session.pendingInput)
  • 一括売却 / メニューを閉じる → 即時追加 (パラメータなし)
  • サウンドを再生 / 効果音 → openSoundCategoryPicker
  • その他のテキスト入力系 → GuiActionCatalog.textInputChoice でパラメータ名と入力プロンプトを取得し、チャット入力モードへ

アクション管理 (openActionManageMenu)

スロットの全アクションを一覧表示。並べ替え・編集・削除の起点。

  • 背景: PURPLE_STAINED_GLASS_PANE
  • グリッド(10-16, 19-25, 28-34)に最大21件のアクションを表示
  • slot 0: タイトル/件数表示 (COMMAND_BLOCK)
  • slot 37: アクションを追加 (openActionTypeMenu へ)
  • slot 43: 全アクション削除 — CLEAR_ACTIONS 確認
  • slot 8: 21件を超えるアクションがある場合の警告 (「表示しきれない」)
  • クリック: グリッド上のアクション → openActionEditMenu(player, session, slot, index)

お気に入り管理 (openFavoritesManage)

よく使うアクションを最大8件まで保存できる機能。favorites/<playerUuid>.yml に永続化されます。

  • 背景: YELLOW_STAINED_GLASS_PANE
  • slot 0: 件数表示
  • slot 10–17: お気に入り8件 (左クリック=スロットに追加 / 右クリック=削除)
  • slot 37: 「お気に入りを追加」 → favRegistering = true でアクションタイプ選択へ
  • slot 43: 全削除 (確認なし)

動的呼び出し

コンテキストメニューの slot 38–44 にも、ここに登録されたお気に入りのショートカットが表示され、クリックで即追加されます。
