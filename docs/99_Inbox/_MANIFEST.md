# 99_Inbox

公開可能だが、既存の分類にまだ収まらない知識の置き場。

ここは単なる一時フォルダではない。`platform` に関係する横断的な知見、判断保留の公開メモ、あとで整理したいが捨てるべきではない文脈を置いてよい。

## ルール

- ここに置けるのは公開可能なものだけ。
- 個人情報、秘密情報、個人用メモ、未整理の生ログは置かない。
- 公開してよいか判断できないものは、ここではなく Git管理外の `docs/local/` に置く。
- 分類が明確になったら `01_Projects/`、`02_Docs/`、`03_Outputs/`、`04_Resources/` へ昇格させる。
- 未分類のまま長期保管してよいが、将来の人間やAIが読めるように短い見出し、作成日、関連パスを付ける。
- Markdownを追加した場合は、この `_MANIFEST.md` または同階層の `INDEX.md` から辿れるようにする。

## `docs/local/` との違い

- `99_Inbox/`: 公開リポジトリに残してよい未分類知識。
- `docs/local/`: 非公開、個人的、ローカル環境依存、または公開判断前のメモ。Git管理外。
