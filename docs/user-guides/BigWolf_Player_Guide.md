# BigWolf プラグイン - プレイヤー向けガイド

**最終更新**: 2026年1月27日
**対応バージョン**: OyasaiPets 2.3.0

## はじめに

BigWolfプラグインへようこそ！このガイドでは、ペットの購入から育成、交配まで、プレイヤーの皆さんが楽しめるすべての機能を解説します。

---

## 基本コマンド

### 一般コマンド一覧

| コマンド | 説明 |
|---------|------|
| `/bigwolf` | 使用方法を表示 |
| `/bigwolf buy` | ペット購入GUIを開く |
| `/bigwolf buy <mob名> [variant]` | 指定したペットの購入画面を開く |
| `/bigwolf list` | 購入可能なペット一覧を表示 |
| `/bigwolf menu` | メインメニューを開く |
| `/bigwolf storeall` | 自分の全ペットを収納 |
| `/bigwolf dead` | 死亡したペット一覧を表示 |
| `/bigwolf revive <番号>` | 死亡したペットを復活（50pt） |
| `/bigwolf history` | ペット履歴を表示 |
| `/bigwolf locate <番号>` | ペットの最終位置を確認 |
| `/bigwolf recover <番号>` | 収納中ペットのスポーンエッグを再取得（100pt） |
| `/bigwolf breed` | 交配GUIを開く |
| `/bigwolf rename <番号> <新しい名前>` | ペットの名前を変更 |
| `/bigwolf transfer <番号> <プレイヤー名>` | ペットを他のプレイヤーに譲渡 |

---

## ペットの購入方法

### 方法1: 購入GUIから選ぶ

```
/bigwolf buy
```

このコマンドでペット購入GUIが開きます。購入可能なペットがスポーンエッグで表示され、クリックで購入できます。

### 方法2: 直接指定して購入

```
/bigwolf buy <mob名> [variant]
```

**例**:
- `/bigwolf buy wolf` - オオカミを購入
- `/bigwolf buy wolf pale` - 白色オオカミを購入
- `/bigwolf buy cat tabby` - トラネコを購入
- `/bigwolf buy parrot red` - 赤いオウムを購入

### 必要なポイント

| 項目 | コスト |
|------|--------|
| ペット購入 | 100pt（デフォルト） |
| レベルアップ（フード） | 100pt/回 |
| スキルLv.1（咆哮の書） | 50pt |
| スキルLv.2（突進の書） | 100pt |
| スキルLv.3（極意の書） | 150pt |
| ペット復活 | 50pt |
| スポーンエッグ再取得 | 100pt |
| 交配 | 200pt |

## ペットの召喚と操作

### 基本操作

| 操作 | 説明 |
|------|------|
| **右クリック** | ペットに乗る |
| **Shift + 右クリック** | ステータスGUIを開く |
| **WASD** | 移動（乗車中） |
| **スペース** | ジャンプ（乗車中） |
| **左クリック** | スキル発動（乗車中・スキル習得後） |
| **Shift** | 降りる（乗車中） |

⚠️ **注意**: 同時に召喚できるペットは**3匹まで**です

## ペットの育成

### レベルアップ

ペットに**魔法のペットフード**を与えるとレベルアップします（100pt/回）。

**最大レベル**: 50

### 追加アイテム

| アイテム | 効果 |
|---------|------|
| **ペットブラシ** | ペットを撫でる |
| **ペットのおやつ** | 体力回復 |
| **おもちゃ** | フェッチ遊び |
| **回復薬** | 体力回復 |

---

## スキルシステム

| レベル | スキル名 | 効果 |
|--------|----------|------|
| **Lv.1** | 咆哮（Roar） | 周囲の敵をノックバック |
| **Lv.2** | 突進（Dash） | 高速ダッシュ移動 |
| **Lv.3** | 極意（Hover） | 空中ホバリング |

⚠️ 順番に習得する必要があります（Lv.1 → Lv.2 → Lv.3）

## ペットの収納

### 個別収納

ステータスGUI（Shift+右クリック）→「収納する」

### 一括収納

```
/bigwolf storeall
```

### スポーンエッグ再取得

```
/bigwolf recover <ペット番号>
```

コスト: 100pt

---

## ペットの復活

```
/bigwolf revive <ペット番号>
```

コスト: 50pt

---

## ペットの交配

### 交配GUIを開く

```
/bigwolf breed
```

### 交配の条件

- レベル10以上のペットが**2匹以上**フィールドにいること
- **200pt**のコストが必要

### 子供の特徴

| 項目 | 説明 |
|------|------|
| **バリアント** | 親のバリアントが優先的に遺伝（約40%） |
| **能力値** | 親の平均値を基準に世代ボーナスが加算 |
| **世代** | 親の高い方の世代 + 1 |
| **初期レベル** | 世代に応じたボーナスレベル（最大5） |

## よくある質問

### Q: ペットが消えてしまいました

`/bigwolf locate <番号>` で最終位置を確認してください。

### Q: 他人からもらったペットが使えません

仕様です。ペットは購入した本人のみが使用できます。

### Q: 交配ができません

レベル10以上のペットが2匹以上必要です。
