# CitiesSkyMine ユーザーガイド

> CitiesSkylinesの都市データをMinecraftに取り込み、窓・階段・選択範囲操作などの建築を支援するプラグインです。

---

## コマンド一覧

すべてのコマンドは `/csm <サブコマンド>` または専用のショートカットで使えます。

```
コマンド              ショートカット   説明
─────────────────────────────────────────────────────────
/csm window          /.win           正面方向に窓を生成
/csm slabstairs      /.ss            選択範囲に階段/スロープを生成
/csm stack           /.ns            選択範囲をプレイヤー視点基準で複製
/csm selection       /.sel           WorldEdit選択範囲の保存・復元
/csm config          /.cf            個人設定GUIを開く
/csm debugstick      /.ds            ブロックデータのプロパティ変更
/csm preset          /.brp           ブラシプリセットの管理
/csm help                            ヘルプを表示
/csm version                         バージョンを表示
```

> **取り消し**: ほぼすべての生成は `//undo` (FAWE) で取り消せます。

---

## 窓生成 (`/.win`)

プレイヤーの正面方向に、トラップドアフレーム＋ガラス＋裏地の窓を生成します。

### 使い方

```
/.win [幅] [高さ] [フレーム素材] [ガラス素材] [裏地素材]
```

すべて省略可能で、前回使った値がデフォルトになります。

### デフォルト値

```
幅:         2
高さ:       3
フレーム:   IRON_TRAPDOOR
ガラス:     WHITE_STAINED_GLASS
裏地:       DRIED_KELP_BLOCK
```

### 使い方の例

```
/.win                          → デフォルト設定で窓を生成
/.win 3 4                      → 3×4の窓を生成
/.win 2 3 OAK_TRAPDOOR GLASS   → オーク＋普通ガラスの窓を生成
```

> 窓の周囲の空気ブロックが自動的にSMOOTH_QUARTZで埋められます。
> 生成後、横に並べるための選択範囲が自動設定されます。

## SlabStairs (`/.ss`)

WorldEditで選択した2点間に、勾配に応じてslab・stairs・fullブロックを組み合わせた坂道を自動生成します。

### 使い方

```
1. WorldEditで2点を選択（//pos1, //pos2 など）
2. /.ss [素材名]
3. やり直すなら //undo
```

### 素材の指定

素材名は「ファミリー名」で指定します。自動的にslab/stairs/fullの3種が使われます。

```
/.ss stone_brick      → STONE_BRICK_SLAB + STONE_BRICK_STAIRS + STONE_BRICKS
/.ss oak              → OAK_SLAB + OAK_STAIRS + OAK_PLANKS
/.ss quartz           → QUARTZ_SLAB + QUARTZ_STAIRS + QUARTZ_BLOCK
```

> 緩い勾配では端にslab・中間にstairs、急な勾配ではstairsにfullブロックを加えて自動調整されます。

## Stack（選択範囲複製）(`/.ns`)

WorldEdit選択範囲をプレイヤーの向きを基準に複製します。WorldEditの `//stack` と違い、向いている方向の「前後左右上下」で指定できます。

### 使い方

```
/.ns <方向> <回数> [スキップブロック...]
```

### 方向

```
forward / back / left / right / up / down
```

### 使い方の例

```
/.ns forward 5         → 正面方向に5回複製
/.ns right 3           → 右方向に3回複製
/.ns up 2              → 上方向に2回複製
```

## Selection（選択範囲の保存・復元）(`/.sel`)

WorldEditの選択範囲に名前をつけて保存・復元できます。
また、直前の選択範囲は自動的に記録され、 `/.sel p` ですぐに復元できます。

### サブコマンド

```
/.sel save [名前]      現在の選択範囲を保存
/.sel list             保存済みの一覧を表示
/.sel delete <名前>    保存済みの選択を削除
/.sel p                直前の選択範囲を復元
/.sel <名前>           名前を指定して復元
```

## Config GUI (`/.cf`)

チェスト型のGUIで個人設定を変更できます。

```
/.cf            ホーム画面を開く
/.cf win        窓設定を開く
```

> GUIでクリックするだけで設定を変更できます。
> コマンドで設定した内容もGUIに反映されます。

---

## DebugStick (`/.ds`)

バニラのデバッグ棒と同等の機能をコマンドで提供します。
見ているブロックのBlockDataプロパティを選択・変更できます。

```
/.ds select     プロパティを選択する（次のプロパティへ切り替え）
/.ds cycle      選択中のプロパティの値を変更する
```

---

## ブラシプリセット (`/.brp`)

よく使うブラシコマンドの設定を名前をつけて保存・呼び出しできます。

### サブコマンド

```
/.brp save <名前> <コマンド>     プリセットを保存
/.brp load <名前>                プリセットを適用
/.brp <名前>                     プリセットを適用（loadの省略形）
/.brp list                       保存済みプリセット一覧
/.brp delete <名前>              プリセットを削除
```

### 使い方の例

```
/.brp save 道路ブラシ //br sphere gray_concrete 5
/.brp 道路ブラシ
```

> プリセット名は英数字・ハイフン・アンダースコアの32文字以内です。
> 保存できるコマンドは `//br`, `//brush`, `//mask`, `//gmask`, `//replace` から始まるものに限られます。

## チュートリアル: 窓を並べてみよう

### Step 1: 窓を作成

壁に向かって立ちます。

```
/.win 2 3
```

→ 2×3の窓が生成されます。

### Step 2: 窓を横に並べる

窓を生成すると自動で選択範囲が設定されるので：

```
/.ns right 4
```

→ 右方向に4回複製され、同じ間隔で窓が並びます。

---

## チュートリアル: SlabStairsで坂道を作ろう

### Step 1: WorldEditで2点を選択

坂道の始点と終点をWorldEditで選択します。

```
//pos1     （坂の低い方に立って実行）
//pos2     （坂の高い方に立って実行）
```

### Step 2: 坂道を生成

```
/.ss stone_brick
```

→ 2点間の勾配に応じて、slab・stairs・fullブロックが自動的に組み合わされた坂道が生成されます。

### Step 3: 素材を変えてみる

```
//undo
/.ss oak
```

→ オーク素材（OAK_SLAB + OAK_STAIRS + OAK_PLANKS）に変更されます。

## よくある質問

**Q: 「このコマンドを使用する権限がありません」と出る**
A: サーバー管理者にロール（builder / takumi / admin）の付与を依頼してください。

**Q: 素材名が分からない**
A: タブ補完が使えます。コマンドを途中まで入力してTabキーを押すと候補が表示されます。

**Q: 生成が大きすぎてエラーが出る**
A: サーバーの設定でブロック数上限が決まっています。管理者に上限の確認・変更を依頼してください。

**Q: 設定を毎回入力するのが面倒**
A: 設定は自動的に保存されます。次回も前回の設定が使われます。`/.cf` のGUIからも変更できます。
