概要

OyasaiMenu プラグインに含まれる各種エディタ画面の使用方法・スロット配置・技術詳細を網羅したドキュメントです。 OyasaiMenuはチェストUI形式のメニュー定義（YAML）と、それをGUI上で編集する複合エディタ GuiMaker を中核に持ちます。

主要コンポーネント

  • GuiMaker 通常GUI/Popup/UIスキンを編集する複合エディタ (guimaker/ パッケージ)
  • AdminEngine 管理メニュー (/adminmenu)
  • AnnouncementManager 本(WRITABLE_BOOK)エディタ
  • MacroEngine マクロ一覧・詳細・本エディタ
  • ParameterCommandEngine 可変コマンド (placeholder付き) 編集
  • SpecialMenuEngine オンラインプレイヤー / 確認メニュー

GuiMakerコマンド体系 (一部)

コマンド動作
/guimaker編集ハブを開く（引数なし）
/guimaker hub編集ハブを明示的に開く
/guimaker new <id>新規通常GUIを作成
/guimaker edit <id> [canvas|preview|commit|revert|info|discard|title|name|lore|...]個別操作（GUI+コマンドのハイブリッド）
/guimaker list編集対象メニューID一覧をチャット表示
/guimaker popup [list|edit|new|set]Popup関連
/guimaker ui [edit|list|silent]UIスキン
/guimaker special特殊メニュー入口
/guimaker template [approve]テンプレート管理（公式承認）
/guimaker helpヘルプ

※ コマンド権限: OPのみ（onCommand 冒頭で sender.isOp チェック）

権限・前提

  • GuiMaker: OP限定
  • AdminMenu / MenuEdit: oyasaimenu.admin パーミッション
  • Macro: oyasaimenu.macro パーミッション
  • ParameterCommand / SpecialMenu (online_players, confirm): OP限定

スロット番号 (rawSlot): 左上から右へ 0–8、次の行が 9–17、…、最終行が 45–53

色分け凡例

  • 機 機能ボタン (戻る・追加・削除など)
  • D データ表示 (現在の編集対象)
  • N ナビゲーション (前/次ページ・カテゴリ)
  • 確 確認・実行ボタン
  • 危 削除・キャンセル等の危険操作
  • E エディタバー (slot 45-53、共通)
  • . 背景ガラス (操作不可)
  • G 動的グリッド (アイテム/エントリ表示)
  • 予 予約スロット (Popup 45-53など)
