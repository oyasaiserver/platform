テンプレートの概念

GuiMakerには、編集結果を「テンプレート」として保存・再利用できる機能があります。 テンプレートは 2軸 × 2軸 = 4種類 に分類されます。

Kind (種類)

  • MENU — GUI全体（メニュー54枠分の構造を丸ごと）
  • BLOCK — 単一スロットのアイテム + 設定 (PDC)

Scope (スコープ)

  • PERSONAL — 個人テンプレート (作成者のみアクセス可)
  • SHARED — 公式テンプレート (全員アクセス可、OPコマンドで承認)

保存ディレクトリ

plugins/OyasaiMenu/guimaker-templates/
├── players/<owner-uuid>/
│   ├── menus/    # 個人 MENU テンプレート
│   └── blocks/   # 個人 BLOCK テンプレート
└── shared/
    ├── menus/    # 公式 MENU テンプレート
    └── blocks/   # 公式 BLOCK テンプレート

GuiTemplateEntry

data class GuiTemplateEntry(
    val id: String,        // ファイル名から .yml を取り除いたID (パス区切り含む)
    val kind: GuiTemplateKind,
    val scope: GuiTemplateScope,
    val file: File
)

  ALL("すべて"), MENU("GUI"), BLOCK("ブロック"), PERSONAL("個人"), SHARED("公式")
}

enum class TemplateSortMode(val displayName: String) {
  UPDATED_DESC("新しい順"), UPDATED_ASC("古い順"),
  NAME_ASC("名前順"), NAME_DESC("名前逆順")
}

テンプレートエディタ (openTemplateEditor)

既存テンプレートを右クリックすると、そのテンプレートを編集モードで開けます。

MENU の場合

  • GuiMakerExporter.loadFileIntoSession でテンプレートファイルをセッションに読み込み
  • キャンバスを開く (タイトルが "&d[テンプレート] <title>" に)
  • エディタバーの slot 48 が「テンプレート保存」に変化
  • キャンバス変更ごとに saveWorkingCopy がテンプレートファイルへ自動保存

BLOCK の場合

  • GuiTemplateStore.loadBlockTemplate で読み込み
  • 54スロットのキャンバスを作り、slot 22 (TEMPLATE_BLOCK_EDIT_SLOT) にアイテムを配置
  • そのままコンテキストメニューを開く (openContextMenu(player, session, 22))

session.templateEditTarget

編集中のテンプレートを表すフィールド。これが null でない場合、保存先はライブYAMLではなくテンプレートファイル。

削除確認 (openTemplateDeleteConfirm)

Shift+右クリックで開く赤背景の確認画面。

  • 背景: RED_STAINED_GLASS_PANE
  • slot 13: TNT + 対象情報 (scope, kind, id)
  • slot 20: 実行する (LIME_CONCRETE) — GuiTemplateStore.deleteTemplate
  • slot 24: キャンセル (RED_CONCRETE) — テンプレートハブに戻る

公式承認コマンド (template approve)

個人テンプレートをコピーして公式 (shared) フォルダに格納するOPコマンド。

/guimaker template approve <player|uuid> <menu|block> <template-id> [official-id]

処理 (GuiTemplateStore.approvePersonalTemplate)

  1. sourceId/officialId を sanitizeId でバリデーション
  2. 個人テンプレートファイルを取得・存在チェック
  3. sharedDir 配下に Files.copy(REPLACE_EXISTING)
  4. 成功時は相対パスを返却（"/guimaker-templates/shared/menus/foo.yml" のような形式）

ID制約 (idPattern)

Regex("[a-zA-Z0-9_.-]+(?:/[a-zA-Z0-9_.-]+)*")
  • 英数字・_・-・. と階層区切り / のみ
  • . または .. 単独の階層は禁止
