概念

OyasaiMenuのお知らせは、メインメニュー(root)に表示されるアナウンスメント。タイトル1個 + 本文の複数行構成です。 編集は WRITABLE_BOOK をプレイヤーに渡して本のUIで行う独自のエディタを採用しています。

データモデル

data class Announcement(val title: String, val body: List<String>)

private var currentTitle: String = "&f✦ ようこそ！"
private var currentBody: MutableList<String> = mutableListOf()

保存先

plugins/OyasaiMenu/announcements.yml

YAML構造（リスト形式だが現状は1件のみ管理）:

announcements:
  - title: "&f✦ ようこそ！"
    body:
      - "&7今日は晴れです"
      - "&71日1回でログインボーナス"

編集フロー

1. エディタ起動 /menuedit announce book または管理者メニュー slot 12 から
2. 本を受け取る WRITABLE_BOOK を player.inventory.firstEmpty() に配置、handheldスロットに切替
3. 本を開く 右クリックで本のUIが開く（Minecraft標準UI）
4. テキスト入力 各ページに文字を書く。改行ごとに本文の1行になる
5. 確定 Done: 本文だけ更新 / 署名: 署名名がタイトルになる
6. 本を削除 3 tick 後に対象スロットから本を削除 (フォールバックでインベ全走査)

初期テキスト

currentBody が空の場合は説明ページが入り、空でなければ既存本文がページ254文字単位で分割される。

ここにお知らせの内容を書いてください。
改行ごとに Lore の1行になります。

Done のみ → Lore を更新 (本は消えます)
署名して確定 → 署名名がタイトルになります (本は消えます)

イベント処理 (onPlayerEditBook)

  1. pendingBookEditors から渡したスロット番号を取得
  2. 本のページから本文を抽出 → 改行で分割し空行を除外
  3. currentBody を更新
  4. 署名時(event.isSigning): タイトルを更新、event.isCancelled = true でWRITTEN_BOOK化を阻止
  5. saveToFile() + broadcastRefresh() でメインメニュー再描画
  6. removeBook(player, slot) で本を削除

broadcastRefresh()

現在 root メニューを開いている全プレイヤーに対し、plugin.menuEngine.openMenu(p, "root") を再実行してお知らせの更新を反映させる。

YAMLストレージ詳細

ロード (parseFile)

  • announcements.yml をプラグインリソースから初期コピー
  • YAML の announcements リストの先頭要素のみ取り出す
  • title = String、body = List<String>
  • 解析エラー時はWarningのみ。currentTitle/currentBody は初期値のまま

セーブ (saveToFile)

1件のlinkedMap (title / body) のみのリストとして書き出す。常に上書き。

コマンド一覧 (MenuEditCommand)

コマンド動作JSON対応
/menuedit announce title <text> タイトルを更新 ○ ({ 始まりはJSON componentとしてパース)
/menuedit announce line <番号> <text> 指定行(1始まり)を更新。不足は空行で埋める ○
/menuedit announce remove-line <番号> 指定行を削除 -
/menuedit announce book 本エディタを開く (closeInventory後 1 tick で書籍を渡す) -
/menuedit announce show 現在のタイトル/本文をチャットに表示 -

JSON パース (parseTextInput)

private fun parseTextInput(raw: String): String {
  val trimmed = raw.trim()
  if (!trimmed.startsWith("{")) return trimmed
  return runCatching {
    LegacyComponentSerializer.legacyAmpersand()
        .serialize(GsonComponentSerializer.gson().deserialize(trimmed))
  }.getOrElse { trimmed }
}

JSON形式の{"text":"...","color":"red"} を渡すと、レガシーカラーコード形式 (&c...) に変換して保存します。

Tab補完

  • arg1: announce, shop, whitelist
  • arg2 (announce): title, line, remove-line, book, show
  • arg3 (announce line): 1 〜 (body.size + 1)
  • arg3 (announce remove-line): 1 〜 body.size
