Popupリスト (openPopupMenuList)

menus/popup/*.yml をページング表示します。配置は通常GUIリストと同じですが、背景色とアイコンが異なります。

  • 背景: PURPLE_STAINED_GLASS_PANE
  • 表示色: &dPopupメニュー
  • slot 44 のラベル: 「新規Popup」「/guimaker popup new <id>」
  • ID表示: popup/<id> 形式

クリック時は PopupMenuAdapter.load(plugin, id) でロードし、session.surface = POPUP がセットされた状態でキャンバスが開きます。

UI画面リスト (openUiScreenList)

gui-maker-ui-screens.yml から読み込まれた編集可能な画面の一覧。クリックすると openUiSkinEditor(player, screen) へ遷移します。

  • 背景: YELLOW_STAINED_GLASS_PANE
  • slot 4: ITEM_FRAME でタイトル表示
  • slot 45: 編集ハブへ戻る
  • slot 48 / 50: 前/次ページ (1ページ最大28画面)
  • グリッドにはスクリーン名と ITEM_FRAME が並ぶ
