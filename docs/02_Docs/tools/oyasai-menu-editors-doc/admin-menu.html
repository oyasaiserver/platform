クリック動作 (onInventoryClick)

slot機能動作
10リロードplugin.reload() — 全YAMLを再読み込み
12アナウンス編集インベントリを閉じてから plugin.announcementManager.openBookEditor(player)
14ショップ商品管理インベントリを閉じてチャットに /menuedit shop ... のガイドを表示
16売却ホワイトリストインベントリを閉じてチャットに /menuedit whitelist ... のガイドを表示
34閉じるplayer.closeInventory()

クールダウン制御

すべてのクリックは CooldownManager.isClickOnCooldown(player.uniqueId) でクールダウン中ならスキップ。連打防止。

activePlayers

このメニューを開いているプレイヤーは activePlayers に追加され、onInventoryClose で削除される。onInventoryClick はこの集合の在籍チェックを最初に行う。

関連コマンド (/menuedit)

管理者メニューから案内される操作は、コマンドベースで実行します。

サブコマンド一覧

コマンド動作
/menuedit announce title <text|JSON>お知らせのタイトルを更新
/menuedit announce line <番号> <text|JSON>指定行を更新（不足分は空行で埋める）
/menuedit announce remove-line <番号>指定行を削除
/menuedit announce book本エディタを開く
/menuedit announce show現在のお知らせをチャットに表示
/menuedit shop <category> list商品一覧
/menuedit shop <category> add <material> <buy> <sell>商品追加
/menuedit shop <category> remove <index>商品削除
/menuedit whitelist list売却ホワイトリスト一覧
/menuedit whitelist add hand <売値>手持ちアイテムをWL登録
/menuedit whitelist remove <番号>WL削除

パラメータ詳細

  • announce title/line: テキストが { で始まる場合はJSONとしてパース (GsonComponentSerializer) → 失敗時はそのまま文字列
  • shop add: Material.valueOf でバリデーション。価格は toDoubleOrNull
  • whitelist add hand: 売値は0より大きい必要あり。カスタム名のないアイテムは警告付きで追加

権限

全コマンドで oyasaimenu.admin パーミッションが必要。onTabComplete も同じ権限チェック。
