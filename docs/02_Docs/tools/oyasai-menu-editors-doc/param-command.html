概念とユースケース

OyasaiMenuのアクション PARAM_COMMAND は、コマンドテンプレート内の {name} プレースホルダを プレイヤーがGUIで対話的に値を入力してから実行するための仕組みです。

典型例

  • //stack {amount} — WorldEditのstack数を画面入力
  • give {player} diamond {count} — 対象プレイヤーと個数を選んで配布
  • gamemode {mode} {player} — モードとプレイヤーをenumで選択

プレースホルダのパターン

// 正規表現
Regex("\\{([A-Za-z][A-Za-z0-9_.-]*)}")

呼び出し

OP限定。plugin.parameterCommandEngine.open(player, action) が呼ばれると54スロットのGUIを開きます。

YAML定義例（通常GUIメニュー側）:

items:
  item_10:
    slot: 10
    icon: REPEATER
    name: "&e可変ペースト"
    actions:
      - type: PARAM_COMMAND
        command: "//stack {amount} up"
        execution: player    # player / op / console
        confirm: "true"      # 任意: 確認画面を経由
        params:
          amount:
            type: int
            min: 1
            max: 50
            step: 1
            default: 10

パラメータタイプ (ParamType)

型推定 (inferType)

YAMLで type 未指定の場合、パラメータ名から推定:

  • player / target / user → PLAYER
  • 名前に block / material / item 含む → MATERIAL
  • 名前に radius / scale / speed 含む → FLOAT
  • その他 → INT

パラメータ仕様 (ParamSpec)

data class ParamSpec(
    val name: String,
    val type: ParamType,
    val min: Double?,
    val max: Double?,
    val step: Double,           // デフォルト 1.0
    val defaultRaw: String?,
    val enumOptions: List<String>
)

YAML側では params: { name: { type, min, max, step, default, options } } のネスト形式、または param.<name>.<key> / <name>_<key> のフラット形式に対応。

手入力モード (startTextInput)

  1. pendingTextInput[player.uuid] = PendingTextInput(session, spec)
  2. インベントリを閉じる
  3. 「&e{name} の値をチャットに入力してください。cancel で中止。」
  4. チャット入力 or コマンド入力をキャプチャ (AsyncPlayerChatEvent / PlayerCommandPreprocessEvent)
  5. cancel または「キャンセル」で中止、それ以外は spec.normalizeInput でバリデーション
  6. 整形後、session.values[name] = normalized として再オープン

初期化 (slot 49)

すべての値を spec.defaultValue(player) に戻す。

クランプ (clamp)

min/max が指定されていれば、数値型は coerceAtLeast/coerceAtMost でクランプされる。

実行モード (executeCommand)

slot 45「実行」をクリックすると、expandCommand でプレースホルダを展開してから実行。

展開順序

  1. plugin.menuEngine.applyPlaceholders(player, template) — PlaceholderAPI等の組み込み置換
  2. session.values.forEach { (key, value) -> result.replace("{$key}", value) } — 入力済みの値を埋め込み

実行モード (mode)

mode動作
player (デフォルト)player.performCommand(command)
consoleBukkit.dispatchCommand(consoleSender, command)
op一時OP化して実行 (finally で wasOp に戻す)

YAMLでのモード指定

execution: console または mode: op など。executionMode(action) が execution → mode の順で読む。

確認画面 (confirm=true)

YAML側で confirm: "true" を指定すると、実行前に SpecialMenuEngine.openConfirmCommand 経由で確認GUI(54スロット)が出る。

正規化 (normalizeCommand)

  1. 前後トリム + クォート除去 ("..." / '...') + \/ エスケープ解除
  2. / 始まりなら removePrefix("/")
