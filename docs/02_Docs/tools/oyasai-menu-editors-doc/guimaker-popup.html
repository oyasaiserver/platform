Popup と通常GUI の違い

OyasaiMenu の Popup は、通常GUIとは異なる専用のYAMLスキーマを持つメニューです。

主要な違い

項目通常GUIPopup
YAML パスmenus/*.ymlmenus/popup/*.yml
サイズ9〜54 (可変)54 固定
slot 45-53通常編集可ナビバー予約
背景ガラスサイト全体で固定 (BLACK)glassフィールドで指定
nav_activeなし下部ナビの強調slot番号
YAML階層menu.title, menu.size, items.item_N.icontitle, glass, items.<name>.icon
fallback_*非対応icon/texture/name/lore/actions それぞれ
セッション surfaceGuiEditableSurface.NORMALGuiEditableSurface.POPUP
PopupActionType不要専用enum (open_popup, player_cmd 等)

nav_active の循環選択肢 (nextNavActive)

[-1] + NavBar.entries.map { it.slot } の順に循環。-1 は「なし」を意味します。

Popup関連コマンド

コマンド動作
/guimaker popupPopup一覧を開く (デフォルト=list)
/guimaker popup listPopup選択GUI
/guimaker popup edit <id>既存Popupをキャンバスで開く
/guimaker popup new <id>新規Popup作成
/guimaker popup set <id> glass <Material>背景ガラスをコマンド指定
/guimaker popup set <id> nav_active <slot>nav_active をコマンド指定
/guimaker popup set <id> title <text>タイトルをコマンド指定

set はドラフトに保存される（exportDraft）。ライブ反映するには /guimaker edit <id> commit ではなく、ロードしてからキャンバスで commit。

Popup YAML 構造 (writePopupYaml)

title: "&8Popup タイトル"
glass: GRAY_STAINED_GLASS_PANE
nav_active: -1
items:
  <key>:
    slot: 0..44
    icon: ENDER_CHEST          # or CUSTOM_HEAD (PLAYER_HEAD + texture)
    texture: "<skin-url>"      # 任意
    name: "&aラベル"
    lore:
      - "&7行1"
      - "&7行2"
    enchanted: true            # 任意
    required_permission: "lpgroup:builder"  # 任意
    op_only: true              # 任意
    fallback_icon: AIR         # 権限不足時の表示
    fallback_texture: "<url>"
    fallback_name: "&8未開放"
    fallback_lore:
      - "&7条件を満たすと表示されます"
    actions:
      - open_menu: "shop"
      - close: true
      - player_cmd: "spawn"
    fallback_actions:           # 権限不足時のクリック動作
      - chat_paste: "..."

Popup向けアクションキー名 (popupActionMap)

YAML出力時は通常GUIのキー (type: PLAYER_CMD 等) ではなく、専用のショートキーに変換されます。

GuiActionDef.typePopup YAMLキー
PLAYER_CMDplayer_cmd: "..."
CONSOLE_CMDconsole_cmd: "..."
OP_PLAYER_CMDop_player_cmd: "..."
URLurl: "..."
CHAT_PASTEchat_paste: "..."
SUGGEST_COMMANDsuggest_command: "..."
OPEN_POPUP / OPEN_SPECIAL / OPEN_MENUopen_popup: "..." / open_special: "..." / open_menu: "..."
OPEN_SHOP / OPEN_POINT_SHOPopen_shop: "..." / open_point_shop: "..."
OPEN_SELL / OPEN_MACRO / CLOSEopen_sell: true / open_macro: true / close: true

SOUND, BROADCAST, MESSAGE, PARAM_COMMAND は PopupActionType に存在しないためPopup側では使用不可 (popupActionMap が null を返す)。通常GUIのみで使用可能。

予約スロット 45-53 (ナビバー)

Popupでは slot 45-53 がナビバーとして使われるため、編集時にapplyPopupReservedSlots で常にナビバー用のガラス/ダイヤなどに上書きされます。

スロットを保護する3層

  1. handleCanvasClick: slot 45-53 のクリックを isCancelled = true + 通知
  2. onInventoryDrag: ドラッグ範囲に 45-53 が含まれる場合キャンセル
  3. writePopupYaml: if (slot in 45..53) continue でYAML書き込みからも除外

NavBar enum

下部ナビバーの定義は OyasaiMenu/engine/NavBar.kt にあり、各エントリの slot プロパティを nav_active の選択肢として使用しています。
