マクロの概念

プレイヤーが複数のコマンドを順番に実行できる個人用マクロシステム。 各プレイヤーには上限 (デフォルト＋permissionで拡張) があり、マクロは PlayerMacro として保存されます。

データモデル

data class PlayerMacro(
    val id: String,         // 自動生成: <mcid>_<safeName>[_N]
    val name: String,       // プレイヤーが見る名前
    val ownerUUID: String,
    val commands: List<String>,
    val cooldownSeconds: Int = 0
)

権限

oyasaimenu.macro

特殊コマンド

  • wait 1.0s (または wait 1.0) — 1秒待機（秒数の後の s は省略可）
  • 先頭 / なし → チャット発言として扱う
  • その他 → 通常コマンドとして実行

マクロIDの逆引き

タイトル文字列 "マクロ詳細: <name>" から名前部分を取り出し、カラーコードを除去して plugin.macroManager.getMacros から検索。複数マクロ同名の場合は最初に見つかったものが返る。

本エディタ (openBookEditor)

マクロのコマンドリストをWRITABLE_BOOKで編集する仕組み。

フロー

  1. WRITABLE_BOOK を生成。マクロのコマンドがあれば1行/coomandで詰めてページに分割 (1ページ254文字)
  2. preferredSlot が指定されていてそのスロットが空ならそこに、そうでなければ firstEmpty()
  3. そのスロットを heldItemSlot に設定 → 自動的に手持ちに切り替え
  4. bookEditorPending[player.uuid] = BookEditorState(macroId, slot)
  5. プレイヤーが本UIで編集し「完了」を押す → onPlayerEditBook
  6. ページから本文を取り出し → 改行で分割 → 空行除外 → 新コマンドリスト
  7. 署名(isSigning)もキャンセル扱い、本は3 tick後に削除
  8. コマンドが空なら破棄、変更がなければ「変更なし」、エラーがあれば再オープン

初期表示テキスト (コマンドが空の場合)

コマンドを1行ずつ入力

改行でコマンドを区切ります
スラッシュなし→チャット発言

wait 1.0s で遅延も可

完了 で確定

マクロ実行本 (createMacroBook)

マクロをクリックひとつで実行できる WRITTEN_BOOK アイテム。

本の構成

  • Material: WRITTEN_BOOK
  • Generation: ORIGINAL
  • Title: マクロ名 (空なら "Untitled")
  • Author: プレイヤー名
  • 表示名: &6▶ &e<マクロ名> &8(&7マクロ実行本&8)
  • ロア: 「右クリック→マクロ実行」「Shift+右クリック→内容を開く」「ID表示」
  • ページ1: マクロ概要 (名前/コマンド数)
  • ページ2以降: 全コマンドを番号付きで列挙
  • PDC: macro_book_id でマクロID保存

右クリック実行 (onPlayerInteract)

  1. action が RIGHT_CLICK_AIR または RIGHT_CLICK_BLOCK
  2. 手持ちが WRITTEN_BOOK で PDC に macro_book_id あり
  3. スニーク中(isSneaking)なら素通り (本を開く)
  4. それ以外: event.isCancelled = true + plugin.macroManager.executeMacro

配布 (giveMacroBook)

player.inventory.addItem(book)。インベ満杯なら足元にドロップ。ENTITY_EXPERIENCE_ORB_PICKUP サウンドを鳴らす。

共有機能 (handleShare / SharedMacroManager)

マクロを他プレイヤーに渡すためのID発行システム。

共有ID発行フロー

  1. コマンド空のマクロは共有不可
  2. 既存の共有がある場合は最大5件まで表示 (作成日時付き)
  3. plugin.sharedMacroManager.publishMacro で新IDを発行
  4. IDは buildIdComponent でクリック可能な Component に整形 (ClickEvent.copyToClipboard)
  5. 受取側: /macro import <shareId>
  6. 過去ID一覧: /macro shares

クリックイベント (Component)

共有IDは NamedTextColor.GOLD + BOLD で表示され、クリックするとクリップボードにコピーされる。HoverEventで「クリックでコピー」がツールチップ表示。
