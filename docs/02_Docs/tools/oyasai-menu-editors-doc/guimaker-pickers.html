権限ピッカー (openPermissionPicker)

LuckPermsグループをカテゴリ別に分類してGUI選択できる画面。選択値は lpgroup:<name> として保存されます。

背景: LIGHT_BLUE_STAINED_GLASS_PANE

カテゴリ分類 (GuiPermissionCatalog)

カテゴリ所属グループ例アイコン
プレイヤーランクdefault, shokyu, beginner, member, chukyu, jokyuEMERALD
建築ランクbuilder, takumiBRICKS (takumi だけ DIAMOND_PICKAXE)
特別ロールfly, white, bluefly→FEATHER, 他→LAPIS_LAZULI
スタッフadmin, owner, staff, mod, moderatorNETHER_STAR
その他未分類のLuckPermsグループPAPER

表示名カスタマイズ (displayName)

  • default → 初期 / shokyu, beginner → 初級者 / chukyu → 中級者 / jokyu → 上級者
  • builder → 建築士 / takumi → たくみ
  • fly → Fly / white → White / blue → Blue
  • その他はLuckPerms表示名があればそれ、なければグループ名

レイアウト (フラット形式)

21件まで一括表示するフラット形式。グリッド(10-16, 19-25, 28-34)に collectGroups() の上位21件が並びます。

  • slot 0: タイトル (IRON_DOOR 「権限を設定」)
  • slot 9, 18, 27: カテゴリラベル (プレイヤーランク / 建築ランク / スタッフ)
  • slot 40: 権限をクリア (BARRIER)
  • slot 42: 手入力 (WRITABLE_BOOK)

カテゴリ別ページング (openPermissionGroupPicker)

カテゴリで絞った場合のページング表示。slot 36/44 で前/次ページ、slot 40 で「カテゴリへ戻る」、slot 42 で「手入力」。

サウンドピッカー (openSoundPicker)

選択したカテゴリ (例: ui) で始まるサウンドのみページング表示。

  • サウンドリスト: Sound.values() をkey化し"<category>."でフィルタ
  • 1ページ21件 (グリッド 10-16, 19-25, 28-34)
  • 左クリック: SOUNDアクションを追加/更新
  • 右クリック / Shift+右: 視聴のみ (playSoundPreview)
  • SOUNDアクションは { "sound": "<name>", "volume": "<value>" } 形式で保存

メニューIDピッカー (openMenuPicker)

OPEN_MENU アクションで開くメニューIDを選択するGUI。

  • 背景: LIME_STAINED_GLASS_PANE
  • 表示対象: GuiMakerExporter.listMenuIds(plugin) の編集可能なメニューID
  • グリッド: 10-16, 19-25, 28-34, 37-43 (28件)
  • slot 44: IDを手入力
  • 各アイテム: ENDER_CHEST + ID表示

チャット入力フロー (PendingInput)

多くのピッカーは選択後にチャットでテキスト入力を要求します。

PendingInput sealed class

sealed class PendingInput(val slot: Int) {
  class ItemName(slot: Int, val color: String = "")
  class LoreLine(slot: Int, val color: String = "")
  class LoreEdit(slot: Int, val lineIndex: Int, val color: String = "")
  class Permission(slot: Int)
  class ActionParam(slot: Int, val actionType: String, val actionIndex: Int? = null)
  class MenuTitle(val color: String = "")
}

入力受信処理

2つのイベントハンドラで受信:

  • AsyncPlayerChatEvent (LOWEST priority) — 通常のチャット入力
  • PlayerCommandPreprocessEvent (LOWEST priority) — スラッシュコマンド入力もキャプチャ

どちらも event.isCancelled = true してチャットへの送信を抑制。handlePendingInput でメインスレッドへ戻して処理。

入力の正規化 (normalizeTypedInput)

  1. 前後の空白をトリム
  2. \/ で始まる場合 \ を除去 (コマンド回避のエスケープ)
  3. "..." または '...' で囲まれている場合は引用符を除去
