# OyasaiAdminTools の使い方（プレイヤー向け）

アンケートに回答できます。お知らせは設定された間隔で自動表示されます。ワールドに境界が設定されている場合は、移動できる範囲も制限されます。

## アンケートを開く

| やりたいこと | コマンド |
|---|---|
| 最近の回答可能なアンケートを開く | `/anke` または `/bl survey` |
| ID を指定して開く | `/bl survey <ID>`、`/anke <ID>`、または `/bl <ID>` |
| 途中から再開する | `/anke resume` または `/bl survey resume` |

ID を指定する場合は、運営から案内された ID を使ってください。

## 回答する

- 選択式の質問は、表示された本またはチャットの選択肢をクリックします。チャットに番号が表示された場合は、`/anke 1` のように番号を入力しても回答できます。
- 記述式の質問では回答用の本が渡されます。本に回答を書いて「署名」してください。署名後に回答が送信されます。
- 本を閉じてしまったときは `/anke resume` で質問を開き直せます。
- アンケートを最後まで回答すると「アンケートにご協力ありがとうございました！」と表示されます。

## 制限

- `/anke` で開けるのは、最近のアンケートのうち、回答対象になっていて回答回数の上限に達していないものです。該当するものがなければ「現在回答可能な新しいアンケートはありません。」と表示されます。
- アンケートごとに回答回数の上限があります。上限が1回の場合、上限に達すると「このアンケートは既に上限回数（1回）回答済みです。」と表示されます。かっこ内の数字はアンケートごとに異なります。
- 運営が対象を限定したアンケートでは、対象外の人は回答を開始できません。開始後に対象から外れても、再開や回答時には対象かどうかを確認しません。
- 途中の回答はサーバー再起動で失われます。プラグインだけの停止・再有効化では残る場合がありますが、保存はされないため継続を当てにしないでください。別のアンケートを始めると、進行中の回答は置き換わります。
- 報酬があるアンケートでも、報酬の付与回数上限に達している場合は回答だけが記録され、報酬は付与されません。

## 困ったとき

| 表示 | 意味 |
|---|---|
| `アンケートが見つかりません。` | 入力した ID のアンケートを開けません。ID を確認してください。 |
| `現在回答可能な新しいアンケートはありません。` | 最近のアンケートがないか、対象外または回答上限に達しています。 |
| `このアンケートに回答する権限がありません。` | そのアンケートは現在のアカウントの対象ではありません。 |
| `このアンケートは既に上限回数（1回）回答済みです。` | 上限が1回の場合の表示例です。回答回数が設定された上限に達しています。 |
| `進行中のアンケートはありません。` | 再開できる回答がありません。 `/anke` から開き直してください。 |
| `無効な番号です。` | 表示された選択肢の番号を入力してください。 |
| `現在は記述式の質問ではありません。` | 今の質問は本に記入する形式ではありません。表示された選択肢から回答してください。 |
| `既にアンケート回答用の本を持っています。インベントリを確認してください。` | すでに回答用の本があります。その本に記入して署名してください。 |

本が届かない場合は、インベントリに空き枠を作って `/anke resume` を実行してください。記述式の質問が続くと、次の本が渡されず、前の本だけ消える場合もあります。本がなくなったら同じ手順で再開してください。記述式は `/anke text <回答>` でも回答できます。

番号を入力しても反応がない場合は、回答中のアンケートがないか、今の質問に合わない番号を入力した可能性があります。`/anke` からアンケートを開き直してください。

## ワールドの境界

- 境界の外へ出ると内側へ戻されます。飛行中でなければ移動先の地表へ移されるため、地下から地表へ戻ることもあります。
- 境界外へのテレポートは内側へ補正され、既定では境界外へ着地するエンダーパールは拒否されます。
- 補正時には乗り物から降ろされ、乗り物も内側へ移されます。自分に乗っている乗客も降ろされます。
- 内側へ戻されたときは、通常 `You have reached the edge of this world.` と表示されます。メッセージ・効果音や境界の挙動は運営の設定によって変わります。

## 運営アシスタントを使う

Pi版では、続きの依頼は自分の短い会話を引き継ぎます。他の運営の会話とは共有せず、しばらく使わないと消えます。サーバーやアシスタントの再起動でも消えるため、過去の操作は共有の記録を検索してください。`/assistant reset` で自分の会話と確認待ちを消せます。

「やったこと」の短い記録は運営共通です。「さっき何をした？」などと聞いて検索できます。実行・提案・取消・拒否を区別して残し、resetでもこの共有記録は消しません。受付済みでも成功が確認できたとは限りません。

外部の頭脳が設定され、利用を許可された運営は `/assistant <依頼>` で、プラグインの使い方を質問したり、操作を依頼したりできます。使い方は接続された頭脳側の資料を調べて回答します。運営向け資料を参照した場合は、その資料に基づく回答と明示します。外部プラグインなど資料にない内容は、一般知識に基づく回答と明示します。

- 未許可の操作は `[実行] [次から確認しない] [やめる]` で確認します。本人が60秒以内に操作してください。
- 緑の実行ボタンを押すと、結果を使ってアシスタントが続きを考えて答えます。必要なら次の確認を表示します。
- 金色の `[次から確認しない]` は運営全員の共有許可へ追加します。引数なしの操作では、引数なしのときだけ確認を省略します。引数がある操作で最初の引数から範囲を決められない場合は表示しません。ホバーに表示されたコマンド・サブコマンドの範囲では、以後の引数は何でも確認なしになります。
- 共有許可は `/assistant allow list` で確認し、`/assistant allow remove <番号>` で削除できます。
- 禁止された操作は許可へ追加できません。実行時には、依頼した本人が持つ権限が必要です。
- 通常のコマンド結果はアシスタントが読みます。プレイヤー専用の操作は「本人として実行」と明示され、結果が自分の画面へ出ます。AIで実行してプレイヤー専用と分かった場合も、本人として再実行する前に確認が出ます。

FAWE の選択範囲について「選んだ範囲の大きさを教えて」と質問できます。形・最小と最大の座標・各軸の大きさ・ブロック数を読み取り、確認ボタンは出しません。選択なし・選択未完了・別ワールド・FAWE が使えない場合はその旨を返します。選択やブロックは変更しません。
