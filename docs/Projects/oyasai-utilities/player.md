# OyasaiUtilities の使い方（プレイヤー向け）

移動、持ち物、採掘、飛行、ポーズなどの便利機能をまとめたプラグインです。使える機能や上限は、運営から与えられている利用資格によって変わります。

## ホーム・ワープ・スポーンへ移動する

| やりたいこと | コマンド |
|---|---|
| 今いる安全な場所をホームにする | `/sethome 名前`（省略時は `home`） |
| ホームへ戻る | `/home 名前`（別名 `/homes`） |
| ホームを消す | `/delhome 名前`（別名 `/remhome`） |
| 自分のホームを全部消す | `/delhome *` |
| ワープ一覧を見る | `/warp`（別名 `/warps`） |
| ワープへ移動する | `/warp 名前` |
| スポーンへ移動する | `/spawn` |

ホーム名は小文字として扱います。`bed`、整数だけの名前、`.` を含む名前は登録できません。同名への設定は上書きです。1個だけ登録できる人は、指定した名前に関係なく `home` に登録されます。複数登録できる人の上限も利用資格によって変わります。

`/home` は自分のホームが1個ならそこへ、複数なら一覧を表示します。存在しない名前を指定した場合も、1個ならそのホームへ、複数なら一覧になります。ホームが無い場合は、運営の設定によってベッドなどの復活地点、または今いるワールドのスポーンへ移動します。`/home bed` は有効なベッドなどの復活地点がある場合だけ使えます。

移動先が危険な場合は、周囲の安全な場所へ補正されることがあります。ワールド境界外や、安全な場所が見つからない移動は断られます。クリエイティブ・スペクテイターでは危険な場所の補正を受けません。

## プレイヤーへ移動する・申請する

| やりたいこと | コマンド |
|---|---|
| 相手の場所へ直接移動する | `/tp 名前`（別名 `/tp2p`） |
| 相手を自分の場所へ呼ぶ | `/tphere 名前`（別名 `/s`） |
| 相手の場所へ移動する許可を求める | `/tpa 名前`（別名 `/tpask`） |
| 自分の場所へ来てもらう許可を求める | `/tpahere 名前` |
| 届いた申請を承認する | `/tpaccept [名前]`（別名 `/tpyes`） |
| 届いた申請を拒否する | `/tpdeny [名前]`（別名 `/tpno`） |
| 自分が送った申請を取り消す | `/tpacancel [名前]` |

`/tp 名前` はオンラインの完全な名前で指定してください。省略名やオフラインの名前では、何も表示せず取り消されることがあります。受け入れ設定で断られた場合、この形式では「TPinfo:名前 is in closed mode!」と表示されます。

承認・拒否は名前を省略すると最新の1件を処理します。`*` または `all` を指定すると全件です。取消は省略すると自分が送った全件を処理します。

- 申請は通常120秒で切れます。運営が期限を変えている場合は、申請の通知に出る秒数に従ってください。
- 同じ相手への申請が残っている間は、再申請できません。自分への申請もできません。
- どちらかがログアウトすると、関係する申請は消えます。再起動でも消えます。
- `/tpahere` は**申請した時点の自分の場所**へ呼びます。`/tpa` は**承認した時点の相手の場所**へ移動します。
- 承認時にも利用資格と相手の受け入れ設定を確認します。承認通知が出ても、移動先の読み込み・安全確認・別の移動制限によって移動できないことがあります。申請は移動開始前に消費されます。

## テレポートの受け入れを変える

`/tpset open` は原則受け入れ、`/tpset close` は原則拒否です。最初は open です。

| コマンド | 内容 |
|---|---|
| `/tpset ok 名前` | 許可リストへ追加し、拒否リストから外す |
| `/tpset ng 名前` | 拒否リストへ追加し、許可リストから外す |
| `/tpset none 名前` | 両方のリストから外す |
| `/tpset mode` | open / close を確認する |
| `/tpset oklist` / `/tpset nglist` | 許可・拒否リストを見る |

open では拒否リストの人だけを断り、close では許可リストの人だけを受け入れます。管理者（OP）からの移動は拒否できません。この設定で、あらゆる移動を禁止できるわけではありません。

## 移動履歴へ戻る・進む

`/back`（`/bk`）で前の地点へ、`/forward`（`/fow`・`/fw`）で次の地点へ移動します。テレポートの出発地点と死亡地点が履歴になります。エレベーター、エンダーパール、ポータル、`/jump`、座った状態から立つときの移動も対象で、取り消された移動も記録されます。ただし履歴からの移動は重ねて記録しません。新しい移動をすると「進む」の履歴は消えます。履歴はログアウトしても残り、再起動で失われます。Pita の慣性停止後は、次のテレポートが履歴に残らない場合があります。

履歴の移動は安全な場所へ補正しません。取り消された移動も履歴に入る場合があり、「TP中…」の表示だけで移動完了を判断しないでください。入獄中はホーム・ワープ・スポーン・申請・履歴の移動を使えません。

## 作業台・持ち物を使う

| コマンド | 開くもの・操作 |
|---|---|
| `/workbench`（`/craft`・`/wb`・`/c`） | 作業台 |
| `/enderchest`（`/ec`） | 自分のエンダーチェスト |
| `/disposal`（`/trash`・`/d`） | 36枠の廃棄メニュー。**閉じると入れた物を取り戻せません** |
| `/anvil` / `/loom` / `/grindstone` | 金床・機織り機・砥石 |
| `/stonecutter` / `/smithingtable` | 石切台・鍛冶台 |
| `/oyasaibackpack`（`/obp`） | 自分のバックパック |
| `/hat`（`/head`） | 主手のアイテムを頭にかぶる |
| `/hat remove` | 帽子を外す |
| `/skull [名前]`（`/eskull`・`/playerskull`） | プレイヤーの頭を作る、または手の頭を変更する |

バックパックは1〜6段です。大きなサイズから小さなサイズへ利用資格が変わり、はみ出す位置に保存済みの物があると開けません。運営へ相談してください。重複して開いたり、読み込み中に開き直したりできません。

帽子は主手の**スタック全体**と現在の頭装備を交換します。耐久値のある物はかぶれません。束縛の呪いによって交換・取り外しが断られることがあります。外した帽子や生成した頭が持ち物に入り切らないと、余りは足元へ落ちます。

頭の変更では、主手が空なら副手の頭も対象になります。見た目を取得している間に手の物を変えると変更を中止します。他人の頭の指定や生成が許可されていない場合は、自分の頭になるか、頭を手に持つよう案内されます。

## 採掘する

しゃがんで適切なツルハシで対象の鉱石を掘ると、接している鉱石をまとめて掘れます。通常は最初の1個を含めて最大64個で、連鎖採掘の後は少し待ち時間があります。斜めに接している鉱石や種類の違う鉱石も対象です。クリエイティブでは発動せず、道具の残り耐久が1以下になると追加採掘を止めます。

`/oresmelter toggle`（`/os toggle`）で自動精錬を切り替え、`/os status` で確認します。ON の間はツルハシで掘った鉄・銅・金の原石がインゴットで落ちます。最初は OFF、再起動で OFF に戻ります。許可が無いと toggle は表示を出さず終わります。

運営が指定した再生成ワールドでは、採掘後の鉱石がいったん岩盤になり、時間がたつと元の鉱石へ戻ります。経済連携が有効なら、現在の道具で計算したドロップ数×鉱石ごとの単価のお金が入ります。一般プレイヤーは対象外ブロックを壊したり、ブロックを置いたりできません。

## 飛行・状態・表示を変える

| コマンド | 内容 |
|---|---|
| `/fly [on または off]` | 飛行許可を切り替える（省略時は反転） |
| `/speed 数値` / `/speed fly 数値` / `/speed walk 数値` | 種別を省略すると飛行中は飛行速度、それ以外は歩行速度（利用資格による補正あり）。1は通常速度、入力は0.0001〜10へ補正される |
| `/flyspeed 数値` | 飛行速度を指定する |
| `/sokudo 数値` | 別の飛行速度指定。0.1〜5、1は通常の飛行速度 |
| `/pita` | 飛行中、移動入力を離したときの慣性を止めるモードを切り替える |
| `/jump`（`/j`・`/jumpto`） | 最大300ブロック先の照準にある安全なブロックの上へ移動する |
| `/jump lock` | 飛行中の空中左クリックでジャンプするモードを切り替える |
| `/afk [メッセージ]` | 離席中・復帰を切り替える |
| `/heal` | 体力・食料・空気を回復し、火を消す。通常は効果も消える |
| `/anshi` | 暗視を付ける・外す |
| `/nick 名前` / `/nick off` | ニックネームを設定・解除する |
| `/realname ニックネームの一部` | オンラインで見える人の実名を調べる |
| `/ptime day` / `/ptime @midnight` / `/ptime reset`（別名 `/playertime`） | 自分に見える時刻を相対指定・固定指定・通常へ戻す |
| `/reach 数値` / `/reach reset` | ブロックとエンティティへの操作距離を変更・標準へ戻す |
| `/scale 数値` | 体の大きさを変更する。省略または1で通常、2で2倍、-4で1/4倍 |
| `/getdebugstick` | クリエイティブのときだけデバッグ棒を受け取る |
| `/l` | サーバーの `/list` を実行する |

`/speed` の1より大きい値は、通常速度から運営が決めた上限までの段階です。`/sokudo` と同じ倍率の意味ではありません。Pita がサーバー全体で有効の場合、OFF と出ても慣性停止は続きます。

回復は通常60秒の待ち時間があり、失敗した操作でも待ち時間が付く場合があります。ニックネームは通常32文字まで（色指定も文字数に含む）、英数字と `_` が使えます。他人と重なる名前や禁止された名前は断られます。`/ptime 100` は使えません。数値なら `/ptime 100ticks` のように指定します。

離席からは操作・チャット、離席開始地点から3ブロックを超える移動などで戻ります。視点変更だけでは活動扱いになりません。自動離席が許可されている人は、通常600秒の無操作で離席します。

reach は利用資格に応じて最大16・32・48・64です。scale の入力は -16〜16、負数は絶対値の逆数です。対戦用としてコードで指定されたワールドでは reach / scale は使えません。ログアウトやそのワールドへの移動で標準へ戻ります。

## Red Bull で24時間飛ぶ

`/redbull` は、飛行資格が無い場合に20ポイントで24時間の飛行を有効にします。Red Bull アイテムを飲む方法もあり、同じ20ポイントが必要です。上級ランクの人、既に一日券が有効な人、または常設の飛行資格がある人の場合は無料で飛行を有効にし、アイテムも消費しません。**再使用で期限は延びません。**

アイテムはしゃがみ右クリックで頭ブロックとして置けます。通常の右クリックでは飲みます。券の期限表示は日本時間です。再ログインしても残り期限を引き継ぎ、期限切れで飛行が止まる場合があります。

## スキンを変える・UUIDを調べる

`/skin set MinecraftID` で変更し、`/skin reset` で本来のスキンへ戻します。設定したスキンは再ログイン時にも自動で適用されます。Minecraft ID は英数字と `_` の3〜16文字です。変更・復元には Mojang のプロフィール情報が必要なため、通信中は少し待ってください。統合版プレイヤーは使えません。

`/uuid 名前` は一度でも参加したことのある人の UUID を、ハイフンあり・なしの2形式で表示します。表示をクリックするとコピーできます。対象が未参加の場合は取得できません。

## 座る・ポーズを取る

`/sit`（`/gsit`）、`/lay`（仰向け。`/glay`・`/layback`・`/glayback`）、`/bellyflop`（うつ伏せ。`/gbellyflop`）、`/spin`（回転。`/gspin`）、`/crawl`（這う。`/gcrawl`）。同じコマンドをもう一度使うと解除します。スニークで降りる・戻る操作もできます。

地面にいて、飛行・滑空・水中・乗り物・睡眠・スペクテイターではないときに始められます。退出・死亡・テレポート・ゲームモード変更などでも解除されます。

空の主手で、通常の向きの階段（逆さ・上付きは対象外）・下付きハーフ・カーペット・苔のカーペット・薄い雪を右クリックすると座れます。上に空間が必要で、しゃがみ中には発動しません。`/sit toggle` でこの右クリック座りを ON / OFF にできます。

空の主手で他のプレイヤーを右クリックすると、相手や積み重なった人の最上段へ乗れる場合があります。通常は自分より指定順で下の階級の人だけに乗れます。階級を確認できない場合や、循環する乗り方は断られます。乗られる側が受け入れを拒否する個人設定はありません。`/sit toggle` はブロックへの右クリック座りだけを切り替えます。

## おならを出す

`/fart` で通常のおならモードを ON にすると、しゃがむたびに音と黄色い煙が出ます。ON のときに `/fart` を使うと、どのモードでも OFF になります。

- `/fart stay` は居座りモードです。他のプレイヤーの頭に乗ってしゃがんでも降りず、おならだけ出ます。降りるには `/fart` で OFF にしてからしゃがんでください。
- `/fart fly` は飛行モードです。しゃがみ連打で少しずつ浮き、飛行モード中は連打をやめて落ちても落下ダメージを受けません。空中で OFF にすると落下ダメージを受ける場合があります。

モードは同時に使えません。同じモードをもう一度指定しても OFF になります。サーバー再起動で全員 OFF に戻ります。

## パーティクルを装備する

`/h`（`/particlehats`）でメニューを開き、装備したい物をクリックします。同じ物をクリックすると外れます。通常は同時7個までです。装備の資格が無い物は使えません。

Thief! は走っている間、Rocket Trail は滑空中、Tornado は飛行中だけ表示されます。透明化中や死亡中は表示を止めます。「この種類は表示しません」とある種類は描画されません。

## エレベーターを使う

上下の同じ位置に、次の組み合わせで床を作ります。**ジャンプで上へ、スニークで下へ**、最も近い同じ組み合わせの床へ移動します。

| 上のブロック | その直下 |
|---|---|
| クォーツブロック | レッドストーンブロック |
| 花崗岩 | 粗い土 |
| クォーツブロック | 白色の板ガラス |
| クォーツのハーフブロック | 鉄ブロック |
| 赤色のカーペット | 青色の羊毛 |

移動先は40ブロック以内、床の上に2ブロック分（赤いカーペットは1ブロック分）の空間が必要です。スペクテイターでは使えません。階数表示は周辺の探索範囲内で数えたものです。

## ブロックの表示を一時的に変える

`/togo [半径] [秒数]`（別名 `/refreshtogo`・`/-`）で、自分の画面の周辺ブロックを一時的な表示に置き換えます。通常は半径10、60秒、最大35個です。表示中にもう一度 `/togo` で解除します。`/togom` で種類・個数・半径・時間を選び、`/togom reset` で初期化できます。

対象は運営が表示を用意した階段・壁・フェンス・ハーフ・ドア・トラップドア・板ガラス・鉄格子です。実際のブロックが別素材になるわけではありませんが、表示中の対象を壊そうとしても破壊は止まります。

`/togo auto` はデバッグ棒を持った時の自動起動を切り替えます。`/togom` で取得できる自動起動アイテムでも起動します。主手・副手のどちらでもよく、手から外すと解除します。表示位置は移動に追従せず、時間切れでも持ち続けるだけでは再起動しません。

## 案内を受ける・案内する

案内者に `/annaimode 自分の名前` で登録してもらい、表面1行目が `[案内完了]` の看板を右クリックします。2行目のエリア ID ごとに一度だけ完了できます。案内者には10トークンを付与する処理が呼ばれます。

案内者は上級ランクが必要です。`/annaimode 名前` で初心者を登録し、`/annaimode` で解除します。既に案内中なら解除してから登録し直してください。`/guidecheck 名前` でオンラインの人の最後の案内者・完了日時を確認できます。`/annai`・`/annai-en` は案内文のメニューを表示します。未知の項目名には何も表示しません。

## タイマーを見る

運営などがタイマーを開始すると、全プレイヤーの画面上部に残り時間が表示されます。途中から参加した人にも表示され、0秒になっても終了操作までは `END!` が残ります。

## ゲームモードとアイテムの制限

許可された人は `/gamemode モード`（`/gm`）、`/gmc`（`/creative`）・`/gms`（`/survival`）・`/gmsp`（`/sp`・`/spec`・`/spectator`）・`/gma` でモードを変更できます。持ち物はサバイバル・クリエイティブ・アドベンチャー・スペクテイターのそれぞれで別に保存されます。まだ保存のないモードへ初めて切り替えると持ち物は空になります。持ち物を分ける制限が免除されている人は切り替わりません。変更時に効果も消える場合があります。

クリエイティブで置いたブロックからは物が落ちず、クリエイティブ由来の落とした物は通常サバイバルで拾えません。逆にクリエイティブでは通常の落とした物を拾えません。容器・防具立てなどでも、異なるモード由来の物の操作が止まる場合があります。クリエイティブの持ち物操作では、保存済みホットバーなどの物の付加情報が除去されたり、頭の複製が止まったりすることがあります。

アドベンチャー・スペクテイターでも、クリエイティブ設置の印がない通常の容器やチェスト付きトロッコの持ち物画面でのクリックは制限されます。クリエイティブのスポーンエッグ使用には、運営による制限の免除が必要です。

## 困ったとき

名前・上限・残高・エリア名を含む行は表示例です。実際の値に置き換わります。スキン変更の失敗理由は通信状況などによって変わります。

| 表示 | 意味・対応 |
|---|---|
| `このコマンドを使用する権限がありません。` | コマンドの利用資格がありません。利用できる機能について運営へ確認してください |
| `No permission!!!` | `/tpset` を使う資格がありません |
| `このコマンドを使う権限がありません` | `/anshi` または `/sokudo` を使う資格がありません |
| `このパーティクルを装備する権限がありません。` | 選んだ帽子・パーティクルの利用資格がありません |
| `安全な場所でホームを設定してください` / `ホーム名が不正です` | 足元が危険、または使えないホーム名です |
