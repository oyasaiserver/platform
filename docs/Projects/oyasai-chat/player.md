# OyasaiChat の使い方（プレイヤー向け）

チャンネルで公開チャットの送り先を切り替えたり、プレイヤーへ PM を送ったりできます。日本語変換や発言の言語判定も使えます。

## チャンネルを使う

- `/chlist` で使えるチャンネルを確認します。現在選ばれているチャンネルには `*` が付きます。
- `/ch` または `/join` を引数なしで実行しても、利用できるチャンネル一覧を表示します。
- `/ch チャンネル名`（別名 `/channel`）または `/join チャンネル名` で参加・選択します。通常のチャットは選択中のチャンネルへ送られます。
- `/leave チャンネル名` で参加を外します。最後に残ったチャンネルからは退出できません。自動参加のチャンネル（既定の Global など）は、次の一覧表示・チャット処理・再ログインなどで再び参加状態になります。
- `/chwho チャンネル名` で同じサーバー内の参加者を確認できます。
- 既定の `/g` は Global の別名です。`/g` で選択し、`/g メッセージ` で参加中の Global へ一度だけ送れます。サーバーによって別名が用意されることがあります。

利用できるチャンネルはサーバーによって異なります。Global のメッセージが別サーバーにも届くかは、運営の設定によります。

通常チャットのチャンネル表示をクリックすると `/chlist` を実行します。プレイヤー名をクリックすると、既定では `/msg 名前 ` の入力候補を出します。

## PMを送る・返信する

| やりたいこと | コマンド |
|---|---|
| 一度だけ PM を送る | `/msg 名前 メッセージ`（別名 `/tell`、`/message`、`/pm`） |
| 相手との会話モードを始める | `/msg 名前` |
| 同じ相手との会話モードを終える | もう一度 `/msg 名前` |
| 最後の相手へ返信する | `/r メッセージ` または `/reply メッセージ` |

会話モード中は、通常のチャット入力がその相手への PM になります。`/ch チャンネル名` や `/join チャンネル名` でチャンネルへ戻ると、PM モードは解除されます。

PM を受け取ると既定では通知音が鳴ります。返信先と会話モードは一時情報で、切断や再起動を越えて保存されません。

相手はオンラインで、PM を受け取れる状態である必要があります。OyasaiChat には、プレイヤー自身が PM の受信可否を切り替えるコマンドはありません。

## 日本語変換と言語を選ぶ

`/japanize` または `/jp` で自動変換の on/off を切り替えます。`/japanize on`、`/japanize off` でも指定できます。既定では自動変換が on です。`/japanize on` は選んでいた翻訳先も解除して `/lang auto` に戻します。

`/lang` で現在の言語 mode を確認できます。

- `/lang auto`: 自動の日本語変換を使います。
- `/lang off`: 自動変換を止めます。
- `/lang 言語名`: 選んだ言語への翻訳を使います。指定できる名前は Portuguese、English、Korean、Japanese、Spanish、German、Indonesian、French、Chinese-Simplified、Chinese-Traditional、Russian、Thai、Vietnamese です。大文字・小文字は区別しません。
- 言語コード（`en` など）や日本語の言語名は指定できません。

自動変換は空白だけではない ASCII 文字だけの発言を対象にします。英字は必須ではなく、数字だけの式や数字の辞書キーも対象です。日本語など ASCII 以外の文字を含む文は自動変換の対象外です。変換が成功すると、既定では「変換後の文 原文」の順で表示されます。外部変換が使えない場合は、かな変換または元の文へ戻ることがあります。

変換・翻訳には発言本文を Google へ送る外部サービスを使います。公開チャットだけでなく PM も対象で、`[?]` や `/lang check` による判定も本文を Google へ送ります。

文頭の `#` は、自動の日本語変換を止める印として使えます。既定では印自体は表示から取り除かれます。明示した翻訳先を選んでいる場合、`#` は翻訳要求を止めません。翻訳せずに送りたいときは `/lang off` にしてください。

プレイヤーの公開チャットと PM の末尾には `[?]` が付きます。カーソルを合わせると「この発言の言語を判定」と表示され、クリックするとその発言を判定します。`/lang check <id>` でも判定できます。判定に使える発言は限られており、受け取っていない発言は判定できません。判定を続けて行う場合は数秒待ってください。

## 接続・移動の通知

Velocity 連携時、通知対象のサーバーへ初めて接続すると、対象サーバー全体に参加通知（既定では `to 接続先` 付き）が出ます。切断時は全体に退出通知が出ます。サーバー移動では移動元に `to 移動先` 付き退出通知、移動先に `from 移動元` 付き参加通知が出ます。各通知は運営が指定した対象サーバーに限ります。単独サーバーでも通常の参加・退出通知は抑止されます。

## 制限

- Shortcut で本文を送るには、そのチャンネルに参加している必要があります。通常チャットの公開先は選択中のチャンネルです。
- PM はオンラインの相手にだけ送れます。相手が PM を受け取らない設定の場合も送信できません。
- 公開チャットはネットワーク配送できないと、そのサーバーだけに表示される場合があります。別サーバー宛て PM は失敗応答が届けば失敗表示が出ます。応答が返らず、送信結果を確認できない場合もあります。
- メッセージは1〜4096文字です。短時間に送信が重なると、少し待つよう表示されることがあります。
- URL は短い表示に置き換わります。クリックできるリンクは限られます。
- mute 中は発言できません。mute 状態を確認できない場合も発言は止められます。受信はできます。

## 困ったとき

| 表示 | 意味 |
|---|---|
| `Unknown channel '<入力値>'. Use /chlist.` | チャンネル名が見つかりません。`/chlist` を確認してください |
| `You do not have permission to use <表示名>.` | そのチャンネルは利用できません |
| `You are not listening to <表示名>.` / `You are not listening to <表示名>. Use /join <ID> first.` | そのチャンネルに参加していません。shortcut で送るときは表示された ID で `/join <ID>` を実行します |
| `You must keep at least one usable channel joined.` | 参加中のチャンネルをすべて外すことはできません |
| `You have no active channel. Use /chlist and /join <channel>.` | 利用できる選択中チャンネルがありません。`/chlist` と `/join チャンネル名` を実行してください |
| `Network delivery was unavailable; this message was shown only on this backend.` | メッセージは現在のサーバー内だけに表示されました |
| `That player is offline.` / `That player is not online on this server.` | 相手がオンラインではありません。少し後でもう一度試してください |
| `That player has private messages disabled.` | 相手が PM を受け取れない設定です |
| `You have no private-message recipient.` | 返信先がありません。先に PM を受け取るか、相手へ PM を送ってください |
| `Network bridge is unavailable.` | ネットワーク側へ PM を送れません。少し待ってから再試行してください |
| `The target backend is unavailable.` | 相手のサーバーへ PM を届けられません。少し待ってから再試行してください |
| `Private message target is still being resolved.` | 相手のサーバーを確認中です。確認が終わってから送信してください |
| `Private message mode changed; message was not sent.` | 会話相手の切替中に入力されました。新しい相手を確認して再送してください |
| `Too many pending messages; please wait.` | 送信処理が混み合っています。少し待ってから再送してください |
| `Chat processing is temporarily unavailable.` | チャット処理を開始できませんでした。少し待ってから再送してください |
| `Message is too long.` / `Message must contain 1–4096 characters.` | 本文が長すぎるか、空です |
| `Message must not be empty.` / `Message must not be blank.` | 送信する本文が空です |
| `mute 中は発言できません。` | mute 中です。残り秒数や理由が続く場合があります |
| `mute 状態を確認できません。運営に連絡してください。` | mute 情報を確認できないため発言できません。運営へ連絡してください |
| `mute の期限が切れました。` | mute が期限切れになりました |
| `古い発言なので判定できません` | 判定に使える発言がありません。末尾の `[?]` から判定してください |
| `数秒待ってから判定してください` | 判定を続けて行うには少し待つ必要があります |
| `[判定] 判定できませんでした。時間を空けて再試行してください` | 言語判定に失敗しました。時間を空けて再試行してください |
