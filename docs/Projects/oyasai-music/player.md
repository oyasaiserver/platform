# OyasaiMusic の使い方（プレイヤー向け）

ノートブロックの演奏を録音して公開し、他の人の曲を聴いたり、いいね・お気に入り・プレイリストに登録したりできます。購入したレコードで周囲にBGMを流すこともできます。
コマンドの利用やBGMの範囲は、運営から許可された内容によって変わります。

## 曲を探して聴く

1. `/mm`（別名 `/musicmenu`）でメインメニューを開きます。
2. 左の「全楽曲一覧」「検索」「マイプロフィール」「ストレージ・お気に入り・プレイリスト」から選びます。同じタブをもう一度押すとメインメニューへ戻ります。
3. 曲を左クリックすると再生します。曲名の後ろの `#数字` が楽曲IDです。

| コマンド | できること |
|---|---|
| `/mm play <ID>` | IDを指定して再生 |
| `/mm open <ID>` | 詳細画面を開き、同時に再生 |
| `/getmp`（別名 `/getmusicplayer`） | 携帯用の「音楽プレイヤー」を取得 |

音楽プレイヤーは右クリックで前回の画面、Shift＋右クリックでメインメニューを開きます。取得する前に持ち物に空きを作ってください。
検索は題名の部分一致、作者名の先頭一致です。作者検索の候補は最大32人で、オンライン・フォロー中の人からも選べます。

## 画面の操作

| 操作 | 楽曲一覧 | プレイリスト内の曲 | プレイリスト一覧 |
|---|---|---|---|
| 左クリック | 再生 | 再生 | 開く |
| Shift＋左クリック | 詳細（自分の下書きは設定） | 詳細 | オンラインの相手へ共有 |
| 右クリック | いいね | 曲順変更の対象を選ぶ | 名前変更 |
| Shift＋右クリック | お気に入り・プレイリスト追加 | もう一度同じ操作で除外 | もう一度同じ操作で削除 |

統合版は左の水色の「アクションモード切り替え」で4種類の操作を選び、タップします。選択は画面の種類ごとに覚え、ログアウトで戻ります。審査画面など、この切替を使わない画面もあります。
短い成功・エラー通知は画面下にも出ます。連続したクリックは0.2秒間隔より短いと無視されます。

- 下段で再生／一時停止、前／次の曲、ループ（OFF → リスト全体 → 1曲）、シャッフルを切り替えます。1曲ループを選ぶとシャッフルはOFF、シャッフルをONにすると1曲ループは解除されます。
- 接続を保ったまま一時停止を続けると、20秒相当で終了扱いです。再生ボタンで最後の曲を最初から聴けます。一時停止中にログアウトするとこの終了タイマーは取り消され、再接続しても再登録されません。
- お気に入り・プレイリストは開くと先頭の聴ける曲を自動再生し、順に進みます。通常の楽曲一覧は、ループ・シャッフルがOFFなら自動で次へ進みません。曲間の自動切替は0.75秒待ちます。
- シャッフルだけをONにした場合は直前の曲を避けながら再生を続けます。リスト全体ループと併用すると、一巡するまで各曲を1回ずつ選びます。
- 曲順変更は対象を右クリックし、移動先の曲をクリックします。同じ曲の再クリックで取り消します。お気に入りには曲順変更がありません。
- 共有は相手に同じ曲順のコピーを作ります。その後の編集は連動せず、限定品を聴くためのレコードも渡りません。
- いいね・お気に入り・同じプレイリストへの追加は重複しません。いいねを取り消す操作はありません。
- プレイリスト管理一覧にはページ送りがなく、表示は38件までです。38件あると新規作成ボタンが消えます。曲の追加先選択や共有で38件を超えて作れますが、39件目以降は管理一覧に表示されません。

曲の詳細には作者の作品一覧、フォロー切替、参考リンク、レコード購入、再生方式の切替があります。左右の広がりがある曲だけ立体音響を選べ、未設定なら立体音響です。選択は曲ごと・自分専用に保存され、変更は次の再生から適用します。現在の再生方式は変わりません。
統合版では左右の広がりが無効になり、既定では同時刻・同じ楽器の3音以上の和音を間引きます。通常音域では最低音・最高音を残しますが、拡張音域では通常域へ折り畳んだ音高で選ぶため、本来の最低音・最高音が残るとは限りません。
ログアウトだけでは個人再生は停止せず、再生中の曲は進みます。終了前に再接続すると残りを途中から聴ける場合があります。再生リストは引き継がれません。

## 録音する

録音コマンドは `/record`（別名 `/rec`）です。

| 方法 | 手順・条件 |
|---|---|
| グリッド型 | 範囲を `//copy` → 曲が進む方向を向いて `/record we grid <BPM>`。BPMは正の整数。向いている水平の方向へ1ブロック進むごとに四分音符1個分、同じ列は和音 |
| 回路型 | 範囲を `//copy` → `/record we default`。コピーした回路を解析して録音。実際の演奏と一致しないときは現地回路録音を使う |
| 現地回路録音 | コピー元と同じワールドで `/record we start <0.5\|1\|2\|3\|4>` → 元の回路を動かす → `/record stop`。範囲内の発音だけを50／100／200／300／400ms単位に丸める |
| 生演奏 | `/record live` → 演奏 → `/record stop`。自分の現在地から48ブロック以内、同じワールドの発音を記録。移動すると録音範囲も移動 |
| 回路の確認 | `/record we inspect`。コピーした範囲・音ブロック・ダスト・リピーター・電源の数を表示。保存はしない |

生演奏・現地回路録音は同時に1つまでです。現地回路録音は最初の音が記録される前だけ、同じ開始コマンドでRStickを変更できます。開始前の無音は保存時に取り除きます。ログアウトすると録音は保存せずに終了します。自動で録音を終える期限はありません。
グリッド型・回路型の看板は元の建築から読むため、コピー元の看板を残し、そのワールドで実行してください。

### 看板で音を変える

ノートブロックの真上の看板の表側を使います。

| 行 | 入力 | 意味 |
|---|---|---|
| 1 | `0`〜`100`（`80%` も可） | 音量。グリッド型・回路型だけに適用 |
| 2 | `-100`〜`100` | 左右の定位。グリッド型・回路型だけに適用 |
| 3 | `1`、`1/2`、`-1/16` など | 四分音符の長さを1とする発音ずらし。正は遅らせ、負は早める |
| 4 | 試聴で得た `数字.数字.数字:パターン` | 特定の音源・パターンへ変更 |

3行目の基準はグリッド型なら指定BPM、他は120 BPMです。`1/2` は八分音符1個分です。解釈できない行は無視し、音量・定位の範囲外の数値は範囲内に収めます。生演奏・現地回路録音の音量は100、定位は中央です。
`/demosound <SoundEvent> <パターン> [ピッチ]` で自分だけ試聴できます。TABで選び、ピッチは省略または0〜24。表示されたIDをクリックでコピーし、看板4行目に使います。

## 曲を設定・公開する

録音成功後は下書きとして保存され、楽曲設定が開きます。後からは「マイプロフィール」の下書きをShift＋左クリックするか、自分の曲の詳細から設定を開きます。

- 題名、正の整数のBPM、レコード種類、価格、参考URLを変更できます。文字・数値は金床で入力して右の結果欄をクリックします。空欄は確定できず、経験値は消費しません。
- 参考URLはホットバーの空き1枠が必要です。渡された本を開き、1ページ目をURLに置き換えて「完了」。空のまま完了しても保存しません。
- BPMを変えると保存済みの音の間隔も変わります。レコード種類は左で次、右で前へ切り替えます。
- 価格は0以上を入力できます。画面には「-1で非売化」と出ますが、現行版は `-1` を受け付けません。
- 公開ボタンは左で通常公開、右で限定公開。公開中に押すと下書きへ戻るため、種類を変えるときは一度下書きへ戻してください。新曲通知は初めて通常公開したときだけです。

| 公開状態 | 聴ける人・購入 |
|---|---|
| 下書き | 作者だけが個人再生。作者はレコードを無料で入手できる |
| 通常公開 | 誰でも個人再生。作者以外は設定価格でレコードを購入 |
| 限定公開・個人用 | 作者だけが個人再生。作者以外は購入不可 |
| 限定公開・限定品 | 作者と、その曲のレコードを持ち物またはレコードストレージに持つ人が個人再生。販売可能 |

限定公開中は「個人用／限定品」を切り替えられます。限定品はIDを知るだけでは再生できず、レコードを手放すと次の再生に使えません。聴ける限定公開曲も、いいね・お気に入り・プレイリストに追加できます。下書きには追加できません。
非公開でも、IDを知っていれば `/mm open <ID>` で題名・作者・統計・BPM・作成日時・参考リンクを表示できます。再生は上記の条件で判定されますが、非公開は詳細情報まで隠す機能ではありません。
詳細の「リポスト (宣伝)」は通常公開曲だけを対象に10Pを消費します。

### 音源を差し替える・削除する

「FAWEクリップボードを再読み込み」は現在の曲を上書きします。

| 操作 | 録音方法 |
|---|---|
| 左 | 現在のBPMでグリッド型 |
| Shift＋左 | 生演奏開始 → `/record stop` |
| 右 | 現地回路録音開始 → `/record stop`。前回のRStick、未指定なら1RStick |
| Shift＋右 | 回路型 |

空の録音は上書きしません。「楽曲を削除」をもう一度押すと削除確定です。別の設定操作を押すと確認は解除されます。曲の削除は取り消せず、新しいレコードは元の曲が削除されると別の曲には使えません。

## 報酬と審査

公開後に「オリジナル審査を提出」を押すと仮OKになり、運営へ通知します。仮OKで申請中なら取り消せます。公開・限定公開と審査結果は別で、却下になっても自動で非公開にはなりません。
参考URLがある曲、または仮OK・永続OKの曲は視聴ポイントと売上還元の対象です。

| 報酬 | 既定の内容 |
|---|---|
| 新しいいいね | 作者へ未受取2pt。送信者へ1000円を即時入金。作者の収益化条件は不要 |
| 有効な視聴 | 曲の総視聴数10回ごとに作者へ未受取1pt（収益化対象だけ） |
| 有料レコード販売 | 購入額の80%を作者の未受取報酬へ加算（収益化対象だけ） |

有効な視聴は曲の長さの80%まで個人再生し、放置扱いでなく、同じ人・同じ曲の直近1時間3回／24時間10回の範囲内のものです。環境BGMや運営の審査用試聴は数えません。未受取分はメインメニューの「未受け取り報酬を受け取る」から受け取ります。額や回数上限は運営の設定で変わります。
ランキングの「日間」は前日、「週間」は前週の月〜日、「総合」は累計で、最大7位です。即時の順位ではありません。

## レコードストレージと環境BGM

ストレージは緑のタブから開きます。この音楽機能のレコード専用で、1ページ40枠、最大20ページ。通常の左右クリック・Shiftクリック・ドラッグで出し入れし、閉じると空のページを詰めます。数字キー・複製・ドロップ等の操作は収納欄へ転送しません。

1. 曲の詳細でレコードを入手します。持ち物が満杯なら購入したレコードは足元へ落ちます。
2. ジュークボックス以外の場所で、レコードを持ってShift＋右クリックし「環境BGM設定」を開きます。
3. 範囲は1以上の整数または `world`。使える上限は画面に表示されます。新しいレコードは半径16、ジュークボックストリガー、ループOFFです。
4. レコードを持ち、しゃがまずにジュークボックスを右クリックします。クリエイティブでもレコードを1枚消費します。

| トリガー | 動作 |
|---|---|
| ジュークボックス | 範囲内に人がいれば再生開始 |
| RS信号 | OFFからONへ変わるたび再生／停止を切替。ONの保持では停止しない |
| 接近 | 範囲内に人が入ると再生、全員が離れると停止 |

環境BGMでは、下書き・個人用・限定品の個人再生制限を適用せず、範囲内の人へ音を送ります。設置済みのBGMは非公開化しても自動停止しないため、周囲に聴かせたくないときはレコードを取り出してください。
範囲内へ途中で入った人は曲の途中から聴きます。ループOFFで終わった曲は、トリガーを再投入するまで再開しません。
手ぶらの右クリックで取り出せます。交換時も元のレコードは返りますが、持ち物が満杯なら中止します。取り出し・交換は装填時と同じゲームモードで行います。ジュークボックスを壊すとレコードを落とします。

## 拡張音域を使う

`/mm rp allow`（`/mm resourcepack allow` も可）で利用を許可し、`/mm rp deny` で停止します。許可していない人には通常音域で再生します。

- Java版は必要な場合にダウンロード確認が出ます。準備中の曲は完了後に再生し、読み込み失敗や30秒相当の待機期限で通常音域へ戻ります。許可は次回接続にも保存されます。
- 統合版は最終確認画面の「同意してダウンロード」で許可します。キャンセル・画面を閉じる・120秒経過では許可を変えません。適用のため再接続する場合があります。
- 統合版の確認画面は、同意後のダウンロードができないと参加できなくなる旨を表示します。参加できない場合は運営へ適用状態の解除を依頼してください。参加できる場合は `/mm rp deny` を実行できます。

OMMTからの楽曲送信にも対応します。受信した曲は自分の非公開下書きに入ります。送信ボタンなどOMMT側の操作はこのプラグインのコードからは未確認です。

## 困ったとき

色を除いた表示文言です。画面下にだけ出るものもあります。

| 表示 | 意味・対応 |
|---|---|
| 既にいいね済みです。 / 既にお気に入り済みです。 / 既に追加済みです。 | 重複登録は行っていません |
| この楽曲を再生する権限がありません。限定品はレコードの所持が必要です。 | 作者・公開状態・レコード所持の条件を満たしていません |
| 楽曲が削除または非公開になったため、リスト再生を終了しました。 | 次の曲へ進む際に聴ける条件が変わっています |
| FAWE/WorldEditのクリップボードが見つかりません。先に //copy 等で範囲をコピーしてください。 | 先に対象をコピーしてください |
| 録音対象のノートブロックが見つかりませんでした。 | 保存する音がありません。範囲・電源・録音方法を確認してください |
| 録音中ではありません。 | 生演奏・現地回路録音の開始待ちです |
| 録音の保存中にエラーが発生しました。コンソールログを確認してください。 | 運営へ連絡し、保存済みの曲があるか確認してください |
| 音源ファイルが見つかりません。 / 音源ファイルが壊れているか、未対応の形式です。 | 自分の操作では復旧できません。運営へ連絡してください |
| 20秒間一時停止のため再生を終了しました。 | 再生ボタンで最初から聴き直せます |
| ストレージを読み書きできません。保存データは保持しています。 | この画面の操作を停止しています。運営へ連絡してください |
| レコード情報を復元中です。少し待ってから操作してください。 | ジュークボックスの操作を待ってください。続く場合は運営へ連絡してください |
| 設定の保存に失敗したため、許可状態は変更しませんでした。 | 拡張音域の保存に失敗しました |
| 失敗した報酬の残高を戻せませんでした。管理者に連絡してください。 | 受取失敗分の復元にも失敗しました。再操作前に運営へ連絡してください |
