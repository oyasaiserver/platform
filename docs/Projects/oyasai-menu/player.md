# OyasaiMenu の使い方（プレイヤー向け）

メニューからサーバー内のショップ、売却、チャンネル、各種ショートカットを使えます。コマンドはゲーム内で実行してください。

## メニューを開く

- `/menu`（短縮形 `/mn`）でメインメニューを開きます。メインメニューにはチャンネル、売却、ショップ、SocialLikes、CarBuilder、ユーティリティ、リンク集があります。
- メニュー下部のプロフィールを押すと、自分のプロフィールを開きます。所持金やポイントなども表示されます。
- サーバーでメニューアイテムが登録されている場合は、`/getmenu` で受け取れます。初回ログイン時に自動で渡される場合もあります。メインハンドに持って右クリックするとメニューが開きます。名前などを変更すると開けなくなる場合があります。クラフト材料には使えません。
- ユーティリティにはスポーン・ワープ、作業台、エンダーチェスト、バックパック、金床、ゲームモードなどのショートカットがあります。各機能の利用条件は、その機能を提供するサーバー側コマンドに従います。
- リンク集のボタンを押すと、リンク先の文字列がチャットに表示されます。
- 各サブメニュー下部で、今開いている画面のナビボタンをもう一度押すとメインメニューへ戻ります。
- ユーティリティの Language ボタンは準備中で、押しても何も起きません。

## ショップで買う・売る

`/shop`（短縮形 `/sh`）でショップ一覧を開きます。`/shop blocks`、`/shop decorations`、`/shop ores`、`/shop tools` のようにカテゴリを指定して直接開くこともできます。短縮名は `bl`（blocks）、`deco`（decorations）、`ore`（ores）、`tool`（tools）です。

ショップ画面では、商品の説明に表示される金額と操作を確認してください。

- 通常は左クリックで購入、右クリックで売却します。
- 数量ボタンで通常操作の数量を1・4・16・64個から選べます。エンチャント付き商品の購入は Shift 操作でも1個ずつです。売却は数量ボタンの数量、Shift 売却は条件に一致する所持分すべてが対象です。表示が「1個固定」でも売却数量には適用されません。
- 通常は Shift+左クリックで64個購入、Shift+右クリックでその商品の所持分をすべて売却します。左右反転中は Shift 操作も入れ替わり、Shift+左クリックで全売却、Shift+右クリックで64個購入になります。
- 左右反転ボタンを押すと、左クリックと右クリックの購入・売却が入れ替わります。
- 下部の「前のページ」「次のページ」でページを切り替え、「戻る」でショップ一覧へ戻ります。
- ショップ画面から売るには、素材だけでなく通常エンチャントの種類・レベルが商品と完全に一致し、売却可能なアイテムである必要があります。エンチャントなしの商品には、エンチャント付きの所持品を売れません。
- ショップの在庫にないアイテムや、売値が設定されていないアイテムは売れません。購入後に持ち物へ入りきらない分は足元に落ちます。

ショップ一覧のポイントショップを選ぶか、`/shop ps`、`/pointshop`（短縮形 `/ps`）を使うとポイントショップを開けます。`/pointshop <category>` でカテゴリを指定できます。指定を省略すると最初のカテゴリを開きます。ポイントショップの商品は左クリックで購入します。下部の所持ポイントボタンを押すと、下部のポイント・所持金表示を更新できます。ポイントが足りない商品は、説明欄に「ポイントが不足しています」と必要ポイント・所持ポイントが表示されます。

## アイテムを一括売却する

- `/sell` で売却画面を開き、上段の枠にアイテムを入れて「売却実行」を押します。売れないアイテムは画面に残り、画面を閉じると持ち物へ戻ります。戻しきれない分は足元に落ちます。
- 持ち物のアイテムを Shift+クリックすると、売却画面の空き枠へ移せます。空き枠がない場合は「投入エリアがいっぱいです。」と表示されます。
- `/sell hand` は手に持ったアイテムを売ります。`/sell all` は売れるアイテムを持ち物からまとめて売り、売れない種類は残します。
- 通常ショップと売却は、クリエイティブモードでは利用できません。サバイバルなどに切り替えてから使ってください。ショップ一覧だけ開ける場合があります。ポイントショップにはゲームモード制限はありません。
- 一括売却・手持ち売却では、通常アイテムは素材ごとに売値が決まり、通常ショップの商品とのエンチャント一致は必要ありません。カスタム名、本のタイトルやページ、カスタムモデルデータを持つアイテムは、運営が登録したものだけ売れます。

**大切なアイテムは売却前に取り分けてください。** 容器の中身は売却を止める条件ではありません。名前などの上記条件がない中身入りシュルカーボックスも売れる場合があり、売ると中身ごと失われます。特殊アイテムの登録照合でも、本の本文、名前の色・装飾、容器の中身、他機能が付けた任意のデータまでは同一か確認しません。

## 困ったとき

| 表示 | 意味 |
|---|---|
| You can not use the menu item in crafting! | メニューアイテムを含むクラフトはできません。材料から外してください。 |
| メニューが見つかりません: `<ID>` | 指定されたメニューがありません。運営に連絡してください。 |
| 内部エラー: popup '`<ID>`' が見つかりません。 | ボタンが開こうとした画面がありません。運営に連絡してください。 |
| '`<category>`' が見つかりません。利用可能: ... | `/shop` に指定したカテゴリがありません。表示された候補から選んでください。 |
| カテゴリが見つかりません: `<category>` | 開こうとしたショップカテゴリがありません。運営に連絡してください。 |
| ショップには OyasaiEconomy が必要です。 | 通常ショップを使うための経済機能が利用できません。 |
| 経済プラグインが見つかりません。 | 売却時に経済機能が利用できません。 |
| ポイントショップには OyasaiEconomy が必要です。 | ポイント機能が利用できません。 |
| ポイントショップが設定されていません。 | 開けるポイントショップがありません。 |
| アイテム保存機能は現在利用できません。 | `/getmenu` でメニューアイテムを受け取る機能が停止しています。運営に連絡してください。 |
| ポイントが不足しています。(所持: `<所持ポイント>P` / 必要: `<必要ポイント>P`) | 商品の購入に必要なポイントが足りません。 |
| ポイント引き落とし処理に失敗しました。 | ポイント提供側で引き落としが完了しませんでした。 |
| 残高不足 (所持: `<所持金額>` / 必要: `<必要金額>`) | 商品の購入に必要なお金が足りません。 |
| 引き落とし処理に失敗しました。 / 入金処理に失敗しました。 | お金の引き落としまたは入金が完了しませんでした。売却品は処理に失敗した取引では消費されません。 |
| このアイテムは購入できません。 / このアイテムは売却できません。 | その方向の取引に価格が設定されていません。 |
| `<素材名>` は売却できません。 (カスタムアイテムはホワイトリスト登録が必要です) / (ショップに売却登録されていません) | そのアイテムは現在の登録条件では売れません。特別なアイテムは運営に相談してください。 |
| 手に何も持っていません。 | `/sell hand` の前に、売るアイテムを手に持ってください。 |
| 売却できるアイテムがありませんでした. (売却不可 `<件数>`種あり) | `/sell all` で売れるアイテムがありませんでした。ピリオドはゲーム内表示どおりです。数字は売れなかったスタック数で、種類数とは限りません。 |
| 売却可能なアイテムがありませんでした。 (未登録/ホワイトリスト対象外: `<件数>`種) | 売却画面に売れるアイテムがありません。件数は売れないアイテムのスタック数です。売れないアイテムは画面に残ります。 |
| もう少し待ってから実行してください。 / 時間を置いて実行してください。 | `/sell hand` または `/sell all` を続けて実行しています。少し待ってから再度実行してください。 |
| クリエイティブモードではショップを使用できません。 / クリエイティブモードでは売却できません。 | サバイバルなど、売買できるゲームモードに切り替えてください。 |

通常メニュー、各サブメニュー、通常ショップ、ポイントショップ、管理画面では、短い間隔でボタンを押すと表示なしで無視されることがあります。画面を切り替えた直後も、少し待ってから押してください。売却画面にはこの連打制限はありません。

コマンドを実行できない場合や、メニューのボタンから別の機能を使えない場合は運営に相談してください。メニューから呼び出すチャンネル・ワープ・SocialLikes などの機能には、それぞれの機能側の利用条件があります。

コマンドの権限不足を示す表示文言は、このプラグインでは個別に設定していません。実際の文言はサーバー側の設定によるため、運営に相談してください。
