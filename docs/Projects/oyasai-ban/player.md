# BANについて（プレイヤー向け）

OyasaiServer では、サーバーへ接続するときにBANされていないかを確認します。BANはサーバー全体に効きます。BAN中は、どのサーバーにも接続できません。

## 接続できないとき

BAN中に接続すると、次のような画面が出て接続できません。

```
あなたはOyasaiServerからBANされています。
理由: （BANの理由）
残り期間: 2日 3時間 15分
```

- 残り期間は日・時間・分・秒で表示されます。0 の単位は省きます。永久BANは「永久」と表示されます。
- 期間が終わると自動で解除され、接続できるようになります。
- 接続中にBANされた場合も、同じ画面が出て切断されます。

「BAN情報の確認に失敗しました。時間をおいて再接続してください。」と出たときは、BANされているとは限りません。サーバー側で確認ができなかったため接続を止めています。時間をおいて再接続してください。続く場合は運営に連絡してください。

## サバイバル・Axiom サーバーへの入場

サバイバルサーバーは、上級以上で、運営がホワイトリストに載せた人だけが入れます。上級以上でもホワイトリストに載っていなければ入れないので、運営に申請してください。Axiom サーバーは匠以上の人と、運営から個別に入場を許可された人が入れます。入場できない場合は「サバイバルサーバーには、上級以上でホワイトリストに載った人だけが入れます」などと表示されます。これはBANとは別の制限です。ログイン直後の接続先に入場できない場合は、同じメッセージで切断されます。

## ほかの人がBANされたとき

誰かがBANされると、接続中の全員のチャットに「[ＢＡＮ] 名前 がBANされました。」と出て、効果音が鳴ります。

## 困ったとき

BANの理由や期間に心当たりがない場合は、サーバーの運営に問い合わせてください。
