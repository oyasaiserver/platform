# サバイバル補助の使い方

## 作物の収穫と苗木の植え直し

成熟した小麦・ニンジン・ジャガイモ・ビートルート・ネザーウォートを右クリックすると、その場に収穫物を落として植えた状態に戻します。種や作物を植え直すための消費はありません。

スニークしながら右クリックすると、同じ高さで東西南北につながる同種の作物を最大128マスまでたどります。未成熟の作物は収穫せずに通り抜けます。斜め・上下・別の種類には広がりません。

木の根元を壊したとき、所持品に対応する苗木があれば1つ使って植え直します。ネザーの幹では対応する菌類を使います。クリエイティブでも所持は必要ですが消費しません。2×2の苗木は自動では揃いません。植えられない地面や保護された場所では植えません。

畑は、プレイヤーやモブが踏んでも土に戻りません。

## 倉庫を使う

`/pull` で近くの使える倉庫を開きます。対応 MOD があれば MOD の画面、それ以外はチェスト形式の画面です。`/pull gui` なら常にチェスト形式で開きます。

| 操作 | 取り出す量 |
|---|---|
| 左クリック | 1スタック |
| Shift＋左クリック | 所持品に入るだけ全部 |
| 右クリック | 1個 |

画面の下段にページ切替・検索・検索解除・閉じる操作があります。検索は金床の名前欄に入力し、右の紙で確定します。経験値や素材は消費しません。

日本語名・英語名・カスタム名・エンチャントやエンチャント本の内容を検索できます。ひらがな／カタカナ、全角／半角、大文字／小文字の違いも吸収します。名前・エンチャント・耐久値・内容などが違うアイテムは別々に表示します。

コマンドで直接取り出すこともできます。

```text
/pull stone 64
/pull minecraft:oak_log
/pull hand 16
```

`hand` はメインハンドに持っているアイテムの種類です。個数は1〜2304、省略すると1スタックです。名前やエンチャントなどが付いた物は画面の該当する行から取り出してください。

取り出せるのは所持品に入る分だけで、残りは倉庫に残ります。結果には取り出した数と容器数、主な取り出し場所が表示されます。

倉庫の範囲から少し離れていても使えます。近くの利用可能な倉庫のうち最寄りの1件が対象です。「使える倉庫がありません」と出たら、倉庫に近づき、メンバーになっているか確認してください。「倉庫の索引を読み込み中」と出たら少し待ってから使ってください。

## 倉庫を登録する

1. `/wh pos1` と `/wh pos2` で倉庫の対角の2点を選びます。
2. `/wh create <名前>` で登録します。
3. `/pull` で中身を確認します。

座標を省略すると、5マス以内で見ているブロック、なければ足元を選びます。`/wh pos1 <x> <y> <z>` のような指定や、`~`・`~5` の相対座標も使えます。選んだ両角を含む直方体が倉庫の範囲になります。

倉庫の名前は1〜32文字で、ほかの倉庫と重複できません。倉庫同士の範囲も重ねられません。他の人の容器を範囲に含めないでください。

対象になる容器はチェスト・トラップチェスト・樽・シュルカーボックスです。ホッパー・かまど・エンダーチェスト・容器付きトロッコは対象になりません。アイテムとして入っているシュルカーボックスの中までは探しません。

倉庫内の対象容器は直接開けなくなります。中身の取り出しには `/pull`、投入には下の投入口を使ってください。

| コマンド | 操作 |
|---|---|
| `/wh list` | 倉庫の一覧 |
| `/wh info` | その場の倉庫の登録情報・空き枠・除外・投入口を確認 |
| `/wh resize <名前>` | 選び直した2点で範囲を変更 |
| `/wh rename <旧名> <新名>` | 改名 |
| `/wh delete <名前>` | 登録を削除 |
| `/wh member add <名前> <プレイヤー>` | メンバーを追加 |
| `/wh member remove <名前> <プレイヤー>` | メンバーを削除 |

範囲変更・改名・削除・メンバー編集は持ち主が行えます。メンバーに `*` を指定すると全員が利用できます。

## 投入口からしまう

倉庫の外にあるチェスト・トラップチェスト・樽を見て、`/wh link <倉庫名>` を実行します。解除はその投入口を見て `/wh unlink` です。

メンバーが投入口にアイテムを入れて閉じると、倉庫へ順に格納します。ラージチェストは左右で1つの投入口です。名前付きアイテム・除外した種類・入りきらない物は投入口に残ります。別の投入が処理中だった場合は、終わってから開閉し直してください。

その場の倉庫で `/wh exclude add <item|hand>` を使うと、その種類を自動格納から除外できます。解除は `/wh exclude remove <item|hand>`、確認は `/wh exclude list` です。既に倉庫にある物は除外しても一覧に出て、手動で取り出せます。

## エンダーチェストの引き継ぎ

ワールドが新しくなった後、初めてログインしたときに以前のエンダーチェストの中身を引き継ぎます。通常の再ログインでは上書きしません。操作用のコマンドは不要です。

**引き継げるのは5マスまでです。** 埋まっていたマスが5つ以下なら全部、6つ以上なら抽選で5マスを、元の位置に戻します。

**引き継いだシュルカーボックスとバンドルの中身は空になります。** 容器そのものは引き継ぎます。
