# OyasaiPets の使い方（プレイヤー向け）

ペットを購入して召喚し、乗ったり、育てたり、収納したりできます。購入にはポイントを使います。

## ペットを購入する

- <code>/bigwolf list</code> で選べる種類を確認します。
- <code>/bigwolf buy</code> でショップを開き、ペットを選んで購入します。購入確認画面で必要ポイントを確認してください。
- 種類を直接指定する場合は <code>/bigwolf buy &lt;MOB名&gt; [variant]</code> です。たとえば <code>/bigwolf buy WOLF</code> でオオカミの購入画面を開きます。
- 購入が完了するとペットが召喚され、そのまま乗った状態になります。
- 召喚できるのは同時に3匹までです。

購入できる種類は WOLF、CAT、FOX、RABBIT、PANDA、POLAR_BEAR、ARMADILLO、DOLPHIN、AXOLOTL、FROG、TURTLE、PARROT、CHICKEN、BEE、ALLAY です。種類ごとのバリアントは購入画面に表示されます。

## ペットに乗る・収納する

- ペットを右クリックすると乗ります。
- 乗っている間に Shift を押すと降ります。
- 自分のペットをスニークしながら右クリックするとペットの操作画面を開きます。
- <code>/bigwolf menu</code> または <code>/bigwolf pets</code> でペット画面を開きます。画面から個別収納などを選べます。個別収納には所持品に空きが必要です。
- <code>/bigwolf storeall</code> は自分の召喚中ペットをまとめて収納し、スポーンエッグにします。所持品に入りきらない分は足元に落ちます。
- 収納したスポーンエッグを使うと、ペットを再び解放できます。解放には安全な場所が必要です。
- 退出時とサーバーの通常停止時にも、召喚中のペットは自動収納されます。所持品に入りきらないエッグは足元に落ちるため、退出前に空きを確保してください。クラッシュ時の収納は保証されません。

### 騎乗中の操作

- WASDで移動し、地上ではSpaceでジャンプします。飛行タイプはSpaceを押し続けると上昇します。飛行には慣性があり、入力を離してもすぐには止まりません。
- 水中タイプは、水中で前進・後退しながら視線を上下に向けると上下移動します（Lv.3の水面走行中は別の動作になります）。
- 陸上・飛行タイプは水中で速度が0.3倍になります。ただし陸上タイプでLv.3を選択中はこの減速を受けません。水中タイプは水中で1.2倍、陸上で0.6倍、カメは陸上で0.3倍になります。

自分以外の人が自分のペットを右クリックすると「このペットには飼い主しか乗れません。」と表示されます。ペットは同じワールド内で飼い主から20ブロックを超えて離れると、5秒ごとの確認で飼い主の近くへ移動します。誰かが乗っている間はこの追従移動をしません。

## 育てる・遊ぶ

- ケア用品・スキルブック・パーティクル結晶・おもちゃは、<code>/bigwolf buy</code> →「アイテムショップ」→各カテゴリから購入できます。スキルブックは購入時と使用時にそれぞれポイントが必要です。
- ペットフードを持ってペットに使うと食事レベルを上げられます。1回の操作ごとにポイントを使います。最大レベルは既定で50です。フードのアイテム自体は消費されません。
- ブラシを使うとなでた回数が増え、レベルアップすることもあります。親密度の数値を上げる機能はありません。ブラシは消費されません。5秒以内に続けて使うと、画面下に「撫ですぎです。」と表示されます。
- おやつは1個消費し、ペットを回復させます。レベルアップすることもあります。
- ヒールポーションはペットを回復させます。すでに体力が満タンでもアイテムは消費され、「ペットの体力はすでに満タンです。」と表示されます。
- ブラシ・おやつでのレベルアップは既定でレベル10まで、1回の確率は既定で5%です。おもちゃは遊んだ回数を増やしますが、レベルアップしません。レベル上限や確率はサーバー設定で変わります。
- スキルブックはLv.1から順番に使います。すでに解放している段階を飛ばして上位だけを解放することはできません。解放にはアイテムとポイントが必要です。
- スキルを解放したら、ペットの操作画面の剣アイコンで使うスキルを選びます。選択後、そのペットに乗って左クリックすると発動します。Lv.1（咆哮）とLv.2（突進）はプレイヤー単位で5秒の再使用待ち時間を共有し、ペットを乗り換えても待ち時間が続きます。待ち時間中は「スキル準備中... 残り ... 秒」と表示されます。
- 咆哮は周囲の生物を吹き飛ばし、2ダメージを与えます。敵味方や所有者を区別せず、他プレイヤーや他人のペットも対象になり得ます（使用者・騎乗しているペット・その同乗者は除外）。周囲を確認して使ってください。
- Lv.3は飛行タイプのホバリング、水中タイプの水面走行を左クリックで切り替えます。陸上タイプには切替操作はありませんが、選択中は騎乗時の水中減速を受けなくなります。
- パーティクルの結晶を使うと、ペットに追加の見た目効果を解放できます。

「非定型 ★」はペットの性質です。ブラシ・おやつのレベルアップ確率が既定で定型の1.5倍（7.5%）になり、未騎乗時に特有の行動をする対象になります。確率倍率や行動の有効・無効はサーバー設定で変わります。

### おもちゃの使い方

種類に合った専用おもちゃを使います。近く（横方向各15ブロック・上下各10ブロックの範囲）にいる、自分の誰も乗っていないペットが対象です。

- 投げるおもちゃは右クリックで投げます。ウーパールーパーはペットが水中にいるときだけ遊べます。持ち帰ったおもちゃは地面に落ちるので拾ってください。
- 猫じゃらしはメインハンドに持ち、釣りを開始する操作で猫を遊ばせます。
- イルカの風船は右クリックで投げます。遊び終わった風船も直接所持品へ入らず、足元に落ちます。

### 復活・再取得

- 死亡したペットは <code>/bigwolf dead</code> で番号を確認してから <code>/bigwolf revive &lt;番号&gt;</code> を実行します。復活にはポイントが必要で、召喚枠に空きがあり、足場と空間のある場所でなければ実行できません。
- 収納中のスポーンエッグをなくした場合は、<code>/bigwolf history</code> で番号を確認し、<code>/bigwolf recover &lt;番号&gt;</code> を実行します。インベントリかエンダーチェストに同じペットのエッグがある場合は再取得できません。再取得にはポイントが必要です。エッグが所持品に入らない場合は足元に落ちます。
- 再取得エッグは通常収納したエッグと同じ情報を保持しません。解放すると速度・ジャンプの倍率が1.0、性質が定型、選択中の見た目効果がなし、ホバリングがOFFに戻り得ます。能力や性質を残したい場合は、先に元のエッグを探し、運営に相談してください。
- <code>/bigwolf locate &lt;番号&gt;</code> は現在地を追跡して移動させる機能ではなく、位置を表示します。

## 交配・譲渡・放棄

### 交配

<code>/bigwolf breed</code> を実行し、条件を満たすペットを2匹選びます。どちらも既定ではレベル10以上で、召喚中である必要があります。必要レベルはサーバー設定で変わります。交配にはポイントが必要で、子ペットを召喚する空き枠と安全な場所も必要です。

異なる種類のペット同士も選べます。その場合、子どもの種類は先に選んだ親にそろいます。親ごとの子どもの数に上限はありません。

子どもの世代は親の高い方の世代+1です。速度・ジャンプの倍率は両親の平均に乱数・突然変異・世代補正を加えて決まり、既定の上限は1.5倍です。初期レベルも世代に応じて増えます（既定では世代-1、最大5）。見た目は親のバリアントを重くした抽選で、性質も親の性質に応じて抽選します。親のスキルは継承せず、子どもで解放し直します。

### 譲渡

1. <code>/bigwolf transfer &lt;番号&gt; &lt;オンラインのプレイヤー名&gt;</code> を実行します。
2. 表示されたペット名と相手を確認し、30秒以内に同じコマンドをもう一度実行します。
3. 相手に収納用スポーンエッグが渡ります。譲渡後に取り消す操作はありません。

2回目に別のペットまたは相手を指定すると、前の確認は取り消され、新しい確認が始まります。期限が切れた場合は最初からやり直してください。

### 放棄

<code>/bigwolf abandon &lt;番号&gt;</code> で確認画面を開きます。放棄したペットは履歴から通常のペットとして使えなくなり、取り消せません。死亡中のペットは放棄できません。

## 表示が出たとき

| 表示 | 意味・次にすること |
|---|---|
| 「ペットは同時に3匹までしか召喚できません！」 | 召喚枠がいっぱいです。先に1匹を収納してから試してください |
| 「既に最大レベルです！」 | その育成操作で上げられる上限に達しています |
| 「番号 &lt;番号&gt; の召喚中ペットが見つかりません。」 | 名前変更・譲渡の対象は召喚中である必要があります。履歴で状態を確認してください |
| 「番号 &lt;番号&gt; の収納中ペットは見つかりません。」 | 再取得できる収納中のペットが見つかりません。履歴で状態と番号を確認してください |
| 「この場所ではペットを復活できません（足場と空間が必要です）。」 | 足場や上方向の空間を確保し、場所を変えてください |
| 「この場所では召喚できません（保護されています）。」 | 召喚できなかったことを示す表示です。この表示だけでは原因となった保護範囲を特定できないため、場所を変えても続く場合は運営に伝えてください |
| 「この場所ではペットを解放できません（保護されています）。」 | 収納エッグから解放できなかったことを示します。別の場所で試し、続く場合は運営に伝えてください |
| 「譲渡確認の有効期限が切れました。もう一度最初から実行してください。」 | 30秒を過ぎています。譲渡コマンドを最初から実行してください |
| 「ポイント情報の取得に失敗しました。」 | ポイントを確認できませんでした。時間をおいて再試行し、続く場合は運営に伝えてください |
| 「ポイント処理を完了できなかったため中止しました。時間をおいて再度お試しください。」 | ポイントの消費が完了しませんでした。操作は中止されています。時間をおいて再試行してください |
| 「このペットエッグは無効です。（放棄または削除済み）」 | 対応するペット情報がありません。エッグを使わず運営に相談してください |

ゲーム内での表示・操作確認は行っていません。
