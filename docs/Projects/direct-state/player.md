# DirectState の使い方（プレイヤー向け）

ブロックを壊さずに、向き・接続・形・素材などを編集する機能です。使える操作や道具はサーバー側で設定されています。

## 画面とモード

- `/ds` または `/ds gui` で設定画面を開きます。使える項目だけ表示されます。
- `/ds help [1|2|3]` でコマンド一覧を表示します。ページ番号をクリックして移動できます。
- 各モードの設定はプレイヤーごとに保存されます。
- `/ds toggle`（短縮形 `/ds tgl`）は、素手編集・個人の更新抑制・素材置換をまとめて一時停止／再開します。各モードの ON/OFF 設定自体は変わりません。編集棒はこの一括停止の対象外です。場所に設定された更新抑制も止められません。
- 設定画面の一括停止項目は、素手編集・更新抑制・素材置換の3機能をすべて使える人に表示されます。コマンドの `/ds toggle` には別の許可が必要で、画面では使えてもコマンドでは拒否される場合があります。

## 素手でブロックの状態を変える

`/ds hand on`（短縮形 `/dsh on`）で有効にします。`off` で停止、`toggle` で切り替えます。

両手に何も持たず、しゃがまずに、対応ブロックを右クリックしてください。向き、接続、成長段階、点灯、水量など、ブロックに応じた状態が変わります。クリックした位置によって操作が変わるブロックもあります。

### ブロックごとの操作

以下は素手編集と Hand 編集棒の右クリック操作です。「巡回」は最後の状態から最初へ戻る操作です。形を編集できるブロックでは形の操作が優先されます。

| 対象 | クリック位置と動作 |
|---|---|
| フェンス・板ガラス・壁 | 選んだ方向の接続を切替。壁の腕はなし→低い→高い→なし。壁の上下面中央や、突き出した腕を除く側面上端では支柱を切替 |
| 対応するフルブロック・ハーフ・階段 | クリック区画の形を巡回。材質によって使える形が異なる |
| 鐘 | 上面で取り付け方式を巡回。側面の上部（高さ13/16以上）で向きを変更、側面のそれ以外で本体の表示／非表示を切替。下面で向きを変更 |
| エンチャント台 | 本体の表示／非表示を切替 |
| ベッド | 上下面で向き、側面で頭／足を切替。クリックした1ブロックだけを編集 |
| 原木・木 | 面の外周4/16で軸変更、中央で皮付き／皮なしを切替 |
| 竹ブロック | 上下面で皮付き／皮なし、側面で軸を変更 |
| 大釜 | 上面の縁から2/16以上内側で空→水→粉雪→溶岩→空。その他では水・粉雪の量を巡回。空の大釜は側面では変化せず、上下面で水へ。満水の水大釜は上下面で空へ |
| ピストン・粘着ピストン | 先端面、または水平側面の先端寄り1/4で伸長を切替。それ以外で向きを変更 |
| ピストンヘッド | 根元面の中央（中心から各軸4/16以内）で短縮を切替。それ以外で向きを変更 |
| オブザーバー | 背面中央（中心から各軸2/16以内）で通電を切替。それ以外で向きを変更 |
| クラフター | 本体上面の背面側2頂点と、それにつながる背面・側面の上端でトリガー状態を切替。その他の本体上面でクラフト状態、それ以外で姿勢を変更。横倒しでは本体上面も横を向く |
| 模様入り本棚 | 正面の6枠をそれぞれクリックして本の表示を切替。他面で向きを変更。実際の本の出し入れではない |
| 看板・吊り看板 | 通常は向きを変更。吊り看板は上面・側面上端2/16で天井型→鎖二本型→壁型→天井型を巡回 |
| ツタ・ヒカリゴケ・スカルクヴェイン・樹脂の塊 | 面中央で既存面を削除、外周4/16で隣接面を切替。最後の1面は残す |
| ペールモスカーペット | 上下面中央で底部を切替、外周で側部をなし→低い→高い→なし。側面中央でその側部を削除、外周で隣接部分を編集。最後の1部分は残す |
| レッドストーン | 上面中央（中心から各軸3/16未満）で強度を巡回。それ以外で選んだ方向の接続をなし→横→上→なし |
| 銅の電球 | 面中央（中心から各軸2/16以内）で通電、それ以外で点灯を切替 |
| リピーター・コンパレーター | 側面で向き。リピーターは上面中央でロックを切替。それ以外は共通の通電操作へ |
| かまど・溶鉱炉・燻製器／樽 | 正面で点灯／開閉を切替、他面で向きを変更 |
| 養蜂箱・ミツバチの巣 | 正面で蜜の量を空／最大に切替、他面で向きを変更 |
| キャンドル | 上面で本数を巡回、他面で点灯を切替 |
| 頭・壁の頭・旗 | 向きを変更。ドラゴンの頭は水平側面で通電を切替 |
| リスポーンアンカー | 充電量を巡回 |
| スカルクシュリーカー・カタリスト・センサー | 召喚可否／開花／作動状態を切替。調律されたセンサーは上下面で向き、他面で作動状態 |
| ウツボカズラの作物 | 上面で成長段階（上半分は3／最大、下半分は巡回）。その他で上半分／下半分を切替。下から上へ変える際は成長段階3に合わせる |
| 小麦などの作物 | 成長段階を巡回。コーラスフラワーは0／5。トーチフラワーは最大成長後に花へ、花は成長段階0の作物へ |
| カボチャ・メロンの茎 | 上面で実付き／通常を切替、その他で向きまたは成長段階 |
| カメの卵／スニッファーの卵 | 卵の数／孵化段階を巡回 |
| 砂・砂利 | 怪しげな素材へ変更し、ブラシ段階を巡回して元の素材へ戻す |
| 氷 | 薄氷へ変更し、劣化段階を進めて氷へ戻す |
| 竹・ケーキ・雪・シーピクルス | 葉の状態／食べた量／積雪量／本数を巡回 |
| 花びら・落ち葉 | 側面で向き、上下面で量を巡回 |
| 洞窟のツタ | 中央で実の有無、外周4/16で先端／茎を切替 |
| 大きなドリップリーフ | 側面で傾き、上下面で向き。小さなものなど2段植物では向きや上半分／下半分を切替 |
| マングローブの芽・垂れ苔 | 上下面で吊り状態（芽）、先端状態を切替（苔）。芽の他面は成長段階 |
| クリーキングの心臓・乾燥したガスト | 上下面で軸／向き、側面で状態／水分量を巡回 |
| 鉄のドア・鉄のトラップドア | 開閉。ドアの相方があれば開閉状態も合わせる |
| レール・はしご・鎖・ホッパー・砥石 | 線路形状／向き／軸を変更 |
| フェンスゲート・エンドポータルフレーム | 上下面で壁内状態／目の有無、側面で向きを変更 |
| 焚き火・避雷針・トリップワイヤーフック | 側面などで向き。焚き火の下面では信号煙、上面では点灯。避雷針・フックの先端等は共通の通電操作へ |
| 鍾乳石 | 先端・根元面で上下方向、側面で太さを巡回 |
| 醸造台・耕地・書見台・足場 | 瓶の表示／乾湿／本の表示／底部状態を切替 |
| トライアルスポナー・ヴォールト | 不吉状態を切替。ヴォールトの上下面は向きを変更 |
| 強力な硫黄 | 乾燥／連続反応状態を切替 |
| チェスト・機織り機・石切台・彩釉テラコッタ | 向きを変更 |
| ウチワサンゴ | 床置き／壁付けを切替。壁付けの上下面は向きを変更 |
| 金床 | 上面で損傷段階、他面で向きを変更 |
| カボチャ | 通常のカボチャは側面でくり抜く。くり抜き・ランタンは正面で素材を変更、それ以外で向き |
| キノコブロック・鉄格子・コーラスプラント | クリックした面の接続・表示を切替 |

材質だけを切り替えられるものもあります。草ブロック／土の道、土→粗い土→根付いた土、ネザースプラウト／歪んだ根、ツツジや葉の開花、アメジスト／芽生えたアメジスト、黒曜石／泣く黒曜石、アメジストの芽の大きさ、昆布やねじれ・しだれツタの先端／茎、タンポポ／金のタンポポ、アイブロッサムの開閉、スポンジの乾湿、フロッグライトの3色に対応します。海草は上面で背の低い／高い状態を切り替えます。専用操作がない場合は、対応する成長・点灯・通電・水量のうち1項目だけを変更します。

## 編集棒を使う

コマンドで棒を受け取るか、手持ちアイテムを編集棒にします。

| 操作 | 使い方 |
|---|---|
| Hand 編集棒 | `/ds stick` で受け取る。対応ブロックを右クリックして状態を編集 |
| シンプル棒 | `/ds sstick` で受け取る。壁・フェンス・板ガラスや対応するフルブロック／ハーフブロック／階段を、右クリックで追加、左クリックで削除 |
| ホールド棒 | `/ds hstick` で受け取る。対応ブロックを右クリック長押ししながら視点を動かして形を編集 |

`/ds stick set`、`/ds sstick set`、`/ds hstick set` は、メインハンドのアイテムに編集道具の種類の印を付けます。ホールド棒の長押し用の性質は追加しないため、元から長押し使用できないアイテムでは通常発行のホールド棒と同じようには使えません。手に何も持っていない場合は設定できません。

視線の先のブロックを対象にします。対象までの距離は6ブロックで、クリックしたブロックと視線の先が違う場合は編集されません。対応していないブロックや形では、変化しないことがあります。

編集道具をメインハンドに持っている間はブロックを壊せません。道具として印を付けた食べ物も食べられません。

ホールド棒の対象はフェンス・板ガラス・ハーフ・壁・階段です。同じブロックを複数の人が同時に編集できません。使用終了、持ち替え、手の交換、ログアウト、開始時の目の位置から0.5ブロック以上の移動、対象の外部変更、利用許可の喪失、視線の大幅な変更などで終了します。

| ホールド対象 | 視点を動かす操作 |
|---|---|
| フェンス・板ガラス | 選んだ接続を外へ引いて追加、内へ押して削除 |
| 壁 | 支柱を掴んで上下に動かすと支柱の有無。腕は外へ引くと低く、上で高く、下で低く、内へ押すと削除。支柱から横へ引くと腕の操作へ移る |
| ハーフ | 側面から上下へ動かすと上付き／下付き。下付きの上面を上へ引く、または上付きの下面を下へ引くと2段にする。2段の上面を下へ動かすと下付き、下面を上へ動かすと上付き |
| 階段 | 縦に動かすと上付き／下付き、横に動かすと角の形と向きを変更 |

形が変わる目安は視点から投影した移動量0.25ブロックです。

## 素材を置き換える

`/ds replace on`（短縮形 `/dsr on`）で有効にし、ブロック素材を持って、しゃがまずに対象を右クリックします。対象ブロックの素材が手持ちの素材に変わります。`off` で停止、`toggle` で切り替えます。

置換の形の合わせ方は `/ds replace type` で順に切り替えます。値を直接指定することもできます。

| 値 | 動作 |
|---|---|
| `off` | 同じ形の別素材を探す機能を使わず、手持ち素材へ置換 |
| `strict` | 対応する同じ形の素材を選び、引き継げる状態を残す |
| `compatible` | `strict` に加えて、対応する壁・フェンス・板ガラス間の置換を行う |

例: `/ds replace type strict`。モードは `off` → `strict` → `compatible` → `off` の順です。置換先が対応する形に見つからない場合は、手持ち素材への通常置換になります。

置換先として選ばれた素材が今と同じなら、状態も変更しません。形の検索に成功し、同じ素材の相方があるドア・ベッドだけは2ブロック一緒に置換します。通常置換や通常置換へのフォールバックでは、クリックした1ブロックだけです。Replace が OFF または一括停止中なら、形の設定が `strict`／`compatible` でも置換は動きません。

素手・編集棒・素材置換による直接編集は素材を消費しません。置換で持っているブロックも減りません。これらにはサバイバル／クリエイティブ限定の制限がありません。

## 更新抑制を使う

`/ds update on`（短縮形 `/dsu on`）で個人設定を有効にします。`off` で個人設定を停止、`toggle` で切り替えます。場所に設定された更新抑制は、個人設定 OFF や一括停止でも有効です。

編集や配置の直後に、対象の周囲で起きる一部の物理・ブロック更新を短時間抑えます。ワールド全体や長時間の更新を止める機能ではありません。有効な間は通常操作も変わります。

- 支持がなく通常は置けない一部のブロックを配置できます。この強制配置はサバイバル／クリエイティブ限定で、サバイバルではアイテムを1個消費します。
- 看板を置いた直後の文字編集画面は開きません。
- 感圧板・トリップワイヤーの作動や耕地の踏み荒らしなど、足で踏む操作を拒否します。
- レバー・ボタン・ドアなどは周辺更新なしで切り替えます。アイテムを持ってしゃがんでいる場合や他の編集が優先される場合は対象外です。ボタンは木製30tick、その他20tick後に戻ります（途中で状態が変われば戻しません）。
- ベッドの片側を壊すと、消えた相方だけを次tickに復元します。
- 自分が起こす振動や TNT 着火も抑えます。これらは編集直後の短時間ガードがない場合でも有効です。

## 困ったとき

| 表示 | 意味 |
|---|---|
| `権限がありません。` | そのコマンドを使う許可がありません。使いたい機能をサーバー運営に伝えてください。 |
| `権限が必要です` | 持っている編集棒を使う許可がありません。 |
| `インベントリに空きを作ってください。` | 編集棒を受け取る空き枠がありません。 |
| `手にアイテムを持ってください。` | `set` を使う前に、メインハンドへアイテムを持ってください。 |
| `他のプレイヤーが編集中です` | そのブロックは別の人がホールド棒で編集中です。終わるまで待ってください。 |
| `つかんだ` | ホールド棒で編集を開始しました。使用を続けて視点を動かしてください。 |
| `Hand: ON` / `Hand: OFF` | 素手編集の設定状態です。 |
| `更新抑制: ON` / `更新抑制: OFF` | 個人の更新抑制設定の状態です。 |
| `DSを無効化しました。` / `DSを有効化しました。` | 素手編集・個人の更新抑制・素材置換の一括停止状態です。場所の更新抑制は対象外です。 |
| `Replace: ON/OFF` と `Type : ...`（末尾に `(inactive)`） | 置換と形の設定。`inactive` は Replace OFF または一括停止中を示し、故障ではありません。 |
| `素材置換:` のあとに素材名 | 置換後の素材です。 |
| `階段: ...`、`壁: ...`、`フェンス: ...`、`ガラス板: ...`、`ハーフブロック: ...`、`ブロック: ...` | 編集後の状態を示す表示です。エラーではありません。 |

状態表示が出ても、対応外のブロック、視線の届かないブロック、または一括停止中では編集されないことがあります。モード、持ち物、しゃがみ状態、対象までの距離を確認してください。
