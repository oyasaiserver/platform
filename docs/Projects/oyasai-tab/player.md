# OyasaiTab の見え方（プレイヤー向け）

OyasaiTab にコマンドはありません。チャットにも何も出ません。タブリストと頭上の名前が自動で変わるので、操作は要りません。

**サーバーによって見え方が違います。** 下の装飾（ヘッダー・フッター、名前の飾り、頭上のレベル）が出るのは、必要な機能がそろったサーバーだけです。ロビーなど装飾の出ないサーバーでは、自分のサーバーの人は素の名前で表示され、別サーバーの人だけが下で説明するようにサーバー名つきで出ます。

## タブリスト（Tab キーの一覧）

- **上部（ヘッダー）:** `OYASAI SERVER` と Minecraft のバージョン。その下に、**あなたの Likes**（もらった数）が出ます。
- **下部（フッター）:** **あなたの所持金**（¥）と**トークン**（P）、**今いるサーバーの**オンライン人数（別サーバーの人は数えません）、TPS（サーバーの処理の速さ。上限 20）、全員の Likes 合計、SLIDs（建築数）の合計。
- **並び順:**
  - 同じサーバーの人は、グループの順（運営が決めた順）→ 名前順。
  - 離席中（AFK）の人は、同じサーバーの人の中で一番下に来ます。
  - 別サーバーの人は、同じサーバーの人の下にまとまって並びます（サーバー名順 → 名前順）。装飾の出ないサーバーでは、別サーバーの人が上に来ることがあります（未確認）。
- **名前の表示:** グループの色つきの `*`、称号、`<数字>`（その人の Likes）、名前の順です。
  - 色つきの `*` は、色の設定があるグループだけに付きます。
  - 別サーバーの人は、Likes の代わりに `<Lobby>` のようにサーバー名が出ます。その人のいるサーバーで装飾が出ていなければ、名前は素のままです。
  - AFK の人は名前が灰色になり、後ろに `[AFK]` が付きます。別サーバーの人も同じです。
- **ping:** 同じサーバーの人の名前の横に ping の数字が出るように作られています。別サーバーの人には数字が付かない作りです（どちらもゲーム内では未確認）。

表示は約 1 秒ごとに更新されます。所持金やトークン、Likes の変化も約 1 秒で反映されます。

## 頭上の名前（名前タグ）

- 同じサーバーの人の頭上に、`[Lv.数字]`（レベル）、色つきの `*`、称号が出ます。グループによって `*` の位置が違ったり、`*` が付かなかったりします。
- 案内人のグループは `【案内人】` とだけ表示され、レベルと称号は出ません。
- 別サーバーの人の頭上には、この表示は出ません（タブリストだけが別サーバーの人を表示します）。
- 他の機能（ミニゲームのチームなど）に入っている間は、頭上の名前は OyasaiTab では変わりません。

## 別サーバーに移った直後

移動した直後は、タブリストの一覧が一瞬ずれたり、別サーバーの人が一度消えたりすることがあります。少し待つと元に戻ります（コードでは移動後に一覧を組み直しています。実機での確認は未実施です）。

## 困ったときの表示の意味

| 見え方 | 意味 |
|---|---|
| `<Lobby>` のようにサーバー名が付いている | 別サーバーにいる人です。Likes は表示されません |
| 名前が灰色で、後ろに `[AFK]` が付いている | 離席中の扱いです |
| 名前が素のままで、`*` や `<数字>` がない。ヘッダー・フッターも出ていない | このサーバーでは装飾が出ません。いつもは出るサーバーで急にこうなったときは、運営に連絡してください |
| 頭上に `[Lv.数字]` が出ない | 上と同じか、他の機能のチームに入っています |
