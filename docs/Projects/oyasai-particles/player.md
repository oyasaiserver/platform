# OyasaiParticles の使い方（プレイヤー向け）

建築の周りに、**入った人だけに見える**桜吹雪や疑似的な雨・雪、夕暮れや星空、環境音を付けられる機能です。
ブロックを置かないため、建築の見た目を壊さずに演出を追加できます。また、ワールドが雨や雷雨のときでも、エリアの中は設定した天候だけで過ごせます。

## 基本の流れ（パーティクルアイテムを使う場合）

1. **ワンドを用意する**: `/opart wand` で「パーティクル範囲指定ワンド（専用のブレイズロッド）」を受け取ります。
2. **範囲を決める**:
   - **左クリック（ブロック）**: Pos1（円柱モードでは中心）を指定
   - **右クリック（ブロック）**: Pos2（円柱モードでは半径・高さ）を指定
   - **Shift + 右クリック（空振り等）**: 四角（Box）と円柱（Cylinder）のモードを切り替え
   - コマンド `/opart shape <box|cylinder>`、`/opart radius <数値>`、`/opart height <minY> <maxY>` でも調整できます。
3. **空間に適用する**: 範囲を決めた状態で、イベント報酬やショップなどで手に入れた「パーティクルアイテム（染料など）」を持って **右クリック** すると、その空間にエリアが作られます。

## 範囲の確認・編集・回収

- **境界の可視化**:
  - ワンドを手に持っている間は、選択中の範囲と自分の周りのエリア枠・中心（白い光点）が自分だけに表示されます。
  - `/opart visualize` で、ワンドを持っていない間も常時可視化の ON/OFF を切り替えられます。
- **設定を変える・アイテムに戻す（回収）**:
  - 可視化中に、エリア中央の白いパーティクルを狙って **Shift + 右クリック** すると直接設定メニューが開きます。
  - `/opart list` から一覧を開いてエリアをクリックしても同じ設定メニューを開けます。
  - メニューでは **パーティクル・疑似天候（砂漠でも雨や雪が降ります）・個人時間（朝/昼/夕暮れ/夜）・環境音・密度・範囲更新** を一覧から選べます。
  - **「撤去してアイテムとして回収」** ボタンを 2 回クリックすると、エリアを消して元のパーティクルアイテムを手元に戻せます（インベントリに 1 枠以上空きが必要です）。

## 表示の ON/OFF（個人設定）

- `/opart toggle` — 自分に見えるパーティクル・疑似天候・個人時間・環境音をまとめて ON/OFF できます（他の人には影響しません）。

## コマンド一覧

| コマンド | 説明 |
|---|---|
| `/opart help` | コマンド一覧を表示 |
| `/opart toggle` | 自分への表示・演出の ON/OFF 切替 |
| `/opart wand` | 範囲指定ワンドを受け取る |
| `/opart shape <box\|cylinder>` | 選択形状を四角 / 円柱に切り替え |
| `/opart radius <数値>` | 円柱モードの半径を指定 |
| `/opart height <minY> <maxY>` | 円柱モードの高さを指定 |
| `/opart visualize` | エリア枠線の常時可視化を ON/OFF |
| `/opart list` | 自分のエリア一覧・設定・回収メニューを開く |
| `/opart edit <名前>` | 指定エリアの設定メニューを開く |
| `/opart remove <名前>` | 指定エリアを削除する（アイテムは戻りません） |
