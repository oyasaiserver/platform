# SocialVotes の使い方（プレイヤー向け）

看板を右クリックして投票数を加算するプラグインです。看板の登録、グループ分け、投票期間の設定、結果の確認もできます。投票は賛成・反対などを選ぶ方式ではなく、クリックごとに票数が増えます。

## 看板を登録する

1. 看板の1行目に `vote` と書きます（大文字・小文字は問いません）。
2. 2行目が看板名になります。
3. 看板を設置すると `SV看板を登録しました (ID:<番号>)` と表示されます。

登録した看板は、SocialVotes のロゴ、看板名、制作者、得票数を表示します。得票数が非公開の場合は看板に `Votes: 非公開` と表示されます。

## 投票する

登録看板を**メインハンドで右クリック**すると1票入ります。しゃがみながら右クリックすると投票せずに簡易GUIを開きます。オフハンドや左クリックでは投票されません。

- 看板の制作者は自分の看板に投票できません。
- 初期値は看板ごとに1票までです。グループに入っている看板では、グループ全体の上限も適用されます。運営が上限を変更している場合はその値が使われます。
- グループに開始・終了時刻がある場合、その期間中だけ投票できます。グループに属さない看板には期間制限がありません。
- 自分の票は簡易GUIからリセットできます。投票期間外はリセットできません。

投票できたときは `§a「<看板名>」(ID:<番号>)に投票しました！` と画面下部に表示されます。

## グループを作る・看板をまとめる

コマンドは `/sv` または `/socialvotes` で実行します。グループ名はコマンド内で1語として指定します。

| やりたいこと | コマンドと手順 |
|---|---|
| グループを作る | `/sv setgroup <グループ名>` |
| 看板をグループに追加 | `/sv add <グループ名>` → 登録済み看板をメインハンドで右クリック |
| 看板をグループから外す | `/sv remove` → 登録済み看板をメインハンドで右クリック |
| グループ一覧を見る | `/sv list` |
| グループ内の看板一覧を見る | `/sv list <グループ名>` |
| グループの投票を始める | `/sv startvote <グループ名>` |
| グループの投票を終える | `/sv stopvote <グループ名>` |
| 看板の場所へ移動する | `/svtp <看板ID>` |

グループを作った人はそのグループのオーナーです。看板の追加・除外、投票開始・終了はグループオーナーまたはOPが行えます。1グループに登録できる看板は45個までです。

追加・除外の操作待ちは、登録看板以外のブロックをメインハンドで右クリックすると解除されます。案内文には「看板以外をクリック」とありますが、実際にはブロックへの右クリックが操作のきっかけです。待ち時間による自動解除はありません。操作中に切断した場合、再接続後も状態が残る可能性があります。

`/sv startvote` は実行時刻から投票を開始します。将来の終了時刻が設定済みなら、その時刻は残ります。`/sv stopvote` は開始前には使えず、開始後に実行するとその時点で投票を終了します。

## 看板のGUI

登録看板をしゃがみながら右クリックすると簡易GUIが開きます。看板名、制作者、グループ、期間、自分の残り票などを確認できます。

- 制作者またはOPは、看板名と制作者表示を変更し、制作者を追加・削除できます。制作者は最低1人必要です。制作者表示を空欄で送信すると、登録された制作者名に戻ります。
- グループオーナーまたはOPは詳細設定を開き、看板・グループの得票表示、投票上限、開始・終了時刻を変更できます。
- グループの詳細設定から投票結果と投票者一覧を開けます。投票者一覧は45人ずつ表示し、投票数順・名前順にも並べ替えられます。
- 得票表示を非公開にすると看板上の得票行が非公開になります。結果GUIの閲覧可否はグループオーナーまたはOPの操作権限で決まります。

時刻は `2025y12M31d23h59min` のように入力します。日 (`d`) と時 (`h`) は必須で、月・年は省略すると現在の日本時間の値、分は省略すると0分です。`0` で開始時刻または終了時刻を解除できます。

## 困ったとき

| 表示 | 意味 |
|---|---|
| `自身が作成したSV看板には投票できません。` | 自分が制作者として登録されている看板には投票できません。 |
| `投票期間外です（開始前）` / `投票期間外です（終了）` | グループの投票開始前、または終了後です。 |
| `この看板への投票上限に到達しています` | この看板で設定された上限に達しています。 |
| `このグループでの投票上限に到達しています` | グループ内の上限に達しています。 |
| `この看板は既にグループに所属しています。` | グループ追加をしようとした看板は、すでに別のグループに所属しています。 |
| `45個を超えるため追加できません。` | グループ内の看板数が上限です。 |
| `グループが見つかりません。` | グループ名を確認してください。名前の大文字・小文字も区別されます。 |
| `この看板はグループに所属していません。` | グループから外す対象ではありません。 |
| `IDが無効です。` | `/svtp` に数字の看板IDを指定してください。 |
| `ID <番号> の看板は存在しません。` | そのIDの登録がありません。`/sv list` で一覧を確認してください。 |
| `ワールド <ワールド名> が読み込まれていません。` | 看板のあるワールドが利用できません。運営に連絡してください。 |
| `この操作はグループ作成者またはOPのみ可能です。` | グループオーナーまたはOPに操作を依頼してください。 |
| `§e<名前> は既に投票対象に含まれています。` | そのプレイヤーはすでに制作者として登録されています。 |
| `§c制作者は最低1人必要です。` | 最後の制作者は削除できません。 |
| `§cプレイヤー <名前> は存在しません。` | 入力したMCIDを解決できませんでした。 |
| `§c対象の看板が存在しません。` | 入力待ちの間に対象看板の登録がなくなりました。 |

`/sv help` で主なコマンドを確認できます。看板の移設、登録の削除、投票結果の全体リセットは運営に相談してください。
