# OyasaiFrames の使い方（プレイヤー向け）

画像を地図にして飾る、額縁を保護する、地図に絵を描く機能です。以下は実装からまとめた案内で、ゲーム内での確認はしていません。

## 画像を地図にする

<code>/tomap &lt;URL&gt; [resize [幅 高さ]]</code> に、画像の直接リンクを指定します。利用できる形式は PNG、JPEG、GIF、WebP です。URL は小文字の <code>http://</code> または <code>https://</code> で始めてください。画像ページでは取得できない場合があるため、画像ファイルの直接リンクを使ってください。

- <code>/tomap URL</code> は画像の縦横比に合わせて地図を並べます。
- <code>/tomap URL resize</code> は 1×1 枚に収めます。
- <code>/tomap URL resize 幅 高さ</code> は指定した列数・行数に収めます。幅と高さは正の数です。画像は枠内に収まるよう縮小・拡大され、縦横比は保たれます。

通常は、1画像あたり最大100枚の地図です。動く GIF は標準で最大16枚分の大きさ（横×縦の合計）、60コマ、作成に使う地図500枚です。1人が持てる動く画像の地図は合計2000枚で、一覧から隠した画像も数えます。サーバー側の設定や権限で上限が変わる場合があります。resize なしの大きな画像は地図枚数の上限に収まるよう自動縮小されます。resize で上限を超える枚数を指定すると拒否されます。動く GIF も同様です。取り込みに成功すると、ポスター用の地図が持ち物に入ります。持ち物に入らない分は足元に落ちます。

取得する画像ファイルは16 MiB以下にしてください。画像は縦横それぞれ8192ピクセル以下、総画素数2500万以下である必要があります。非公開ネットワークのアドレスや標準以外のポートへの接続は拒否されます。

近くにいる全員への動く画像地図の送信には、閲覧者ごとに接続中3000枚の上限があります。ログアウト、ワールド移動、リスポーンで送信状態がリセットされます。近くの誰かが地図を受け取っていない間は、ポスターが最初のコマのままになることがあります。

### 自分の画像を見る

<code>/tomap list</code> で画像一覧を開きます。

- 左クリックで画像を受け取ります。
- 右クリックで確認画面を開き、「非表示にする」を選ぶと自分の一覧から隠します。隠した画像をプレイヤー側から一覧へ戻す操作はありません。間違えて隠した場合は運営に相談してください。
- 一覧は1ページ45件です。前後のページへ移動できます。

<code>/tomap info</code> は、見ている額縁か手に持っている地図の情報を表示します。額縁を調べるときは5ブロック以内から見てください。

## ポスターを貼る・外す

1. 画像の地図を手に持ちます。
2. 貼りたい面の左下になるブロックを、その面を向いて右クリックします。壁・床・天井に貼れます。
3. ポスターの大きさ分、後ろに固いブロックがあり、前にブロックや額縁・絵画がない場所を選びます。

地図は消費しません。額縁を直接右クリックして貼ることはできません。チェストやドアなど右クリックで開くブロックに貼るときは、しゃがみながら右クリックしてください。貼ったポスターは透明な額縁に表示されます。

ポスターを見ながら <code>/tomap remove</code> を実行すると外せます。5ブロック以内から額縁を見てください。通常のポスター額縁は取り除かれ、額縁アイテムは返りません。旧版から引き継いだポスターは、画像だけ外れて額縁が残ることがあります。

- <code>/tomap glow</code> は、見ているポスターを普通の額縁・輝く額縁の間で切り替えます。
- <code>/tomap glow on</code> / <code>/tomap glow off</code> は、これから貼るポスターの額縁を選びます。切り替えは以降に貼るポスターに適用されます。

額縁ロックが有効な場合、貼った人がポスター額縁の持ち主になります。管理ポスターは持ち主でも通常の破壊では外せず、ロック解除後も同じです。外すには <code>/tomap remove</code> を使ってください。

remove と、見ているポスターへの glow は、対象として見つかった全額縁の条件を先に確認します。ロック済みなら自分が持ち主であること、ロックされていなければその場所に建築できることが必要です。自分のロックがある額縁では建築権限を確認しません。1枚でも条件を満たさないと操作全体が拒否されます。OP はこの所有者・建築条件を迂回できます。

## 額縁をロック・透明化する

額縁を置くと自動でロックされます。既に置かれた額縁をロックするときは、<code>/gakubuchilock on</code> を実行してから額縁を右クリックします。終わったら <code>/gakubuchilock off</code> を実行します。短縮形は <code>/glock</code> です。

自分がロックした額縁を解除するには、<code>/gakubuchiunlock on</code> の後に額縁を右クリックし、終わったら <code>/gakubuchiunlock off</code> を実行します。短縮形は <code>/gunlock</code> です。別の人がロックした額縁は解除できません。

- <code>/gakubuchitoumei on</code> の後に額縁を置くと、自動で透明になります。終了は <code>/gakubuchitoumei off</code> です。短縮形は <code>/gtoumei</code> です。
- <code>/gakubuchifinder</code> は近くの自分の透明なロック済み額縁を赤いパーティクルで10秒間示します。範囲の既定値は32ブロックです。<code>/gfinder 64</code> のように指定でき、範囲は1～100ブロックです。
- <code>/toumeigakubuti</code>（<code>/toumei</code>、<code>/invisibleframe</code>）は、見ている額縁の透明・表示を切り替えます。8ブロック以内の額縁が対象です。

ロックや透明化のモードはログアウトすると終了します。モードを切り替えるときは、前の操作が終わったことを表示で確認してください。

## 地図に絵を描く

お絵かき機能を使える場合は、<code>/painttools canvas</code> でキャンバス地図を作り、額縁に飾ります。持ち物に空きを作ってから実行してください。作成コマンドでは、持ち物に入らなかったキャンバス地図が返されません。

<code>/painttools dye</code> で染料一覧を開き、染料を手に持って額縁の地図を操作します。

- 額縁を右クリックすると、ブラシで描きます。初期サイズは2です。
- 額縁を左クリックすると、つながった同じ色の範囲を塗り替えます。
- しゃがみながら左クリックすると、離れた部分も含め、キャンバス全体の同じ色を置換します。染料・紙・羽根・イカスミ・砂糖で使えます。
- しゃがみながら染料で右クリックすると、キャンバス全体を塗ります。
- 紙は消しゴムです。羽根は色を指定するペン、イカスミは暗くする道具、砂糖は明るくする道具です。
- <code>/painttools brushsize 0</code> ～ <code>20</code> でブラシサイズを変えます。サイズ変更はプレイヤーごとにその場で有効になります。
- <code>/painttools undo</code> は約1分前、<code>/painttools undo 2</code> や <code>/painttools undo 3</code> は約2分前・約3分前のスナップショットへ戻します。額縁から8ブロック以内で実行してください。3回分のスナップショットが揃うまでは、1段階の Undo も使えず、表示も出ません。お絵かき機能の初期化後、最初は10秒後、以後60秒間隔で記録するため、サーバーが通常の速度で動作していれば約130秒後から使えます。対象キャンバスが記録時に読み込まれていなかった場合も戻せません。

染料一覧から取得した羽根を手に持って空中またはブロックを左クリックすると、色入力画面が開きます。色は <code>255,255,255</code> または <code>#FFFFFF</code> の形式で指定します。<code>1,1,1</code> / <code>#010101</code> は透明色として扱われます。染料起動用アイテムが登録済みなら、<code>/getdye</code> で受け取れます。また初回参加時にも自動配布されます。染料アイテムはクラフトに使えません。

| <code>外す権限がありません</code> | 対象の額縁に他人のロックがあるか、ロックのない額縁の場所に建築できません。運営または区域の管理者に確認してください。 |
| <code>画像の索引を読めません</code> / <code>額縁の記録を読めません: &lt;理由&gt;</code> | 画像または額縁の記録を読み込めませんでした。表示を運営に伝えてください。 |

額縁ロックやお絵かきのコマンドが使えない場合、または表示が上記と異なる場合は、その表示を運営に伝えてください。
