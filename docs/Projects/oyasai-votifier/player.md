# 投票について（プレイヤー向け）

投票サイトからサーバーに投票すると、投票した本人に報酬が届きます。
投票が一定数たまると「投票パーティ」になり、そのときオンラインの全員に報酬が配られます。

報酬の中身（お金・ポイントなど）と当たる確率、パーティに必要な投票数は、運営の設定で決まります。

## 投票するとき

- 投票サイトには、**Minecraft のユーザー名を正確に**入力してください。英数字と `_` だけの16文字以内の名前でないと、投票は受け付けられません。
- 投票した本人の報酬は、オフラインでも届けようとします。
- 「投票ありがとうございます」のお礼メッセージは、投票が届いた時点でオンラインのときだけ表示されます。

## 投票の通知

投票が届くと、チャットと画面下（アクションバー）に「〇〇さんが投票しました！(12/60)」のような通知が全員に出ます。
かっこ内は、いまの投票数とパーティに必要な数です。通知を出すかどうかは運営の設定によります。

## 投票パーティ

- 投票数が必要な数に届くと、「累計投票数が〇〇に達しました！」などの通知が出て、**その瞬間にオンラインのプレイヤー全員**に報酬が配られます。オフラインの人には配られません。
- 報酬は一人ずつ別々に抽選されます。人によって当たりが違うことがあります。
- パーティが始まると、投票数は0から数え直しになります。

プレイヤーが使えるコマンドはありません。いまの投票数は、投票時の通知で確認してください。

## 困ったとき

報酬が届かない場合は、投票したサイト、入力したユーザー名、投票した時刻を添えて運営に問い合わせてください。
