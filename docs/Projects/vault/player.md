# Vault の使い方（プレイヤー向け）

サーバーのお金（円）を管理する機能です。残高を見る、ほかの人に送金する、残高の多い順を見る、ができます。
ブロックや道具は扱いません。

## 最初の残高

初めてサーバーに参加すると口座が作られ、**¥10,240** が入ります。

- 経済の機能が止まっている間に初めて参加した人は、次に参加したときに口座が作られます。それまでの残高は ¥0 と表示されます。

## コマンド

| コマンド | 別名 | できること |
|---|---|---|
| `/balance` | `/bal`、`/ebal`、`/ebalance`、`/money`、`/emoney` | 自分の残高を見る。`/balance 名前` で他の人の残高を見る（見られるのは一部の人だけ） |
| `/pay 名前 金額` | `/epay` | 自分の残高から相手に送金する |
| `/balancetop [ページ]` | `/ebalancetop`、`/baltop`、`/ebaltop` | 残高の多い順を 10 人ずつ見る。ページは 1 から（数字でないときは 1 ページ目） |
| `/vault-info` | なし | お金の機能が使える状態か、だれでも見られる |

コマンドが使えるかどうかは、サーバーの権限設定で決まります。

## 送金する

`/pay Alice 1000` のように入力します。

**送金は確認なしで、すぐに確定します。取り消せません。**
成功すると「¥1,000 を送金しました。」と出ます。**受け取った人には何も表示されません。** 送ったことは自分で伝えてください。

- 金額は数字で入れます。`1,000` や `¥1,000` の形でも入力できます。
- 小数は四捨五入します（0.5 円は 1 円）。1 円未満は送れません。マイナスも送れません。
- 名前は大文字と小文字を区別しません。
- 自分あてには送れません。
- 相手がオフラインのときは送れません（一部の人だけは送れます）。
- 残高が足りないときは送れません（例外は運営が決めた一部の人だけです）。
- 相手の残高が上限（10,000,000,000,000 円）を超えるときは送れません。

## 残高と名前

- 残高は `¥10,240` の形で表示されます。マイナスの残高が出ることもあります（運営が認めた操作の結果など）。
- 名前は参加するたびに更新されます。
- 同じ名前の人が新しく参加すると、古い方の名前は外れます。名前が外れた口座は、ランキングで名前の代わりに英数字の ID が出ます。
- 同じ名前の口座が 2 つあると、その名前では残高を見ることも送金もできません。

## 困ったとき

| 表示 | 意味 | 対処 |
|---|---|---|
| 経済は現在利用できません。 | お金の機能が止まっています | しばらく待ってから、もう一度試してください。止まったままなら運営に連絡してください |
| `/pay <player> <amount>` | 書き方が違うか、金額に数字が入っていません | 名前と金額を 1 つずつ入れてください |
| 相手の口座がありません。 | その名前の口座が見つかりません | 相手が一度参加したか、名前の綴りを確かめてください。同じ名前の人がいる場合も見つかりません |
| オフラインの相手には送金できません。 | 相手がサーバーにいません | 相手が参加してから送ってください |
| 金額は 1 円以上にしてください。 | 0 円、マイナス、1 円未満の金額、または `1.2.3` のように数として読めない金額 | 1 円以上の金額を数字で入れてください |
| 送金に失敗しました。残高と上限を確認してください。 | 残高が足りない、自分あて、相手の上限超過、またはお金の機能が止まっている | 残高、宛先、相手の残高を確認してください |
| 権限がありません。 | ほかの人の残高を見る権限がありません | 自分の残高は `/balance` で見られます |
| プレイヤーが見つかりません。 | 名前の口座が見つかりません（`/balance` の場合） | 名前を確かめてください。同じ名前の人がいないかも確かめてください |
| ページは 1 以上にしてください。 | 0 やマイナスのページ番号 | 1 以上の数字を入れてください |
| Essentials の経済コマンドは使えません。 | `/essentials:pay` のように名前空間を付けて打った | `/pay` や `/balance` などの通常の名前で打ってください |
