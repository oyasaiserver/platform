# OyasaiGames の使い方（プレイヤー向け）

OyasaiGames には、建築アイテムルーレット、サイコロ、HeadHunt、PvP、BedWars、TNTRun、スロット、肝試し、武器や線香花火があります。使える機能や会場は運営の設定によって異なります。

## メニュー

`/games`（別名 `/og`・`/oyasaigames`）を使うとメニューを開けます。メニューからルーレット、サイコロ、HeadHunt の案内、BedWars の参加画面を開けます。ゲームごとのコマンドは下記を参照してください。

## 建築アイテムルーレット

1. `/roulette`（別名 `/oroulette`）か `/games` のメニューから開きます。
2. 「全建築用アイテム」「フルブロックのみ」「フルブロック以外」を選びます。
3. 抽選回数（1・3・5回）と、結果を全体に知らせるか自分だけにするかを選びます。初期選択は全建築用アイテム・1回・全体公開です。
4. 右下のトーチ「▶ ルーレットを回す！」を押します。

結果のブロックはチャットと画面に表示されます。チャットのブロック名をクリックするとIDをコピーできます。抽選はブロックを手に入れる機能ではなく、同じブロックが複数回選ばれることもあります。

- 画面を閉じても抽選は続きます。ログアウトすると進行中の抽選は止まります。
- 抽選中は次の抽選を始められません。完了後は通常10秒の待ち時間があります。
- 特殊ブロックがロック中と表示される場合、そのブロックは候補に入りません。

## おやさいサイコロ

`/dice`（別名 `/saikoro`・`/odice`）でサイコロを入手します。種類を指定する場合は `/dice get 2d6` のように入力します。使える種類は D2・D4・D6・D8・D10・D12・D20・D100、個数は1〜10個です。対応していない面数は D6 に置き換わり、読み取れた個数は残ります（例: `3d7` → 3D6）。形式を読み取れない指定は1D6になります。すでにサイコロを持っている場合、`/dice`・`/dice get` は追加配布せず手持ちのモードを変更します。

1. サイコロをメインの手に持ち、右クリックを長押しして投げる強さをためます。
2. 右クリックを離すか、最大までためると投げます。止まると出目が表示され、複数個なら合計も表示されます。
3. 投げたサイコロの近くで右クリックして回収します。止まってから15秒で自動回収され、投げ始めから25秒でも回収処理が行われます。

しゃがみながら右クリックすると、種類・個数・通知の公開/非公開を選べます。

- 1人が持てるサイコロは1個です。投げたものが戻るまでは新しいサイコロを入手できません。
- 投げた直後は2秒間再投擲できません。持ち替えや左クリックでためる操作が取り消されます。
- 公開通知は同じワールドの周囲30ブロック以内に届きます。非公開はチャット通知だけを本人に限定します。
- 他の人のサイコロは回収できません。持ち物が満杯なら入手・返却したサイコロは足元に落ちます。

## HeadHunt（頭ブロックの宝探し）

運営がイベントを開始したら、会場の宝HEADをメインの手で右クリックして探します。`/headhunt`（別名 `/hhunt`）で案内を見られます。`/headhunt team list` はチーム一覧、`/headhunt team info [チーム名]` は自分または指定チームの情報を表示します。

| 方式 | 勝利条件 |
|---|---|
| 個人戦 | 1人ですべての宝を見つける |
| チーム戦・共有 | チームで全ての宝を見つける。誰かが見つけた宝は共有される |
| チーム戦・個人発見 | 開始時のチームメンバー全員が、それぞれ全ての宝を見つける |

- 個人戦は参加登録なしで誰でも宝を探せます。チーム編成とゲームの進行は運営が管理し、開始後にチームの参加者を追加することはできません。最初に勝利条件を満たした人・チームが出るとイベントは終了します。
- 個人発見では、開始時メンバーがログアウトしてもその人の発見分が必要です。
- 宝HEADは通常のブロックのようには壊せません。チームと進行状況は再起動後に引き継がれません。

## PvP（アリーナ対戦）

1. `/pa list` で参加できるアリーナを確認します（別名 `/pvparena`・`/ogpa`）。
2. `/pa アリーナ名 [チーム名]` で参加します。チーム名を省略すると人数の少ないチームが選ばれます。
3. 会場でクラス選択が必要な場合は `/pa class クラス名`、準備完了は `/pa ready` を使います。会場のクラス看板や準備用ブロックから選べる場合もあります。
4. `/pa leave` で退出し、`/pa stats` で累積キル・死亡・勝利数を確認できます。

アリーナごとに勝敗条件、参加人数、途中参加、クラス変更、参加費や報酬が異なります。観戦は `/pa アリーナ名 spectate` です。参加・観戦中はコマンドや持ち物の操作が制限され、退出時に参加前の持ち物と状態へ戻ります。参加時はカーソルにアイテムを持たないでください。参加費は開始前の退出では返金され、開始後の通常退出では返金されません。

賭けが有効なアリーナでは、試合に出ていない人が `/pa アリーナ名 bet 対象 金額` を使えます。`/pa bet 対象 金額` でも受け付けますが、対象が複数の試合にいる場合はアリーナ名が必要です。受付時間と金額の制限があり、引き分けは返金、外れは払戻しなしです。当たりの配当は、賭けた金額に賭け金総額と設定された倍率を掛け、当たった人の賭け金総額で割り、端数を四捨五入して整数にします。倍率には小数も使えます。同じ試合で賭け直すと前の賭けは返金されます。

## BedWars

`/bw gui`（別名 `/bedwars`）または `/games` から参加画面を開きます。`/bw gui solo|double|triples|squads` でモードを選び、`/bw list` で会場を確認できます。`/bw join アリーナ名` または会場に設置された参加看板からも参加できます。アリーナ名は一覧に表示された名前を指定してください。

- 開始するとチームに自動で分かれます。鉄・金・ダイヤモンド・エメラルドを集め、店舗を右クリックするか `/bw shop`・`/bw upgrades` でアイテムやチーム強化を購入します。
- 資源不足、持ち物の空き不足、現在の装備より低い段階の商品では購入できません。quickbuy の枠を右クリックし、カテゴリ内の商品を選ぶと枠に登録できます。
- 自分のチームのベッドが残っていれば倒されても復活できます。ベッドが壊された後に倒されると観戦になります。最後まで残ったチームが勝ち、時間切れは引き分けです。
- 試合中のアリーナには、許可されている場合に観戦者として参加できます。`/bw leave` で参加前の持ち物と状態へ戻ります。
- `/bw rejoin` は退出・切断した試合が続いていて、自分のチームのベッドが残っている場合に使えます。試合中の持ち物は引き継ぎません。
- `/bw stats` は自分の統計、`/bw leaderboard` は得点上位10人を表示します。

パーティーが有効な場合は `/bwparty invite 名前` のあと、相手が `/bwparty accept リーダー名` を使います（別名 `/party`）。`/bwparty leave`・`kick 名前`・`disband` も使えます。招待の有効時間は運営設定によります（初期値60秒）。設定によってはリーダーの参加・退出にメンバーも同行します。試合参加中のリーダーが切断した場合も、同行設定が有効ならメンバーは試合から退出します。リーダーがパーティーを退出するとパーティーは解散します。

会場内のエンダーチェストは、初期設定ではチーム共有チェストになります。試合中の通常チャットはチーム内、観戦者のチャットは観戦者同士に届きます。先頭に `@a`（初期設定。運営が変更可能）を付けると試合の全員に届きます。`/shout メッセージ` は試合の全員に届き、初期設定では連続使用まで60秒待ちます。参加中は BedWars 関係以外のコマンドを使えません。

## TNTRun

1. `/tntrun list`（別名 `/tr`）で会場を確認します。
2. `/tntrun join アリーナ名` または参加看板を右クリックして参加します。アリーナ名は省略せず指定します。
3. 試合が始まると足元の床が消えていきます。落下、会場外への移動、致命的なダメージで脱落すると観戦になります。
4. `/tntrun leave` で退出し、`/tntrun stats` で参加数と勝利数を確認します。

最後の1人が勝者です。同時に最後の全員が脱落した場合と時間切れは引き分けです。参加費はなく、勝者へのお金・経験値の報酬は会場設定によります。

- 待機中の `/tntrun vote` で開始投票、`/tntrun shop` でダブルジャンプを購入できます。投票は同じ人が重ねて数えられません。所持できる未使用分は通常10回までで、使えばまた購入できます。地面にいるときにジャンプを続けて押すと使えます。未使用分は次の試合に持ち越されます。
- 待機中は投票・情報・ショップ・統計・退出用アイテムも使えます。
- パーティーが有効な場合、`/tntrun party create`・`invite 名前`・`accept リーダー名`・`decline リーダー名`・`kick 名前`・`unkick 名前`・`leave`・`info` を使えます。参加はリーダーが行い、メンバー全員が一緒に参加します。リーダー以外は単独で参加できません。ログアウトでパーティーを離れ、リーダーの退出で解散します。
- 参加中は持ち物を動かしたり、TNTRun 以外のコマンドを使ったりできません。退出時に持ち物と状態が戻り、場所は参加前または会場設定のロビーです。

## スロット

運営が設置した台や対象エンティティを右クリックし、画面のレバーを押します。料金は台に表示されます。台によっては景品一覧も開けます。

- 当選率・景品の重み・Luck/Unluck の影響は台によって異なります。重み0の景品は当たりません。景品一覧に表示される確率は運補正前です。
- 料金を払う前に、当たった景品を受け取れる空きを用意してください。
- 画面を閉じても抽選は続きます。同じ台の連打では二重に決済されません。接続された台は待ち時間を共有します。
- ログアウト・死亡・停止・処理失敗では返金を試みますが、結果が未確定のときは運営確認が必要です。

## 肝試し

開始前に `/joingame normal` で通常参加、`/joingame hunter` で鬼希望を予約します。`/leavegame` は開始前の予約を取り消します。開始には3〜10人が必要です。10人を超えて予約すると観戦者として登録され、鬼希望は鬼になる確約ではありません。

- 探索者は配られた地図の目的地を探します。正しい目的地に到着すると地図を1枚消費し、発見ポイントが1増えます。演出後に次の地図が配られます。場所が違うとダメージを受けます。
- 鬼は開始後30秒で出発します。探索者を捕まえるとキルポイントが3増えます。
- 致命的なダメージや途中ログアウトで探索者は脱落し、観戦者になります。ゲーム中に再接続した場合も、脱落済みなら観戦者として戻ります。
- 制限時間は15分です。時間切れは探索者の勝ち、探索者の全滅は鬼の勝ちです。
- 走る・跳ぶとスタミナが減ります。「[スタミナ切れ]」「[スタミナ回復中]」「[スタミナ全回復]」の表示を見て休んでください。同じ役割の味方の近くでは体力が少しずつ回復します。
- `/points` で現在の発見・キルポイントと累計イベントポイントを確認できます。終了時に今回分が累計へ加算されます。「獲得報酬 (狐火)」は表示のみで、狐火アイテムは配布されません。

終了時はゲーム用ロビーへ移動し、持ち物・ゲームモード・体力・満腹度・経験値が復元されます。元の場所や状態効果がそのまま復元されるわけではありません。

## 武器・生活アイテム

運営から渡された武器を使います。射撃・スコープ切替の操作は武器ごとに異なります。装填できる武器は、持ち物画面を閉じて Q キー（ドロップ操作）で装填します。装填中は名前の末尾に `ᴿ`、残弾は `«数字»` で表示されます。持ち替え・持ち物画面の操作・死亡などで、連射や装填が取り消される場合があります。

運営が用意した `[CS]番号` の看板を右クリックすると、指定アイテムを支払って武器を買えます。クリエイティブ以外で、支払いアイテムと持ち物の空き枠が必要です。

線香花火は右クリックで着火します。持ち替えると「線香花火の火が消えました。」、時間切れでは「ぽとっ... 火の玉が落ちてしまった。」と表示されます。使ってもアイテムは減りません。「自決用ナイフ」を右クリックすると死亡します。

## 困ったとき

表示には色やゲーム名の接頭辞が付くことがあります。数字や名前を含む文言は、その時点の値に置き換わります。

| 表示 | 意味・対応 |
|---|---|
| `現在、あなたの抽選タスクが実行中です。完了をお待ちください。` | ルーレットが終わるまで待ちます。 |
| `クールダウン中です。あと N 秒お待ちください。` | ルーレットの待ち時間が終わるまで待ちます。 |
| `エラー: 抽選対象のブロックが登録されていません。` | 抽選候補がありません。運営へ連絡してください。 |
| `このサイコロは他のプレイヤーのものです。` | 持ち主だけが回収できます。 |
| `この宝HEADは登録情報と一致しません。管理者に連絡してください。` | 宝の登録に問題があります。運営へ連絡してください。 |
| `宝HEAD情報の保存に失敗しました。管理者に連絡してください。` | 宝の変更を保存できませんでした。運営へ連絡してください。 |
| `PvP は無効です。` / `BedWars は無効です。` / `TNTRun は無効です。` | その機能は現在利用できません。起動時から無効な場合は、この表示ではなくコマンドの使い方だけが出る場合があります。 |
| `ルーレットは無効です。` | メニューからルーレットを開けません。 |
| `BedWars: 有効な招待がありません` | 招待が期限切れ、取り消し済み、または相手の指定が違います。 |
| `前回ゲームの復元処理が完了していません。再接続するか管理者に連絡してください。` | 肝試しの前回データ復元が完了していません。再接続するか運営へ連絡してください。 |
| `PvP の復元が未完了です。管理者に連絡してください。` / `持ち物の復元が未完了です。管理者に連絡してください。` | 参加前の持ち物や状態を戻せていません。復元でエラーが起きると切断され、再接続でも解消しなければ再び切断されます。運営へ連絡してください。 |
| `TNTRun の復元が未完了です。管理者に連絡してください。` / `BedWars の持ち物復元が未完了です。再接続してください。` | 持ち物の復元が終わらず切断されました。再接続で復元を再試行します。繰り返す場合は運営へ連絡してください。 |
| `未解決の取引があります。管理者に連絡してください。` | スロットの前回取引が未解決です。運営へ連絡してください。 |
| `取引の照合が必要です` | TNTRun の取引確認が必要です。運営へ連絡してください。 |
| `先に /tntrun leave で退出してください。` | TNTRun 参加中は他のコマンドを使えません。先に退出します。 |
| `権限がありません` / `この台を使う権限がありません。` | 利用が許可されていません。運営へ相談してください。 |
