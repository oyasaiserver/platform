# DynamicProfile の使い方（プレイヤー向け）

プロフィール、レベル、称号を見たり、自分の SocialLikes3 建築をおすすめとして登録したりできます。他のプレイヤーのプロフィールから、送金・テレポート申請・プレゼントもできます。

## コマンド

| やりたいこと | コマンド |
|---|---|
| 自分のプロフィールを開く | `/dp`（別名 `/dprofile`・`/dpr`・`/dpro`） |
| 他の人のプロフィールを開く | `/dp <プレイヤー名>` |
| リーダーボードを見る | `/dpl [種類] [ページ]`（別名 `/dpleaderboard`） |
| 週間リーダーボードを見る | `/dpwl [種類] [ページ]`（別名 `/dpweeklyleaderboard`） |
| おすすめ建築を登録する | `/dpsuki add <スロット番号> <建築ID>` |
| おすすめ建築を外す | `/dpsuki remove <スロット番号>` |

リーダーボードの種類は `level`（レベル）、`like`（いいねした回数）、`reclike`（いいねされた回数）、`chat`（チャット回数）、`move`（移動）、`playtime`（プレイ時間）です。種類を省略するとレベル順、ページを省略すると1ページ目を表示します。

`/dpwl` で期間内の値を表示するのは `like`・`reclike`・`chat`・`move` です。`move` は徒歩分だけで、飛行・乗り物は含みません。`level` は累積経験値順で現在レベルを表示し、`playtime` は Minecraft の累積プレイ時間を表示します。集計期間は運営が切り替えるため、暦の1週間とは限りません。

## プロフィールを見る・編集する

`/dp` を実行すると自分のプロフィールが開きます。プレイヤー名を付けるとその人のプロフィールが開きます。プロフィールの頭アイテムをクリックすると、紹介文などの概要と、経験値・移動・投票・いいねなどの数値表示が切り替わります。

自分のプロフィールでは、次の操作ができます。

### 称号を選ぶ

「称号設定」をクリックし、一覧から持っている称号を選びます。表示中の称号をもう一度クリックすると解除できます。称号の説明や所有者数も一覧に表示されます。

### 自己紹介を編集する

本のアイコンをクリックします。編集用の本がインベントリに入るので、文章を編集して閉じてください。更新に使われるのは1ページ目だけで、2ページ目以降は保存されません。署名しても変更を取り消す動作は保証されません。ゲーム内では「変更せず終了する場合は、署名してください」と案内されますが、キャンセル方法として使わないでください。編集用の本を受け取る空きが必要です。

### おすすめ建築を登録する

プロフィールの紙または看板のスロットを右クリックすると、自分の建築一覧が開きます。建築をクリックして登録します。

コマンドから登録する場合は、スロット番号を1～5、建築IDを数字で指定します。建築IDは SocialLikes3 に登録された自分の建築である必要があります。登録済みの看板はクリックでその場所へ移動できます。スロットを右クリックすると編集、Shift+右クリックで登録解除できます。

### レベルアップ通知を切り替える

ベルのアイコンをクリックすると、レベルアップ時のタイトル通知を切り替えます。新しいプロフィールでは通知がオンです。オフでもレベルアップのチャットと、運営が指定したレベルの全体通知は表示されます。この設定はレベルアップ時の効果音と、おすすめ建築の紹介時の効果音にも適用されます。

### レベル報酬を受け取る

チェストのアイコンから、受け取り可能な報酬を確認します。サーバーに報酬が設定されている場合だけ表示されます。クリエイティブまたはスペクテイターモードでは受け取れません。アイテムを受け取ると、インベントリに入りきらない分は足元に落ちます。

## 他の人のプロフィールからできること

相手のプロフィールに表示されるアイコンから、次の操作ができます。

- エメラルド: お金の送金額を決め、サーバーの `/pay` コマンドで送金します。
- ダイヤモンド: ポイントの送金額を決め、`/token send` コマンドを実行します。
- エンダーパール: 相手へ `/tpa` を送ります。相手が許可すると移動します。
- シュルカーボックス: 中身を入れて閉じると、相手へプレゼントします。送信時にシュルカー代100がかかります。相手がオンラインでない場合や支払いに失敗した場合は、アイテムが返されます。相手のインベントリが満杯なら、シュルカーボックスは相手の足元に落ちます。

これらの送金・テレポートはサーバー側の各コマンドやサービスを使います。相手のプロフィールには、公開されている数値、自己紹介、おすすめ建築なども表示されます。

サーバーからおすすめ建築が定期的に紹介されることがあります。紹介対象となるのは、おすすめを登録しているオンラインのプレイヤーです。案内のリンクをクリックすると、その建築へ移動します。

プロフィールの「ログイン日数」は暦日ごとの回数ではありません。通常は前回の加算から24時間以上たって参加したときに1回増えます。日付が変わっただけでは増えず、オンラインのまま日をまたいでも日ごとには増えません。昇格条件のログイン日数もこの値です。

## 制限

- おすすめ建築のスロットは5つです。指定できる番号は1～5です。
- おすすめに登録できるのは、存在する自分の SocialLikes3 建築です。
- プレイヤー選択画面に並ぶのはオンラインの人です。名前を指定してプロフィールを開くこともできます。
- `/dpsuki list` は入力候補に出る場合がありますが、一覧表示の処理はありません。実行すると使い方が表示されます。
- レベル報酬、送金、ポイント、テレポートはサーバー側の設定や連携先が必要です。

## 困ったとき

| 表示 | 意味・対応 |
|---|---|
| エラーが発生したため、あなたのDynamicProfileの情報が一時的に初期化されています。管理者に連絡してください。 | 以前のプロフィール情報を読み込めなかった通知です。運営に連絡してください。 |
| プレイヤーのみ実行可能です。 | `/dpsuki` はゲーム内のプレイヤー専用です。 |
| スロット番号は1～5で指定してください。 | 番号を1～5から選び直してください。 |
| 建築IDは数字で指定してください。 | SocialLikes3 の建築IDを数字で入力してください。 |
| ID <番号> の建築はあなたのものではありません。 | 自分が登録した建築IDを指定してください。 |
| ID <番号> の建築は存在しません。 | 建築IDを確認してください。 |
| インベントリに空きがないため、自己紹介編集用の本を開けません。 | アイテム欄を空けてから、もう一度プロフィールを開いてください。 |
| 相手がオンラインではありません！ | プレゼントを開始する相手がオンラインのときに試してください。 |
| 相手がオフラインです！ | プレゼントを閉じる前に相手がログアウトしました。アイテムは返却されます。 |
| 支払いに失敗したため、アイテムを返却しました。 | 支払いに失敗しました。アイテムを確認してから運営に相談してください。 |
| クリエイティブ状態だと受け取れません。（クリックしてサバイバルに変更） | サバイバルに変更してからレベル報酬を受け取ってください。 |
| 「（何だこのおっさん！？）」 | プロフィールを開いた名前のプレイヤーは、サーバーに参加した記録がありません。 |

自己紹介を編集したときは「自己紹介を更新しました。プロフィール画面で確認できます。」と表示されます。おすすめ登録が成功すると「スロット1 にID 123 を登録しました。」の形式で、解除すると「スロット1 を空にしました。」の形式で表示されます。
