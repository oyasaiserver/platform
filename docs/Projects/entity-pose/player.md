# EntityPose の使い方（プレイヤー向け）

EntityPose は、アーマースタンドなどの向き・姿勢・位置を調整し、選んだエンティティをまとめてコピー、貼り付け、削除する建築用の機能です。操作は `/ep` コマンドと、コマンドで受け取る2種類の道具から行います。

## コマンド

| やりたいこと | コマンド |
|---|---|
| コマンド一覧を見る | `/ep` |
| エンティティ棒を受け取る | `/ep stick`（`/ep st`） |
| Copy Wandを受け取る | `/ep wand`（`/ep wa`） |
| 視線の先の情報を見る | `/ep info`（`/ep in`） |
| 視線の先の設定を開く | `/ep infoset`（`/ep ins`） |
| スケールを指定する | `/ep scale 数値`（`/ep sc`） |
| 角度の刻みを指定する／選ぶ | `/ep kakudo 数値`（`/ep ka`）。数値を省略すると選択画面 |
| 移動量の刻みを指定する／選ぶ | `/ep zahyo 数値`（`/ep za`）。数値を省略すると選択画面 |
| コピー範囲を解除する | `/ep clear`（`/ep cl`） |
| 選択したエンティティをコピーする | `/ep copy`（`/ep co`） |
| コピーしたエンティティを貼り付ける | `/ep paste`（`/ep pa`） |
| 選択したエンティティを削除する | `/ep cut`（`/ep cu`） |
| 一時的な足場を使う／止める | `/ep hojo on`／`/ep hojo off`（`/ep ho`） |

## エンティティを出して調整する

1. `/ep stick` を実行し、受け取った「エンティティ棒」を手に持ちます。
2. ブロックを左クリックして、出したいエンティティを選ぶ画面を開きます。通常・小型のアーマースタンド、オオカミ、ネコ、ウサギ、オウム、馬、アレイを選べます。アーマースタンドの腕の有無や、動物の種類を選べる項目もあります。
3. 選んだエンティティが目の前に現れて視線についてきます。対象を確認して右クリックすると、その場に固定されます。追従中は別のエンティティを同時に出せません。追従を取り消すコマンドはなく、ログアウトしてもプレビューは消えずに配置された状態になります。
4. 固定したエンティティをエンティティ棒で左クリックすると、調整する部位・動作が切り替わります。しゃがみながら左クリックすると前の項目に戻ります。右クリックで1回分調整し、しゃがみながら右クリックすると逆方向へ動かします。

アーマースタンドでは、頭・胴体・腕・脚の軸ごとの角度、全体の向き、X/Y/Z座標を調整できます。アーマースタンド以外の生き物では、全体の向き、頭の向き、座る状態、X/Y/Z座標、上下反転を切り替えられます。座れない種類を選んだ場合は「このエンティティは座れません。残念;;」と表示されます。

角度の刻みは初期値が1度、移動量は1マスです。`/ep kakudo 数値` は0.5〜90度、`/ep zahyo 数値` は0.01〜2マスの範囲に収まる値になります。数値を省略して選択画面を開くと、角度は1・5・8・12・15・22.5・40・45度、移動量は0.1・0.25・0.5・1マスから選べます。どちらもログアウトすると初期値に戻ります。

上下反転をONにすると元の名前は置き換わり、OFFにしても元の名前は戻りません。

腕のあるアーマースタンドに左手装備を付けるには、エンティティ棒・Copy Wand以外のアイテムを手に持ち、しゃがんで右クリックします。使用を許可されていて、アイテムのロックがない場合に1個装着します。以前の左手装備は返却され、持ち物に入らない分は足元に落ちます。

**設置を確定した対象や貼り付けた対象は、死亡時に装備を含むドロップと経験値が消えます。** 装備を回収する場合は、死亡させる前に外してください。

### 道具のショートカット

| 道具・操作 | 結果 |
|---|---|
| エンティティ棒を持って持ち替え | 角度の刻みの選択画面 |
| エンティティ棒を持ってしゃがみ＋持ち替え | 移動量の選択画面 |
| エンティティ棒を捨てる操作 | 視線先の設定画面。棒は捨てない |
| エンティティ棒をしゃがんで捨てる操作 | 棒を実際に捨てる |
| Copy Wandを持って持ち替え | 両端が確定した範囲選択を解除。片端だけの場合は解除されないので `/ep clear` を使う |

道具を持つスロットへ切り替えると、視線の先約5ブロック以内の生き物が発光し、照準を外すと解除されます。他のプレイヤーにも見える発光で、元の発光状態は戻しません。複数人での操作や別の発光機能と干渉する場合があります。

## 情報と個別設定

- `/ep info` は、視線の先3ブロック以内にいるエンティティの種類、位置、向きなどを表示します。アーマースタンドでは部位ごとの角度や重力、底板、透明、アイテムのロックも表示します。
- `/ep infoset` は、視線の先のエンティティの設定画面を開きます。範囲選択中の対象を指して開くと、選択中のエンティティをまとめて設定する画面になります。
- 個別設定画面の対象は、画面を開いた時ではなく**設定項目をクリックした時点の視線の先**から選ばれます。画面を操作するときは、設定したい対象から照準を外さないでください。
- 設定画面では、ダメージ無効、透明、スケール、アレンジのロックを切り替えられます。アーマースタンドでは重力、底板、アイテムのロックも設定できます。動物など懐く種類では懐き状態を切り替えられます。
- `/ep scale 数値` は視線の先の生き物を指定値にします。範囲選択中の対象ならまとめて設定します。値は0.3〜3.0に収まり、小数第1位に丸められます。GUIのスケール設定は0.1ずつ増減します。

一括設定画面では、重力・底板・アイテムのロックは選択対象がすべてアーマースタンドの場合だけ表示され、懐きの一括設定はありません。ON/OFF項目は「全てONなら全てOFF、それ以外は全てON」に揃えます。スケールは各対象の現在値から増減します。

アレンジのロックは棒での選択・調整を止めますが、スケール、設定画面、コピー、削除は禁止しません。削除や設定変更を防ぐ保護としては使えません。

情報表示・スケールのコマンド実行時、設定画面を開く時、範囲選択では、プレイヤーとAIが有効なエンティティを選べません。個別設定画面のクリック時にはこの制限を再確認しないため、画面を開いた後も他のプレイヤーやAIが有効な対象へ照準を移さないでください。これらの受付時にAIが有効な対象を選ぶと「このエンティティはAIが有効です」と表示されます。

## 範囲を選んでコピー・貼り付け・削除する

1. `/ep wand` を実行し、受け取った「Entity Copy Wand」を手に持ちます。
2. 範囲の一方の端にいるエンティティを左クリックして `pos1`、もう一方を右クリックして `pos2` にします。両方を選ぶと、範囲内の対象数が表示され、対象の上に目印が出ます。順番はどちらからでも構いません。
3. `/ep copy` で選択中の対象をコピーします。
4. 貼り付けたい場所へ移動して `/ep paste` を実行します。エンティティ同士の位置関係を保って、今いるワールドに貼り付けます。何度でも実行でき、そのたびに複製が増えます。
5. 選択した対象を削除する場合は `/ep cut` を実行します。削除は取り消せません。範囲だけ解除する場合は `/ep clear` を実行します。

範囲に入るのは、プレイヤー以外の生き物でAIが無効なものです。選択範囲はエンティティの外枠を基準にします。ワールドを移動した後も範囲選択は自動解除されないため、別ワールドへ移る前に `/ep clear` を使ってください。ログアウトすると範囲選択は解除されます。`/ep clear` は範囲選択を解除しますが、コピー済みデータは消しません。

選択対象は両端を確定・取り直した時点の一覧です。コピー時に範囲を探し直しません。後から範囲へ入った対象は追加されず、範囲外へ移動しても有効な対象はコピーされます。

コピーと貼り付けの基準は、それぞれ実行時にプレイヤーがいるブロックの原点（X/Y/Zの整数座標）です。対象群の中心ではありません。プレイヤーの向きを変えても配置や向きは回転しません。

範囲内が0体でも選択状態になります。そのまま `/ep copy` を実行すると「0体のエンティティをコピーしました」と表示され、貼り付けても何も出ません。端点を取り直してください。

コピーでは位置・向き・一部の設定や、アーマースタンドの装備を引き継ぎます。通常の名前、動物の透明状態、年齢固定、懐いた動物の所有者は引き継ぎません。子供かどうかと懐き状態は引き継ぎますが、子オオカミ・子ネコを生成した時の年齢固定は貼り付けで復元されません。`/ep cut` はクリップボードを更新しないため、以前のコピーが残っていれば後から貼り付けられます。コピー内容はログアウトでは消えませんが、サーバー再起動で消えます。コピー前に範囲が正しいことを目印と表示数で確認してください。

## 一時的な足場

空中で作業する場合は `/ep hojo on` にします。エンティティ棒でエンティティを左クリックしたとき、足元の1ブロック下が空気で、近くに別のエンティティがいなければガラスが一時的に置かれます。プレイヤーが横に1.1ブロック以上離れるとガラスは空気に戻ります。使い終わったら `/ep hojo off` にしてください。OFFにしても、すでに置いたガラスは直ちに消えません。同じワールドで横へ離れ、消えたことを確認してください。プラグイン停止時にも一括撤去されないため、ガラスが残る可能性があります。初期状態はOFFです。ログアウトしてもONの状態が残る場合があるため、作業後にOFFに戻してください。
