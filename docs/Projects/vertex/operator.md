# Vertex の運用（運営向け）

プレイヤー向けの操作は [player.md](player.md)、内部の仕組みは [PROJECT.md](PROJECT.md) を参照。

schematic.cloud の配布 API からファイルを取得し、FastAsyncWorldEdit の保存先へ配置します。ロード・貼り付けは自動で実行しません。

## 権限

| 判定 | 既定・条件 | できること |
|---|---|---|
| OP | OP なら許可 | `/oyasai-schematics load` を実行する |
| `group.blue` | Vertex は既定値を宣言しない。付与・継承は権限管理側で設定する | OP でなくても同じコマンドを実行する |

- コードでは青匠以上に `group.blue` が継承されることを想定しています。実際の権限管理設定は未確認です。
- プレイヤー専用の判定はなく、コンソールも同じ条件で受け付けます。コンソールでの実行・クリック表示は未確認です。
- 権限はコマンド受付時にだけ確認します。取得中に権限を外しても、処理を取り消しません。
- ログアウトを理由に取得を取り消す処理もありません。送信者のオンライン状態を確認せず保存を進めます。退出後の結果メッセージの表示は未確認です。
- 権限不足では専用メッセージを送らず、コマンド処理は false を返します。ロード用コマンドの権限は別で、Vertex は検査しません。

## コマンド

| 操作 | コマンド |
|---|---|
| データをダウンロードする | `/oyasai-schematics load ID` |
| 配布 URL の末尾から ID を取り出してダウンロードする | `/oyasai-schematics load URL` |

運営専用の追加コマンド、一覧・削除・再読み込み・取消コマンドはありません。`load` は大文字・小文字を区別しません。追加引数は無視します。

引数なし・未知のサブコマンドでは案内を送らず終了します。ID なしでは false を返すだけです。URL の検証はせず、最後の `/` より後を ID として使います。末尾の `/` は空 ID になり、クエリ文字列なども取り除きません。指定された URL 自体へはアクセスせず、固定の配布 API に ID を渡します。

成功メッセージは「[oyasai-schematics] ダウンロード成功。このメッセージをクリックしてコマンドをコピー、実行してロードできます。」です。クリックで `/schematic load ID.schem` をコピーするだけで、ロードを実行するわけではありません。

## 設定と既定値

設定ファイルはありません。次はすべてコードに固定された値で、設定の編集では変えられません。

| 項目 | 値 |
|---|---|
| 取得先 | `https://api.schematic.cloud/download/<ID>` |
| 保存先 | `plugins/FastAsyncWorldEdit/schematics/`（サーバー作業ディレクトリ基準） |
| 最終ファイル名 | `<ID>.schem` |
| サイズ上限 | 32 MiB（33,554,432 バイト） |
| 接続タイムアウト | 10秒 |
| 読み取りタイムアウト | 30秒 |
| 受信ループの期限 | ストリーム処理開始前から60秒。読み取り前に検査するため、処理全体の厳密な60秒上限ではない |
| 同名ファイル | 上書きを試みる。既存ファイルを置換できるかは環境依存 |
| 同時実行数・実行間隔 | 制限なし |

`Secrets.kt` に環境変数を読むコードはありますが、現在のサービスからは使われていません。ダウンロード用の認証情報・API 切替設定はありません。

## データ保存と失敗時

- 保存先がなければ作成を試みます。Vertex 自身の DB・履歴・設定データはありません。
- 同じディレクトリの `download-*.part` に受信し、完了後に原子的な移動で `<ID>.schem` への保存を試みます。同じ ID の既存ファイルを置換するか移動が失敗するかは環境依存です。バックアップを作らず、同時取得も排除しません。
- 移動前に失敗した場合、既存の同名ファイルは置き換えません。原子的移動に対応しないファイルシステムでは失敗し、代替の移動は行いません。
- 一時ファイルは処理の最後に削除を試みます。削除失敗やプロセス終了では残る可能性があり、起動時の掃除はありません。移動後の削除で例外が起きた場合は、保存済みでも失敗として通知されます。
- 失敗時は「[oyasai-schematics] ダウンロードに失敗しました: 理由」と、warning `Schematic <ID> download failed: <理由>` が出ます。

| 理由 | 確認すること |
|---|---|
| `HTTP 数字` | 配布元の応答。HTTP 200 以外は失敗。期限切れ・存在しない ID の専用判定はない |
| `サイズ上限は 32 MiB です` | 配布元の Content-Length または実際の受信量が上限を超えていないか |
| `ダウンロードがタイムアウトしました` | 受信が時間内に進んだか |
| その他の例外理由 | 通信、ID、保存先の作成・書き込み・移動・一時ファイル削除の問題。理由は例外メッセージをそのまま表示する |

## 起動・移行・停止の注意

- FastAsyncWorldEdit は `softdepend` です。存在・有効状態を検査するコードはなく、未導入でもダウンロード先の作成を試みます。ロードできることまで確認してから案内してください。
- 起動時に同名の既存コマンドをコマンドマップから削除して登録します。他のプラグインが `oyasai-schematics` を登録している場合は影響します。
- 保存先は固定です。旧データの移行・ワールドの移行・整合性検査はありません。既存の同名ファイルも次の取得で上書き対象になります。
- 停止時にダウンロードの完了待ち・明示的な通信取消・巻き戻しは行いません。非同期処理終了時にプラグインが無効なら結果通知と失敗ログを登録しません。停止途中のファイルとタスクの実動作は未確認です。

## 守られるもの・守られないもの

- **制限する:** ダウンロードの受付権限、HTTP 応答、受信サイズ、通信待ち時間、完了前のファイルを最終名で公開しないこと。
- **制限しない:** schematic の内容・形式、ロード後のサイズや貼り付け範囲、建築編集コマンドの利用権限、ワールドの保護、同時取得。同じ ID の上書きを防ぐ仕組みもありません。
- ID の形式や URL の配布元を検証しません。配布された ID を使い、保存成功と建築データの安全性・正常性を同一視しないでください。

## 他のプラグインとの連携

- FastAsyncWorldEdit とは保存先と `/schematic load` のコピー用文字列だけで連携します。API を呼んでロード・貼り付けを行う処理はありません。
- 青匠以上の権限継承は LuckPerms を想定したコードコメントがありますが、LuckPerms API は使わず、Bukkit の権限判定だけを使います。実際のグループ構成は未確認です。
