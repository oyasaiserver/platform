# Vertex の使い方（プレイヤー向け）

schematic.cloud の配布 API で取得できる建築データ（schematic）を、サーバーへダウンロードする機能です。青匠以上、または管理者が使えます。
**ダウンロードしただけでは、建築はワールドに置かれません。**

## 建築データをダウンロードする

1. schematic.cloud の配布 API で取得できるデータの ID を用意する。
2. `/oyasai-schematics load ID` を打つ。ID の代わりに、最後が ID になっている配布 URL も指定できます。末尾に `/` や余分な文字を付けず、ID だけを指定してください。
3. 成功したら「[oyasai-schematics] ダウンロード成功。このメッセージをクリックしてコマンドをコピー、実行してロードできます。」と出ます。
4. メッセージをクリックすると `/schematic load ID.schem` がコピーされます。これを自分で実行してロードします。

URL を指定しても、最後の `/` より後を ID として使うだけです。任意サイトのファイル URL を直接ダウンロードする機能ではありません。

受付直後や取得中の表示はありません。成功・失敗の結果が出るまで待ってください。再実行すると別の取得処理が始まります。ログアウトによる取消は保証されません。

クリックだけではコマンドは実行されません。ロードは別の建築編集機能の操作で、そちらの利用権限も必要です。ワールドへの貼り付けは Vertex の機能に含まれません。

## 制限と注意

- ダウンロードできるサイズは32 MiBまでです。通信には時間制限があります。
- 保存先は全利用者・全ワールドで共通です。同じ ID の取得は同名データの上書きを試みますが、環境によって保存に失敗することがあります。他の人の取得も同じ保存先を使うため、自分の成功通知後に別の取得結果へ置き換わる可能性があります。
- 取得したデータがロードできる形式かどうかは、ダウンロード時には確認しません。成功表示が出ても、ロードできない場合があります。
- `load` の大文字・小文字は区別しません。ID を省略した場合、使えない人が実行した場合、別のサブコマンドを打った場合は、専用の説明が出ません。

## 困ったとき

失敗時は「[oyasai-schematics] ダウンロードに失敗しました: 理由」と表示されます。

| 理由・状態 | 意味 |
|---|---|
| `サイズ上限は 32 MiB です` | ファイルがサイズ上限を超えています |
| `ダウンロードがタイムアウトしました` | 受信処理の時間制限を超えました |
| `HTTP 数字` | 配布元がダウンロード成功の応答を返しませんでした。ID の間違い・期限切れなどを個別には判定しません |
| その他の理由付きエラー | 通信や保存などで失敗しています。表示された理由を運営に伝えてください |
| 何も表示されない | 正常に取得中でも表示はありません。結果を待ってください。コマンドが `/oyasai-schematics load ID` になっているかも確認し、利用資格については運営に確認してください |
| 成功したのにロードできない | 建築編集機能の利用権限や、データ形式に問題がないか運営に確認してください |
