# CitiesSkyMine の使い方（プレイヤー向け）

道路・交差点・外壁・窓・坂道・柱・群衆・雲・曲線を作る建築補助機能です。WorldEdit の選択範囲の保存、複製、ブラシの呼び出しもできます。使える機能は運営が決めます。

## 基本の操作

`/csm help` で一覧、`/csm help cloud` または `/.help cloud` で項目別のヘルプを見られます。ヘルプ項目は1つだけ指定します。`/csm version` はバージョン、`/csm info` は FAWE の検出結果を表示します。

| 機能 | コマンド | 短縮形 |
|---|---|---|
| 道路 | `/csm road` | `/.rc`、`/rc` |
| 交差点 | `/csm intersection` | `/.ri`、`/ri` |
| 外壁 | `/csm facade` | `/.hb`、`/hb` |
| 建物データの配置 | `/csm payload`（`/csm load`・`/csm load64` も可） | `/.pl` |
| 窓 | `/csm window` | `/.win` |
| 坂道 | `/csm slabstairs` | `/.ss` |
| 接続を全部外す | `/csm unconnect` | `/.unconnect` |
| 柱割り | `/csm columns` | `/.col` |
| 複製 | `/csm stack`（`/csm ns` も可） | `/.ns` |
| 群衆 | `/csm crowd` | `/.crowd` |
| 選択範囲の保存 | `/csm selection`（`/csm sel` も可） | `/.sel` |
| 個人設定 | `/csm settings` | `/.settings` |
| 雲 | `/csm cloud` | `/.cloud` |
| ベジェ曲線 | `/csm bezier` | `/.bez` |
| ブロックの状態変更 | `/csm debugstick` | `/.ds` |
| ブラシプリセット | `/csm preset` | `/.brp` |
| スキマティック貼り付け | `/csm schematic` | `/.sc` |
| WorldEdit の状態表示 | `/.hud` | — |
| 選択範囲のパーティクル表示 | `/.sui` | — |

**実ブロックの生成・複製は既存ブロックを上書きします。** 取り消しは `//undo` です。「FAWE undo 履歴への登録に失敗しました。」を含む警告が出た場合、生成は完了していますが取り消しの登録には失敗しています。
マネキンとデバッグ棒の変更は `//undo` の対象外です。選択範囲や個人設定の変更も、ブロックの取り消しでは戻りません。

## 道路・交差点・外壁

**道路:** メインハンドに骨を持ち、通したいブロックを順番に右クリックします。通過点はクリックしたブロックの1つ上です。2点目から自分にプレビューが表示されます。道路を使える人が骨を持って右クリックすると、ドアやチェストを開く操作も通過点の追加に置き換わります。開くときは別の物に持ち替えてください。

1. `/.rc set radius 30 lane 3 sidewalk 2` などで形を調整する。
2. `/.rc status` で設定を確認し、`/.rc build` で設置する。
3. 白線を階段素材にした場合は `/.rc smoothline` で向きを整える。
4. `/.rc reset` で通過点とプレビューを消す（設置済みの道路は消えない）。

設定名は `radius`（半径）、`transition`（緩和曲線長）、`lane`（片側車道幅）、`centerline`（中央白線幅）、`outerline`（外縁白線幅）、`sidewalk`（歩道幅）、`roadmat`・`sidewalkmat`・`linemat`（各素材）。半径は0より大きく1000以下です。複数の設定をまとめて指定でき、途中で入力を誤ると、その前に変更した値は作業中の設定にだけ残り、その入力では保存もプレビュー更新も行われません。再起動前に正しい設定を再入力してください。`centerline` に正の偶数を指定すると、断面の中央白線幅は1小さくなります（2なら1、4なら3）。`/.rc debugline on|off|toggle` は設置時の白線を色分けします。

**交差点:** 中心に立って `/.ri here` → `/.ri set arms 4 armlength 16 cornerradius 4` → `/.ri build`。`here` は向きを45度単位に丸めます。`rotation` で角度を指定できます。腕数は3〜6、長さは最低2、コーナー半径は最低0に補正されます。道幅・歩道幅・素材は道路の設定を共有します。`/.ri status` で確認できます。

**外壁:** 20ブロック以内の起点ブロックの面を見て `/.hb build 4 cream`。ベイ数は1〜40、色は `cream|grey|brown|red`、高さは34ブロック、幅は6×ベイ数+1です。見ているブロック自体を上書きし、その面に正対したときの右へ伸びます。起点の面から手前へ最大2ブロック、奥へ最大6ブロックまで使います。ベイ数の省略・数値でない入力は4、範囲外は範囲内に補正、未知の色は cream になります。
運営が用意した素材から作る場合は `/.hb schem full` または `/.hb schem 8 wide`。ベイ数は1〜60、パターンは `regular|wide|grand`（未知の値は regular）です。ベイ指定では高さ31、幅は regular が3×ベイ数、wide・grand が4×ベイ数です。full は固定の幅131・高さ39の範囲を読みます。どちらも起点から手前2〜奥20ブロックの範囲の空気以外を置きます。階段などの向きは回転しないので、見る面を変えてもブロックの向きは元の素材のままです。

道路の点・交差点の中心・曲線の点は再起動で消えます。別ワールドで作業するときは、道路を reset、交差点を here で設定し直してください。

## 窓を作って並べる

`/.win [幅] [高さ] [枠] [ガラス] [裏地]`。例: `/.win 2 3 OAK_TRAPDOOR GLASS`。

- 足元の1ブロック前を起点に、正面へ枠・ガラス・裏地の3層を作ります。幅と高さは1〜16ですが、既定の生成量上限は512です。3×幅×高さに周囲の空気の埋め対象も加えるため、16×16は必ず拒否されます。12×12なら周囲の埋めを含めても上限内です。
- 初回の既定は幅2・高さ3、鉄のトラップドア・白色の色付きガラス・乾燥昆布ブロックです。指定した寸法と素材は次回の省略値になります。
- 既定ではガラスの上下左右にある空気を滑らかなクォーツで埋め、生成範囲を選択します。左右の埋め部分は自動選択に含まれません。
- 選択後に `/.ns right 4` で横に4回複製できます。

## 坂道・柱・複製

これらは WorldEdit で **cuboid（直方体）を2点選択**して使います。

**坂道:** `/.ss stone_brick`（素材省略時は石レンガ）。`oak`、`quartz` など、ハーフ・階段・通常ブロックがそろう素材を指定します。ポイント1から2へ1列の坂を作り、緩い斜面はハーフと階段、急な斜面は通常ブロックと階段を組み合わせます。水平距離がない選択は使えません。選択の幅全体を坂で埋める操作ではありません。

**柱割り:** 手にブロックを持ち、`/.col 2 7 center -s` で太さ2・希望する柱間7の候補を確認します。`-s` を外すと最初の候補で設置します。ブロックを持っていない場合は石です。

- `edge`（既定）は端に柱、`center` は両端に余白を取ります。柱間は希望値なので、実際の間隔は候補の `gaps` を確認してください。
- `/.col 2 5 -p center` は本数5、`/.col 2 5x3 -p center 2d` は左右5本・奥行3本です。
- `2d` なしは奥行の中央に1列、ありは格子状です。左右・奥行は実行時の向きが基準で、高さは選択範囲全体です。
- 太さ・本数は1以上、柱間は0以上。左右・奥行の両方に太さが収まる必要があります。本数が収まらなければ生成できません。

**複製:** `/.ns <方向...> <回数> [上書きしないブロック...]`。

- `forward|back|left|right|up|down`（`f|b|l|r|u|d`）を組み合わせられます。`/.ns right up 2` は右上へ2回です。
- 通常は選択の寸法ずつ移動します。`/.ns f1 d2 5` は前1・下2ブロックずつ5回です。0以下の回数は1に補正されます。
- `/.ns f 4 -a` は **複製先が空気の場所を変更しません**。`water` などの追加指定も複製先の種類を判定します。コピー元の空気を除外する指定ではありません。
- コピー元と複製先が重なる小さな移動量では、途中で書き換えた内容を後のコピーが読むことがあります。

## 接続を全部外す

WorldEdit で直方体を選択し、`/csm unconnect` または `/.unconnect` を実行します。範囲内のフェンス・板ガラス・鉄格子・チョルスプラントの接続を全方向外し、壁は単独の柱の形にします。水没など他の状態は保持します。フェンスゲート・つる・キノコブロック・スカルクの脈は変更しません。

変更したブロック数を表示し、既に接続が外れているものは数えません。取り消しは `//undo`、説明は `/csm help unconnect` です。選択範囲が大きすぎる場合は、小さくして実行してください。
物理更新を起こさないため外した状態は保たれますが、隣のブロックを後から置く・壊すと接続が再計算され、また張り付くことがあります。

## 群衆を作る・消す

cuboid を選択し、`/.crowd density=0.12 seed=42`。選択の底面から、壁ブロック2段と頭で人を作ります。幅・奥行は各256以下です。地面や既存ブロックを避ける機能はありません。間隔や配置条件によって、実際の人数は指定密度から計算した目標より少なくなります。

| 指定 | 既定 | 範囲・意味 |
|---|---|---|
| `density` | 0.12 | 0.01〜1、目標密度 |
| `group` | 0.6 | 0〜3、グループ人数の抽選に使う値 |
| `stand` | 50 | 0〜100、複数人が立ち話配置になる割合 |
| `noise` | 0.6 | 0〜1、密度のむら |
| `scale` | 14 | 3〜48、むらの大きさ |
| `gap` | 1 | 0〜4、別グループとの間隔 |
| `fb` | 0 | 0〜100、前後向きの組の割合 |
| `forward` / `right` | 各50 | 0〜100、前後組の前向き／左右組の右向きの割合 |
| `jitter` | 15 | 0〜90、向きのばらつき（度） |
| `seed` | ランダム | 整数。同じ条件と値で配置を再現 |
| `mode` | `block` | `block` または `mannequin` |

`mode=mannequin` は人型のマネキンです。既定では1回の目標人数が300以下である必要があります。**マネキンは `//undo` で消えません。** 消したい範囲を高さも含めて選び、`/.crowd remove` を使います。他の人がこの機能で作ったマネキンも範囲内なら消します。ブロックの群衆は `//undo` で取り消します。ブロックの頭の見た目は運営が登録したものから選ばれ、登録がなければ既定のプレイヤーの頭になります。

## 雲・曲線・ブロックの状態

**雲:** `/.cloud [size] [height] [density] [seed] [yOffset]`。既定は `128 48 0.72`、seed はランダム、底面は足元から100上です。X/Z は自分の位置を中心とする正方形で、クモの巣を配置します。
size・height は1〜256、density は0.30〜0.95、seed は0〜10000000、yOffset は−256〜512。例: `/.cloud 128 16 0.50 2026 128`。同じ人の雲生成は同時に1つです。計算中にログアウトした場合は設置しません。

**曲線:** `/.bez add` で現在位置を点に追加し、2点以上で `/.bez preview on` → `/.bez build stone 3`（半径3）または `/.bez build flat gray_concrete 7`（幅7の1枚板）。素材省略時は手持ちブロック、半径の既定は0、flat の幅は5です。

- `preview on`・`build`・`status` は現在の WorldEdit 選択頂点を自動で読み込みます。完成した直方体選択があると、その頂点（通常4点で、高さも使う。重なる点は除く）で手動の点を置き換えます。手動の点を使う場合は、先に `//sel` で選択を解除してください。`/.bez fromsel` で明示的にも読み込めます。
- `/.bez set 2` は2番目を現在位置に更新、次の番号なら追加。最大32点です。`/.bez remove [番号]` は省略時に末尾を削除します。
- `/.bez plane on|off` で最初の点の高さにそろえます。`/.bez segments 64` は分割数（8〜256、既定64）。半径は0〜8、flat の幅は1〜64です。
- プレビューは実生成位置より上に表示します。`/.bez preview off` で止め、`/.bez clear` で点を消します。

**状態変更:** 対象を見て `/.ds select` で変更する項目を選び、`/.ds cycle` で次の値に進めます。既定の距離は6ブロックで、液体は対象を探す際に無視します。**`//undo` では戻りません。** 項目・値は画面下に表示されます。

## 選択範囲・ブラシ・表示の保存

**選択範囲:** `/.sel save road1` → `/.sel road1` で復元。`/.sel list` で一覧、`/.sel delete road1` で削除します。同じ保存名は上書きし、大文字・小文字は区別しません。英数字・`_`・`-` 以外は `_` に置き換わるため、名前が重なることがあります。`save`・`list`・`p` などの操作名は保存名に使わないでください。
直前の選択は約1秒ごとに記録され、`/.sel p` で戻せます。短時間に何度も変えた選択をすべて記録するわけではありません。直方体・多角形・凸多面体の保存に対応し、その他の選択は復元時に直方体になります。復元は移動ではありません。別ワールドの範囲を復元しても、その場所へテレポートしません。

**ブラシ:** `/.brp save stone "//br sphere -h andesite 3" -m ">0 smoothquartz"` → `/.brp stone`。`-m` はマスク、`-g` は全体マスクです。`/.brp list`・`/.brp delete stone` で管理します。
名前は英数字・`_`・`-` の1〜32文字で、大文字・小文字を区別せず上書きします。既定は20件、コマンドの合計200文字まで、呼び出し間隔は1秒です。省略したマスクは解除されず、現在のマスクが残ります。実行途中に失敗しても、先に変更したマスクは元に戻りません。

**個人設定:** `/.settings` のアイコンをクリックして道路・窓・交差点・建物配置・HUD・選択範囲表示を変更します。直接開く場合は `/.settings road|win|ri|pl`。**この画面には持ち物をドラッグしないでください。** 入れた物を取り出せず、画面の切り替えや終了で失うおそれがあります（実機での消失は未確認）。

**HUD:** `/.hud on|off`、`/.hud sel on|off`、`/.hud width 40`（8〜96文字、`reset` で既定幅）。引数なしは状態確認で、既定は off です。on にするとサイドバーを置き換え、他の表示が隠れることがあります。全体マスク、手持ちツール・ブラシ、選択範囲をサイドバーに表示します。
「設定済み」は詳細文字列を特定できない設定、「(前回設定)」は保存した表示と現在の種類が異なる状態、「Gマスク: 状態不明」は状態を読めなかった意味です。表示が前回の文字列でも、実際の設定と同一とは限りません。`/.sel` の復元や窓生成による自動選択の直後は、HUD がすぐに更新されないことがあります。

**選択範囲の輪郭:** `/.sui on|off`（引数なしは状態確認）。既定は on。直方体だけに表示され、既定では体積10000000を超える選択、高い ping、輪郭から遠い場所では表示されないことがあります。

## スキマティック・建物データを配置する

**スキマティック:** `/.sc bench` または `/.sc bench -a`。WorldEdit の保存先にあるスキマティック名を指定します。保存先は運営の設定により自分専用か共通で、共通なら他の人の保存したものも対象です。足元の1ブロック前にスキマティックの原点を合わせ、向きを90度単位に丸めて貼ります（南向きが無回転）。原点は建物の角とは限らず、コピー時の立ち位置など保存された原点によって建物の位置が変わります。`-a` は **コピー元の空気を貼らない**指定です。エンティティ・バイオームは貼りません。`/.sc list` で一覧、`/.sc reload` は保存先の確認です。自分の貼り付けが実行中なら拒否されます。完了後に自分で再実行してください。読み込み後の確認時にログアウトしていれば貼り付けませんが、貼り付け開始後のログアウトは取り消しになりません。

**建物データ:** `/.pl load <payload> [0-3] [L|R] [hollow|solid]`。Base64 専用は `/.pl load64`。足元の高さと向きを基準に、建物の手前端を1ブロック前に合わせます。回転は90度単位、L は建物の左端を自分の位置に合わせて右へ、R は右端を合わせて左へ広げる指定です。`1L`・`L1` のようにも書けます。同じ種類の指定を重ねると拒否されます。既定は回転0・R・hollow、実行時の指定は次回の省略値になります。
hollow は内部と床の内側を省き、外壁と1段下げた屋根床を置きます。既存の内部ブロックを空気で消す機能ではありません。

長いデータは全片を登録してから実行します。

```text
/.pl p building1 1/2 <前半>
/.pl p building1 2/2 <後半>
/.pl r building1 1 L hollow
/.pl clear building1
```

ID は32文字以内の文字・数字・`_`・`-`、最大512片、結合後200000文字までです。同じ番号は上書きできますが、同じIDで総数を変えると拒否されます。**最初の登録から10分を超えると期限切れ**になり、追加登録でも延長されません。実行後もデータは残るため、もう一度 run すると再配置します。再起動では消えます。`clear` のID省略は自分の全データを削除します。

## 困ったとき

文言は接頭辞・色を除いて記載しています。件数・名前・理由の部分は実行ごとに変わります。

| 表示 | 意味・対応 |
|---|---|
| このコマンドを使用する権限がありません。 / このHUDを使用する権限がありません。 | 運営に利用を相談してください |
| WorldEdit で範囲を2点選択してから実行してください。 | 選択が未完成です |
| stack は cuboid 選択にだけ対応しています。 / 柱生成は cuboid 選択にだけ対応しています。 / 群衆生成は cuboid 選択にだけ対応しています。 / SlabStairs は cuboid 選択にだけ対応しています。 | 直方体の選択に切り替え、2点を選び直してください |
| ポイント1からポイント2までに水平距離がありません。 | 坂道の始点と終点のX/Zが同じです |
| 手持ちに配置可能なブロックを持つか、material を指定してください。 | 曲線の素材を選んでください |
| 雲生成が既に実行中です。完了まで待ってください。 | 同時に雲を生成できません |
| 少し待ってから再実行してください。 | ブラシ呼び出しの間隔が短すぎます |
| デバッグ棒互換コマンドは無効です。 / クリエイティブモードでのみ使用できます。 | 運営の利用条件に従ってください |
| 対象ブロックが見つかりません。 | 状態変更の対象に近づいて見直してください |
| 保存済みコマンドが現在の許可リストに一致しません。 | 保存済みブラシが現在は利用できません。運営に確認してください |

「生成ブロック数が上限 (…) を超えています: …」「計算ボリュームが上限 (…) を超えています: …」などは、生成量が大きすぎる意味です。範囲や寸法を小さくしてください。
「分割payload … は未完了です。未受信: …」は不足片の登録、「分割payload … が見つかりません。」はIDの確認と期限切れ後の再登録が必要です。
「保存先ワールドが見つかりません: …」は範囲を保存したワールドが見つからない意味です。
「配置に失敗しました: …」などの失敗表示だけでは、変更が全くなかったとは判断できません。周囲のブロックと取り消しの可否を確認して運営へ伝えてください。
