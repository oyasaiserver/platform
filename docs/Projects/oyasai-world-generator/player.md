# OyasaiWorldGenerator の使い方（プレイヤー向け）

展示用のボイドワールドやスーパーフラットワールドへの移動と、設定されたポータルの利用ができます。ワールドの作成やポータルの設定は運営が行います。

## ワールドへ移動する

- `/owg tp [ワールド名]` — 高さを管理するワールドへ移動します。名前を省略すると、運営が設定した対象の先頭へ移動します。移動に成功すると、そのワールド用のゲームモードと飛行設定が適用されます。
- `/mvtp <ワールド名>` — 通常ワールドと高さを管理するワールドへ移動します。このコマンドが使えるサーバーでは、通常ワールドは保存済みスポーン地点（未設定ならワールドのスポーン地点）、高さを管理するワールドは`(0.5, 運営が設定した高さ, 0.5)`へ移動します。高さを管理するワールドへの移動成功時は `/owg tp` と同じゲームモード・飛行設定が適用されます。通常ワールドへの移動では、ゲームモードは切り替わりません。

利用にはサーバー側の許可が必要です。`/owg` は初期設定で管理者向けです。`/mvtp` の利用可否はサーバーの権限設定によります。別のワールド管理プラグインが検出された場合、`/mvtp` は OyasaiWorldGenerator から提供されません。

高さを管理するワールドでも、ポータルや他の移動機能から入ると、そのワールド用のゲームモード・飛行設定は適用されません。飛行が許可されても自動で飛び始めるわけではなく、ボイドには足場も生成されません。運営に安全な到着地点を確認してください。退出しても入場前のゲームモード・飛行状態へ自動で戻りません。

## ポータルを使う

設定済みポータルの範囲に歩いて入ると移動します。ポータルの移動先は運営が設定します。移動先のワールドがロードされていない、移動先が見つからない、安全な場所を確保できないなどの場合、プラグイン独自の移動は行われず、プレイヤー向けのエラー表示もありません。範囲内にネザーポータルがある場合は、通常のネザーポータル移動が続くことがあります。反応しない場合は運営に知らせてください。

乗り物で範囲に入ると、移動する乗客は降ろされ、乗り物は元の場所に残ります。到着したポータルはその場で再発動しません。いったんポータル範囲の外へ出てから入り直してください。徒歩・乗り物での利用には1秒の間隔が必要です。

## 制限と困ったとき

| 表示 | 意味・対応 |
|---|---|
| `[OWG] 対象ワールドが見つかりません` | 指定したワールドは移動対象にありません。名前を確認するか、運営に対象ワールドを確認してください。 |
| `[OWG] まだ準備できていません` | 対象ワールドはまだロードされていません。時間をおいて再度試し、続く場合は運営に知らせてください。 |
| `[OWG] 移動に失敗しました` | サーバー側で移動が完了しませんでした。再度試しても続く場合は運営に知らせてください。 |
| `[MV] 読み込み済みワールドが見つかりません: <ワールド名>` | 指定したワールドが見つからないか、ロードされていません。運営に知らせてください。 |
| `[MV] 移動に失敗しました` | 通常ワールドへの移動が完了しませんでした。運営に知らせてください。 |

サーバー側でワールドを準備できない場合は運営へ知らせてください。起動時検査で問題が見つかっても、すでに読み込まれたワールドへの入場が自動で止まるとは限りません。入れることだけで安全と判断せず、運営の案内に従ってください。
