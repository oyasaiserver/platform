# OyasaiToken の使い方（プレイヤー向け）

トークンの残高確認、プレイヤーへの送金、残高ランキングに使います。

## 残高を確認する

自分の残高は `/token` または `/token balance` で確認できます。

未登録のアカウントは、ログイン・残高確認・トークン操作時に初期残高を使います。既定は25トークンで、運営の設定により変わります。

## プレイヤーに送金する

`/token send <プレイヤー名またはUUID> <数量>`

- 数量は正の整数を指定します。サーバー側で送金額に上限が設定されている場合があります。
- 相手がオフラインでも指定できます。入力した名前をコマンド側では見つからない名前として拒否しないため、送信前に名前をよく確認してください。
- 名前を間違えると、その名前の別アカウントに送られます。送金を自分で取り消す方法はありません。
- 自分自身にも送金できますが、残高は変わりません。このときも、送る数量以上の残高が必要です。
- 送金の保存後、相手がオンラインなら相手に `<あなたの名前> sent you <数量> tokens.` と表示されます。そのときオフラインだった相手には後から通知されません。

## 残高変更の通知

運営による加算・減算・残高設定などでは、数量や変更後の残高が通知される場合があります。標準通知は既定で無効で、運営の設定やトークンを変更する機能によっては届きません。

通知対象の変更がオフライン中に行われた場合は、次回ログインの約1秒後に保留通知を受け取ります。1件なら通常の通知、複数件なら件数と合計増減をまとめた通知です。送金の通知は、この保留通知の対象ではありません。

通知の「現在の残高」は、その通知対象の変更直後の値です。まとめた通知では最後の保留通知の値を表示します。その後に通知なしの変更があると、ログイン時の通知と実際の残高が異なる場合があります。最新の残高は `/token balance` で確認してください。

## ランキングを見る

`/token top [件数]` で残高の上位を `1. 名前: 残高` の形で表示します。件数を省略した場合や整数以外を指定した場合は10件です。0以下は1件、51以上は50件として扱います。残高が同じ人の並び順は決まっていません。

## 表示の意味

| 表示 | 意味 |
|---|---|
| `You do not have permission.` | このコマンドを使う権限がありません。運営に確認してください。 |
| `Usage: /token send <player> <amount>` | 送金コマンドの形式が違います。プレイヤー名と数量を指定してください。 |
| `Amount must be positive.` | 数量は正の整数で指定してください。 |
| `Amount is outside the send limit.` | サーバーで設定された送金可能額の範囲外です。 |
| `Not enough tokens.` | 残高不足などで送金を受け付けられませんでした。残高を確認し、足りているのに続く場合は運営に知らせてください。 |
| `Token send was cancelled.` | サーバー側の別プラグインが送金を止めました。 |
| `Token persistence failed; no send notifications were delivered.` | 送金の保存に失敗しました。再試行を続けず、運営に知らせてください。 |
| `No token balances.` | 表示できる残高がありません。 |

送金が完了すると、`Sent <数量> tokens to <プレイヤー名>.` と表示されます。自分自身への送金では `Sent <数量> tokens to yourself.` と表示されます。
