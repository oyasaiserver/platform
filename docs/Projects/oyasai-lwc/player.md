# OyasaiLWC の使い方（プレイヤー向け）

チェストやドアに鍵をかけて、自分と共有した人だけが使えるようにする機能です。
**置いただけでは鍵はかかりません。** コマンドで鍵をかけてください。

## 基本の操作

コマンドを打ってから **30 秒以内に、対象のブロックを右クリック**します。
右クリックした時点でコマンドは使い終わります。違うブロックをクリックした場合は、もう一度コマンドを打ってください。

## 鍵をかける

`/lock`（別名 `/cprivate`）→ ブロックを右クリック。「ブロックを保護しました」と出れば完了です。

**まとめて鍵をかける:** `/lock auto` で自動保護モードになります。

- モード中に置いた**容器**には、自動で鍵がかかります
- モードは60秒で終わります。容器を置くたびに残り時間が60秒に戻ります（ドアなど容器以外を置いても延びません）
- 別のワールドへ移動すると終わります。もう一度 `/lock auto` を打つと途中で止められます
- 残り時間は画面下に出ます
- 鍵付きのチェストの隣に置いてラージチェストにした場合は、新しい鍵は作らず、元の鍵（持ち主・種類・共有・ホッパー設定）がそのまま使われます

コマンドを打って右クリックする前に別のコマンドを打つと、後のコマンドに置き換わります。`/lock auto` を打つと、待っていたコマンドは取り消されます。ログアウトすると、待っていたコマンドも自動保護モードも終わります。

## 鍵をかけられるもの

- **容器:** チェスト、トラップチェスト、銅のチェスト、かまど、溶鉱炉、燻製器、ディスペンサー、ドロッパー、樽、コンポスター、書見台、飾り壺、クラフター、シェルフ、シュルカーボックス
- **その他:** ドア、トラップドア、フェンスゲート、看板、旗

ラージチェストとドアは、片方に鍵をかければ両方が守られます。
**ラージチェストの注意:** 鍵は最初にクリックした側に記録されます。そちら側を壊すと、残った側の鍵も外れます。

## 見せるだけの鍵（展示用）

`/cdisplay` → ブロックを右クリック。お店の見本や展示に使います。

- チェストなどは開いて中を見られますが、**誰も出し入れできません**（持ち主・共有相手も同じ）。開いている間は、自分の持ち物の欄もクリックで操作できません
- コンポスター・飾り壺・シェルフ・クラフター・ドア・トラップドア・フェンスゲート・看板・旗は、右クリックそのものができなくなります
- 書見台の本は取れません
- 中身を入れ替えたいときは `/unlock` で外し、入れ替えてから `/cdisplay` でかけ直します

鍵の種類（`/lock` と `/cdisplay`）は後から切り替えられません。いったん `/unlock` で外してかけ直します。このとき、共有相手とホッパー設定は消えます。

## 友だちと共有する

`/cmodify 名前` → ブロックを右クリック。

- 複数人もまとめて指定できます: `/cmodify Alice Bob`
- 共有をやめるときは名前の前に `-` を付けます: `/cmodify -Alice`
- 相手がオンラインか、最近サーバーに来た人でないと見つからないことがあります。見つからない名前は飛ばして、残りの人だけ設定します
- 誰も見つからなかったときも「共有相手を更新しました」と出ます。結果は `/cinfo` で確かめてください

共有した人は開けて使えます。鍵を外したり、壊したり、設定を変えたりできるのは、持ち主と管理者だけです。
他の人の鍵付きチェストの隣（前後左右）に、同じ種類・同じ向きのチェストを置くことはできません。つながらない位置でも断られることがあります。共有されていても同じです。

## ホッパーを使えるようにする

鍵をかけた容器は、ホッパーやホッパー付きトロッコでの出し入れが止まります。自動仕分けなどで使うときは:

- `/chopper on` → ブロックを右クリック（`off` で元に戻す）

**移動元と移動先の両方**に鍵がある場合は、両方を `on` にしてください。展示用の鍵でも `on` にすると、ホッパーで中身が出入りします。

## 鍵を確認する・外す

| やりたいこと | コマンド（そのあと対象を右クリック） |
|---|---|
| 持ち主・種類・共有相手・ホッパー設定を見る | `/cinfo` |
| 鍵を外す | `/unlock`（別名 `/cremove`） |

## 困ったとき

| 表示 | 意味 |
|---|---|
| このブロックは保護されています | 他の人の鍵です。持ち主に共有を頼んでください |
| すでに保護されています | もう鍵がかかっています。種類を変えたいときは外してからかけ直します |
| このブロックは保護できません | 鍵をかけられないブロックです（上の一覧を参照） |
| 他人の保護チェストの隣には置けません | 他の人のチェストとつながるのを防いでいます。少しずらすか、しゃがみながら置いて単体のチェストにしてください |
| 持ち主か管理者だけが変更できます / 壊せます | 鍵の変更・撤去・破壊は持ち主と管理者しかできません |
| プレイヤーが見つかりません: 名前 | その人はまだ見つかりません。相手がオンラインのときにもう一度試してください |
| 操作の有効時間が切れました / ブロック操作を取り消しました（30 秒経過） | コマンドから30秒以上たちました。もう一度コマンドを打ってください |
| このコマンドは廃止しました | `/cpublic`・`/cpassword`・`/cunlock` などは使えなくなりました |
