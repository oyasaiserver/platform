# SocialLikes3 の使い方（プレイヤー向け）

自分の建築に Like 看板を付けて紹介し、他の人の建築へ遊びに行って「いいね」できる機能です。建築一覧、作者のフォロー、旅行ガイド、いいねの統計も使えます。

## 建築を登録する

1. 建築の紹介場所に看板を置き、**表面の1行目に `likes`、2行目に建築のタイトル**を書きます。`likes` の大文字・小文字はどちらでも使えます。
2. 看板が `(SocialLikes)`・タイトル・作者・いいね数の表示に変わり、全員へ建築のお知らせが出ます。
3. お知らせのリンク、または `/sltp ID` で、その看板の場所へ遊びに行けます。

`like` では登録できません。タイトルが空、裏面への記入、ロード中の登録も受け付けません。登録した看板は直接編集・破壊できなくなります。**建築全体に鍵をかける機能ではありません。**

## いいねする・看板の情報を見る

- Like 看板を右クリックすると「イイねしました！」と画面下に出ます。同じ建築にいいねできるのは1人1回です。取り消す操作はありません。
- 自分の建築にもいいねできます。他人の建築への新しいいいねでは、押した人へお金1000、作者へ投票ポイント2ptの報酬があります。作者がオフラインなら次の参加時に受け取ります。報酬が届かない場合は運営へ連絡してください。
- **しゃがんで右クリック**すると、いいねした人、作者、コメント、作成日などの画面を開きます。いいねは付きません。
- 「リポスト(宣伝)」は10Pで建築を全員へ紹介します。**確認画面はなく、クリックすると10Pを使います。** 作者以外も使えます。

看板の「✓」は、運営が通常の右クリックをした印です。

旧い看板は、最初の右クリックで「アップデートしました！」と出て新しい看板になります。そのクリックではいいねを付けないので、もう一度右クリックしてください。

## 建築を探す・見に行く

| やりたいこと | コマンド・手順 |
|---|---|
| メニューを開く | `/slmenu`。全ての建築、建築名検索、作者の建築、フォロー一覧、旅行ガイドへ進めます |
| 全員の建築を見る | `/slbuild`。看板アイテムをクリックすると移動します |
| 作者の建築を見る | `/sluser 名前` |
| 特定の建築へ移動する | `/sltp ID` |
| 登録順に次・前へ移動する | `/sltp next`・`/sltp back`。先に一度 `/sltp ID` を使います |
| 同じ作者の次・前へ移動する | `/sltp unext`・`/sltp uback` |
| 最近登録・宣伝された建築へ移動する | `/sltp new [1-10]`。省略すると最新。短縮形は `/sla [1-10]`・`/alw [1-10]` |
| 近くの建築を探す | `/slnear [件数]`。省略・数字でない値・0以下は5件。チャットの建築名をクリックして移動します |
| まだいいねしていない他人の建築へ | `/sllucky` |
| 看板が少ない場所を探す | `/vacanttp`（別名 `/vtp`）。今のワールドで探します |

`/sltp new` は登録と宣伝の履歴を新しい順に最大10件並べます。同じ建築が複数回入ることがあります。移動先は看板の位置です。ワールドが使えないときや、移動が止められたときは移動できません。

作者の建築一覧で「フォローする」を選ぶと、`/slmenu` の「フォロー建築一覧」からその人の建築を見られます。最初は前回の退出後の新着を表示し、「新着/全建築の切替スイッチ」で全件に切り替えます。作者の建築一覧で「フォローを外す」を選ぶと解除できます。「フォロー中の人」の一覧からは、作者を選んでその建築一覧へ進みます。

`/slnear` は今いるワールドの周囲±12チャンクを探します。1方向におよそ190ブロックの範囲で、円形の距離制限ではありません。

建築名検索や名前・コメントの入力は、金床の画面で**右側の出力アイテムをクリックして確定**します。空白だけでは確定できず、閉じると取り消します。

空き地探しは `/vtp 半径 [許容する看板数]`、`/vtp バイオーム [半径] [許容する看板数]` でも使えます。半径はチャンク単位（1チャンクは16ブロック）。引数なしでは半径8・看板2件以下、半径だけなら看板数の既定は半径÷3です。バイオーム名は `PLAINS` のような大文字の正式名をそのまま指定します。高さY=200のバイオームで探すため、地下のバイオームを探す用途には使えません。**看板数が少ない場所を探す機能で、土地の所有・保護や建築の有無は確認しません。**

## 自分の看板を変更・移動する

しゃがんで自分の看板を右クリックし、「詳細設定」を開きます。

- タイトル、木材の種類を変更できます。木材を変えても、普通・壁付き・吊り・壁付き吊りの形は維持します。
- コメントはいいね一覧の「コメントを編集する」から入力します。カンマ（`,`）は改行として表示されます。
- 「看板を再入手する」または `/slsignget ID` で移動用の看板を受け取れます。吊り看板にしたいときは `/slsignget ID hanging`、または再入手ボタンを Shift クリックします。

**移動の手順:** 再入手した看板を新しい場所に置く → `/slupdate` → **10秒以内に新しい看板を右クリック**。登録位置が変わり、以前の場所に看板が残っていれば取り除かれます。置いただけでは登録位置は変わりません。

「看板を消去する」→「はい、消去します。」で登録と看板を消します。画面にも「この操作は取り消せません」と出ます。消去後、そのIDへの移動・再入手はできません。

「SLTP看板を入手する」は、建築へ移動するための別の案内看板です。いいね用の看板ではありません。価格は通常50pt、クリエイティブを利用できる人は100ptです。回収は3ブロック以内から看板を見て `/slsignbreak`。回収できるのは、その案内看板の持ち主・紹介先の建築の持ち主・管理者です。

SLTP看板を回収すると、その案内看板の持ち主は回収した人になります。紹介先の建築が消えた案内看板は `/slsignbreak` で回収できません。「SLTP看板を入手する」を押しても反応しない場合は、運営へ連絡してください。

再入手したアイテムは、持ち物がいっぱいなら足元に落ちます。

## 旅行ガイドで建築を巡る

1. `/slguide` で公開ガイド一覧を開き、クリックして本を受け取ります。`/slguide ID` でも入手できます。
2. 本をメインの手に持って**左クリック**すると、掲載順に次の「まだいいねしていない建築」へ案内します。
3. **右クリック**で情報を開きます。チェストなど操作できるブロックへの右クリックは、そのブロックの操作を優先します。空中で右クリックすると本を開けます。
4. 掲載建築名や `Next:` のリンクからも案内できます。移動しただけでは発見にならず、Like 看板へのいいねで進捗が増えます。

旅行ガイドの本をメインの手に持っている間、左クリックは案内の操作になるためブロックを壊せません。

既定では未発見建築への案内の間に30秒待ちます。いいね済み建築へリンクから戻る場合は待ち時間を適用せず、待ち時間を延長もしません。移動に失敗した場合も延長しません。存在しない看板や使えないワールドの建築は案内不可です。

有効な掲載建築をすべていいねするとコンプリート表示になります。新しいいいねで完成したときは、初回は全体告知と花火、記録済みなら本人への通知と花火を出します。看板が消えて対象件数が減っただけでは完成の演出は出ません。0件のガイドはコンプリートになりません。

情報ページの「リポスト NP」は、**クリックすると確認画面なしで**ポイントを使って宣伝します。価格は既定で10P＋有効な掲載建築1件につき1Pです。

## 自分の旅行ガイドを作る

1. `/slguide create` → 金床でタイトルを入力して右側の本をクリック。タイトルは1〜32文字、色指定・制御文字は使えません。
2. 編集キーをメインの手に持ち、編集画面の「建築追加」を押して、自分の Like 看板を右クリックします。追加に成功すると追加モードは終わります。失敗したらもう一度対象を選べます。
3. 既定では1冊30件まで。同じ建築を同じガイドに2回追加できません。個人ガイドは作者本人の建築だけです。
4. 順番の変更・掲載解除・タイトル変更・説明入力を済ませ、「公開する」で一覧に載せます。建築を1件以上追加してください。

編集キーをメインの手に持ったまま Like 看板を右クリックすると、通常はいいねではなく編集画面が開きます。建築追加モード中は追加操作になります。いいねするときは別のアイテムに持ち替えてください。

編集キーの再入手は `/slguide edit` または `/slguide edit ID`。キーを他の人へ渡しても、その人がガイドを編集できるようにはなりません。説明は編集キーを手に持って「説明を書く」を押し、右クリックして記入します。使うのは最初のページだけで、既定8表示行を超えた分は切り詰めます。個人ガイドに出るコメントは建築のコメントと共通で、カンマより前の部分だけを既定5表示行まで表示します。

作れる冊数は所属ランクによって既定1〜5冊です。複数該当すれば最大値で、それに購入済みの追加枠を足します。該当ランクも追加枠もない場合は作れません。`/slguide edit` の「追加枠を買う」で増やせます。既定価格は150・400・800・1200・1500P、その後も1500P。購入とガイド削除は**15秒以内の再確認**が必要です。購入済み枠の払い戻し・ガイド削除の取り消しはできません。ガイドの削除は建築そのものを削除しません。

初公開で全体告知します。編集後に非公開→公開へ戻すと更新告知します。編集せずに公開を往復しても再告知しません。建築追加・説明入力のモードは退出で解除されます。

## 統計を見る

| コマンド | 内容 |
|---|---|
| `/sldata` | 自分の概要、建築、いいね、交流・宣伝などの統計。タブで切り替えます |
| `/sldata ranking` | 今週の制作者別いいね数 Top5。画面で月・年・全期間も選べます |
| `/sldata server` | 全体の建築宣伝効果・宣伝回数 |
| `/sldata week`・`/sldata month`・`/sldata year` | 全体のいいね推移グラフ |
| `/sldata help` | コマンドの案内 |

時刻が記録されていない昔のいいねは、全期間の件数には入っても期間別の数には入りません。画面の期間選択ですべての項目が同じ期間に揃うわけではありません。詳細統計は最大30秒ほど前の集計が出ることがあります。統合版では統計画面が表示されない場合があります。

## 困ったとき

表では色と `(SocialLikes)` の接頭辞を省き、変わる部分を `ID`・`N` と表記しています。

| 表示 | 意味・対応 |
|---|---|
| 現在は"likes"と書いたらLike看板を作れます。 | 1行目を `likes` にしてください |
| 看板の表面以外には書き込めません! / 2行目にタイトルを書いてください！ | 表面に、タイトル付きで書きます |
| 現在ロード作業中です、しばらくお待ち下さい。 | データの読み込み中です。少し待って再操作します |
| ポイント不足です! | 建築の宣伝には10P必要です |
| SLTP看板の取得には投票ポイントがNpt必要です。 | 案内看板の購入ポイントが足りません。表示に `&c` が残る場合があります |
| 旧Like看板です。登録データの座標と違います。 運営に報告お願いします | 看板の位置が登録と違います。看板の場所を運営へ伝えます |
| 一度sltpを行ってください | 先に `/sltp ID` で建築へ移動してから、次・前への移動を使います |
| 周囲にLike看板はありませんでした | 今いるワールドの探索範囲に建築がありません |
| 有効なSL看板ではありません。 | ガイドへの追加対象が登録と一致しません。正しい看板を選び直します |
| 個人ガイドには作者の建築だけ追加できます。 | 自分の建築を選びます |
| 個人ガイドはN冊までです。/slguide edit から追加枠を購入できます。 | 作れる冊数の上限です |
| 価格が変わりました。もう一度確認してください。 | ガイド宣伝の確認画面からやり直します |
| 既にイイねしています！ | その建築にはもういいね済みです |
| この看板のデータを保存できませんでした。運営に報告してください（ID: ID） | 表示が変わっていても保存に失敗しています。IDと操作を運営へ伝えます |
| データの削除に失敗しました。 | 消去後の保存に失敗しました。運営へ伝えます |
| ID:IDは存在しません / ID:IDのワールドが存在しません | 登録がないか、そのワールドを使えません |
| 何らかの理由で「タイトル」へテレポート出来ませんでした(ID:ID) | 移動が成功していません |
| アップデートモードを自動終了しました | 10秒たちました。もう一度 `/slupdate` を打ちます |
| 他人のLike看板は取得できません | 自分の看板を指定します |
| この看板はSLTP看板ではありません | `/slsignbreak` は移動用の案内看板の回収専用です |
| 未いいねの他者建築は見つかりませんでした。 | 抽選できる建築がありません |
| このガイドブックは現在公開されていません。 | 非公開・削除済みなどで使えません |
| このガイドブックは編集できません。 | 自分のガイドでないか、削除済みなどです |
| あとN秒で再び案内できます。 | ガイドの案内の待ち時間です |
| 削除確認の有効期限が切れました。 / 購入確認の有効期限が切れました。 | 確認画面からやり直します |
| 追加済み、または1冊の上限N件に達しています。 | 重複・上限などで追加できません。運営の確認が必要な場合もあります |
| 現在ポイントを利用できません。 | ポイント連携が使えません |
| 宣伝できず、返金にも失敗しました。運営に連絡してください。 / 追加枠を保存できず、返金にも失敗しました。運営に連絡してください。 | 運営へ操作内容を伝えてください |
| バイオームが見つかりませんでした。 / 空き地が見つかりませんでした。 | 探索回数内に見つかりませんでした |
| コンフィグにWorldBorderが設定されていません。 | そのワールドの探索範囲がありません。運営へ伝えます |
| 足場が無いためテレポートできませんでした / 空き地の検索に失敗しました。運営に報告してください。 | 移動先や検索に問題があります |

看板が反応しない、更新後も元の場所に飛ぶ、報酬が届かない場合は、建築IDと行った操作を運営に伝えてください。
