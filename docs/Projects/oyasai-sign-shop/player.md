# OyasaiSignShop の使い方（プレイヤー向け）

看板を右クリックして買い物・売却をするお店の機能です。店の種類は `/signshop list` でも確認できます。

## 店の種類

| 看板の1行目 | 右クリックしたときに起きること |
|---|---|
| `[Buy]` | お金を店主に払い、店の箱から商品を受け取る |
| `[Sell]` | 商品を店の箱へ渡し、店主からお金を受け取る |
| `[iBuy]` | お金を払い、商品を受け取る（サーバーの店。箱の在庫は減らない） |
| `[iSell]` | 商品を渡し、お金を受け取る（サーバーの店。箱には入らない） |
| `[Device]` | お金を店主に払い、店のレバーを10秒間オンにする |

1回の取引で動く商品は、店ごとに決まった組み合わせ（例: ダイヤ 64 個）です。商品の名前・エンチャントなどが見本と完全に同じものだけが対象になります。持ち物は、防具欄・オフハンドを除いた36マスだけを使います。

## 取引の前に確かめる（左クリック）

素手など（下の「店を作る」で使う道具以外）で看板を**左クリック**すると、次のように表示されます。

`種類 / 商品: DIAMOND x64 / 価格: 100円 / 取引可能`

最後の部分が「取引可能」でなければ、今は取引できません。

| 表示 | 意味 |
|---|---|
| 品物または空き容量が不足 | 店の在庫・店の箱の空き・自分の商品・自分の持ち物の空きのどれかが足りません |
| レバーを使えません | Device 店のレバーが今オンになっている、またはなくなっています |
| 停止中: 理由 | 店が止められています。運営に連絡してください |
| 見本を読めません | 店の商品データに問題があります |
| 未登録 | 店として登録されていない看板です |

この確認ではお金の残高は見ません。看板1行目の色は、青なら取引できる見込み、赤なら取引できない状態の目安です（取引や再読み込みのときにだけ更新されるので、ずれることがあります）。

## 取引する（右クリック）

看板を右クリックします。

| 表示 | 意味 |
|---|---|
| 取引が完了しました | 成功です |
| 取引できませんでした。取り消し済みです | 途中で失敗し、お金と品物は元に戻っています |
| **取引結果の確認が必要です。運営に連絡してください** | 結果が確かめられませんでした。**同じ店を使わず**、運営に連絡してください |
| 在庫または空き容量が足りません | 左クリックの確認と同じ理由です |
| 残高が足りません | 払う人の残高が足りません。`[Sell]` では**店主の**残高不足です |
| レバーを使用できません | Device 店のレバーがオンのまま、またはなくなっています。しばらく待ってください |
| この店は現在利用できません | 停止中、別の人が取引中、または利用が制限されています。少し待って直らなければ運営へ |
| 値段を読めません。運営に連絡してください | 看板の値段が読めず、店が止まりました |
| 取引を開始できませんでした / 品物の見本を読めません / この容器では取引できません / 経済サービスがありません / LWC を確認できません | 店またはサーバー側の問題です。運営に連絡してください |

## 店の箱

店に登録された箱は、店主（と運営）しか開けたり壊したりできません。他の人が開こうとすると「この店のチェストは店主だけが開けます」と出ます。店の看板を支えているブロックは、店主も含めて誰も壊せません。看板は店主が壊すと店ごと削除されます（下を参照）。

店の箱から直接取り出されるのを防ぐのは、この開閉の制限だけです。ホッパーでの吸い出しを防ぐには、箱に `/lock` で鍵をかけてください（[OyasaiLWC](../oyasai-lwc/player.md)）。Device 店のレバーは守られないので、誰でも直接切り替えられます。

## 店を作る

店を作れるかどうかはサーバーの権限設定で決まります。作れない場合は「作成権限がありません」と出ます。`[iBuy]`・`[iSell]` は運営向けです。

1. 看板の**1行目**に `[Buy]` などの種類、**4行目**に値段を書きます。値段は `100`、`1,200`、`¥100` のように書きます（小数は四捨五入。`0` は無料）
2. 使う箱（チェスト・トラップチェスト・樽・シュルカーボックス）か、Device ならレバーを、**レッドストーンを持って左クリック**します。「対象を選びました」と出ます。複数選べます（最大100個、看板と同じワールドだけ）
3. **1つ目に選んだ箱**に、1回の取引で売り買いする商品を入れます。入っている物が全部、1回分の商品になります（Device では不要。ただし `[iBuy]`・`[iSell]` にも見本用の箱が要ります）
4. レッドストーンを持ったまま看板を左クリックします。「店を作成しました」と出れば完成です

**注意:** 選んだブロックの選択を取り消す方法はありません。店を作り終える（成功する）まで、またはサーバーが再起動するまで選択が残ります。間違えて別のブロック（かまどなど）を選ぶと、そのままでは作成に失敗し続けます。

かまど・ホッパー・ディスペンサー・銅のチェストなど上記以外の容器は店に使えません。

## 店を変える・調べる・消す

| やりたいこと | 方法 |
|---|---|
| 商品・値段を変える | 箱の中身や看板4行目を直してから、**イカスミ**を持って看板を左クリック（つなぐ箱も変えるなら、先にレッドストーンで選び直す） |
| 店の情報を見る | **本と羽ペン**を持って看板を左クリック |
| 店を消す | **金のオノ**で看板を壊す |

変更・削除は店主だけができます。店の箱を店主が壊すと、その店は**停止**します。再開するには、残っている箱（またはレバー）をレッドストーンで選び直してから、レッドストーンかイカスミで看板を左クリックして更新します。

## 困ったとき（店を作るとき）

| 表示 | 意味 |
|---|---|
| 値段を読めません | 看板4行目の値段の書き方が違います |
| 対象は同じ世界から100個以下で選んでください | 何も選んでいない、選びすぎ、または別ワールドのブロックを選んでいます |
| LWC の許可を確認できません | 選んだブロックが他の人の鍵付き、または読み込まれていない場所にあります |
| 箱またはレバーの選択が正しくありません | Device なのにレバーがない、または他の店なのに箱がありません |
| 自動で中身が変わる容器は店に使えません | 使えない種類の容器を選んでいます（選択は取り消せないので運営に相談してください） |
| 見本の品がありません | 1つ目の箱が空です |
| 同じキーの店が既にあります | その場所の店はすでにあります |
| 店主ではありません | 他の人の店は変更できません |
| 登録済みの店ではありません | イカスミは作成済みの店にだけ使えます |
| 閲覧権限がありません | 他の人の店の情報は見られません |
| 保存に失敗しました。店を点検してください | 運営に連絡してください |
