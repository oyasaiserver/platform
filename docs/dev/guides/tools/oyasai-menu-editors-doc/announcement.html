お知らせの設定 AnnouncementManager

announcements.yml を読み込んでルートメニューに表示

← 目次に戻る

このページの内容

  1. 設定ファイル
  2. 反映方法

設定ファイル

plugins/OyasaiMenu/announcements.yml を直接編集します。announcements リストの先頭要素が表示されます。

announcements:
  - title: "&f✦ ようこそ！"
    body:
      - "&7今日は晴れです"
      - "&71日1回でログインボーナス"

title はルートメニューの %announcement_title%、body は %announcement_body% に差し込まれます。

反映方法

編集後にコンソールまたは管理者から /oyasaimenu reload を実行します。管理者メニューのリロードボタンも使用できます。
