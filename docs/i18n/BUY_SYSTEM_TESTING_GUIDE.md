## 🎮 実装された機能

### 1. `/bigwolf buy` - メイン購入GUI
- 全ペット種類をカテゴリ別に表示
- バリアントがあるペットは「バリアント選択」へ
- バリアントがないペットは「直接購入確認」へ

### 2. `/bigwolf buy <MOB>` - 直接バリアント選択
- 例: `/bigwolf buy wolf` → オオカミのバリアント選択GUI
- 9種類のバリアントが日本語名で表示
- 例: brown → 茶色, spotted → 斑点

### 3. `/bigwolf buy <MOB> <variant>` - 直接購入
- 例: `/bigwolf buy wolf brown` → 茶色オオカミの購入確認画面
- 例: `/bigwolf buy cat tabby` → トラネコの購入確認画面
- 1ステップで購入画面に到達

### 4. バリアントエッグクリック → 購入確認
- バリアント選択GUI内のエッグをクリック
- 購入確認画面へ正しく遷移
- 修正前: 再度バリアント選択に戻ってしまった ❌
- 修正後: 購入確認画面へ遷移 ✅

### 5. バリアント名の完全日本語化
- 80種類以上のバリアント名を日本語化
- GUI表示とLOREの両方で日本語表示
- 英語名もLOREに併記
