## 🚀 クイックスタート

### プレイヤーの方

1. [プレイヤー向けガイド](./BigWolf_Player_Guide.md)を読む
2. `/bigwolf` コマンドで使い方を確認
3. `/bigwolf <mob名>` でペットを購入（直接召喚されます）
4. Shift+右クリックでステータス確認
5. ペットが死んだら `/bigwolf revive <番号>` で復活

### 管理者の方

1. [OP・管理者向けガイド](./BigWolf_Admin_Guide.md)を読む
2. `config.yml`で価格などを設定
3. `/bigwolf reload` で設定を反映
4. `/bigwolf item all` でテストアイテムを入手
5. `/bigwolf shop <mob>` でショップを設置

## 📋 主な機能

- 🐺 **50種類以上のペット** - 多様なMOBをペットとして召喚
- 💰 **経済システム** - TokenManagerと連携したポイント制
- 📈 **育成システム** - レベル50まで成長
- 🧬 **交配システム** - 2匹のペットから新しい世代を誕生させ、能力値を継承・強化
- ⚡ **スキルシステム** - 3段階のスキルを習得
- 🎨 **カスタマイズ** - 名前変更、パーティクル設定
- 📦 **収納システム** - ペットをアイテム化して保管
- 💀 **復活システム** - 死亡したペットを50ptで復活
- 📍 **位置追跡** - ペットの最終位置を記録・確認
- 🔒 **譲渡防止** - ペットは購入者のみが使用可能（譲渡機能あり）
- 🏪 **ショップシステム** - ワールド内にショップMOBを設置
- ⚙️ **柔軟な設定** - 価格、能力値、交配パラメータなど細かく調整可能
