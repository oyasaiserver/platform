# docs

OyasaiServer `platform` の作業の記憶。人と AI が、分かったこと・決めたこと・つまずいたことを次の作業者へ引き継ぐ場所です。

入口は [Home.md](Home.md) です。AI は作業しながらここを読み、学んだことを作業と同じ PR で書き足します。

| フォルダ | 中身 |
|---|---|
| [Projects/](Projects/) | プロジェクトごとの入口 `PROJECT.md`・仕様・判断 |
| [Knowledge/](Knowledge/) | 横断的な知見・手順・[過去の失敗](Knowledge/mistakes.md) |
| `Decisions/` | 横断的な判断（日付付き） |
| [Archive/](Archive/) | 役目を終えた資料 |

公開リポジトリなので、個人情報・秘密・非公開のサーバー詳細は書きません（[Home.md](Home.md#公開リポジトリとして守ること)）。
