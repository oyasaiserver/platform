## クイックスタート（最短でペットを使い始める）

1. `/bigwolf buy` でショップを開く
1. 欲しいペットを選んで購入する（トークンが必要）
1. インベントリにスポーンエッグが届く
1. エッグを右クリックでペットを召喚する
1. ペットに右クリックで乗る
1. 乗った状態で左クリックするとスキルが発動する（解放済みの場合）

まずはここまでできれば、すぐに冒険へ出発できます。

---

## ペットの購入

### 購入方法

**GUIから購入（おすすめ）**

```
/bigwolf buy
```

**コマンドで直接指定して購入**

```
/bigwolf buy <MOB名> [variant]
例: /bigwolf buy wolf black
```

### 購入可能なペット一覧を見る

```
/bigwolf list
```

### ペットのカテゴリ

| カテゴリ | 特徴 | ペット |
|---|---|---|
| 陸上型 | 地上で扱いやすい | オオカミ、ネコ、キツネ、ウサギ、パンダ、ホッキョクグマ、アルマジロ |
| 水棲型 | 水中移動が得意 | イルカ、アクスオロトル、カエル、カメ |
| 飛行型 | 空中移動が得意 | オウム、ニワトリ、ミツバチ、アレイ |

> **お知らせ:** v2.5.0 以降、フグ（PUFFERFISH）はペットラインアップから削除されました。

## ペットの基本操作

| 操作 | 方法 | |---|---| | 召喚 | スポーンエッグを右クリック | | 乗る | ペットに右クリック | | 降りる |
スニーク（Shift）長押し | | 個別収納 | ペットにスニーク右クリックでGUIを開き「収納する」を押す | | 全収納 |
`/bigwolf storeall` |

> **注意:** ペットは同時に最大3匹まで展開できます。

## ペットを育てる

### エサやり（レベルアップ）

ペットフードを持ってペットを右クリックするとレベルを上げられます。

### 遊ぶ（レベルアップ）

おもちゃ・ブラシでもレベルアップのチャンスがあります（一定確率、Lv.10まで）。

| 例 | おもちゃ | 遊び方 | |---|---|---| | オオカミ、キツネなど | 各種おもちゃ | 右クリックで投げるとペットが取りに行く | |
ネコ | 猫じゃらし | 釣り竿のように使う | | イルカ | フグ風船 | 右クリックで遊ぶ |

---

## スキルの解放と発動

スキルブックをペットに使うとスキルが解放されます。

| スキル | 説明 | 発動操作 | |---|---|---| | スキル1: 咆哮 | 周囲の敵をノックバック＋ダメージ | ペット騎乗中に左クリック |
| スキル2: 突進 | 前方に高速で突進する | ペット騎乗中に左クリック | | スキル3: 特殊 | ホバリング/水面走行のON/OFF切替 |
ペット騎乗中に左クリック |

**クールダウン:** スキル1・2は5秒（スキル3はトグル式）

## ペットの管理

### ペット一覧・履歴

```
/bigwolf history
/bigwolf history 2
```

### 名前変更

```
/bigwolf rename <番号> <名前>
例: /bigwolf rename 1 モフモフ
```

### 位置確認

```
/bigwolf locate <番号>
```

### エッグ再取得（収納中ペット）

```
/bigwolf recover <番号>
```

---

## ペットが死んだとき

```
/bigwolf dead
/bigwolf revive <番号>
```

---

## 交配（ブリーディング）

同じ種類のペット2匹で子ペットを誕生させられます。

### 交配条件

- 両方のペットがレベル10以上
- 交配回数上限（1体あたり3回）に達していない
- トークンが足りている

### 交配手順

1. `/bigwolf breed` でGUIを開く
1. 親にする2匹を選択する
1. 実行ボタンで確定する
1. その場に子ペットが出現する

---

## 放棄・譲渡

```
/bigwolf abandon <番号>
/bigwolf transfer <番号> <プレイヤー名>
```

`abandon` は取り消しできないため慎重に実行してください。
