## 🚀 クイックスタート

### プレイヤーの方

1. [プレイヤー向けガイド](./BigWolf_Player_Guide.md)を読む
1. `/bigwolf` コマンドで使い方を確認
1. `/bigwolf <mob名>` でペットを購入
1. 購入券を右クリックで召喚
1. Shift+右クリックでステータス確認

### 管理者の方

1. [OP・管理者向けガイド](./BigWolf_Admin_Guide.md)を読む
1. `config.yml`で価格などを設定
1. `/bigwolf reload` で設定を反映
1. `/bigwolf item all` でテストアイテムを入手
1. `/bigwolf shop <mob>` でショップを設置

## 📋 主な機能

- 🐺 **50種類以上のペット** - 多様なMOBをペットとして召喚
- 💰 **経済システム** - TokenManagerと連携したポイント制
- 📈 **育成システム** - レベル50まで成長
- ⚡ **スキルシステム** - 3段階のスキル（咆哮・突進・極意）
- 🎨 **カスタマイズ** - 名前、パーティクル、サイレントモード
- 📦 **収納機能** - ペットをアイテム化して持ち運び
- 🎮 **直感的GUI** - 分かりやすいメニュー
- 🛒 **ショップシステム** - ワールド内に購入MOBを設置
