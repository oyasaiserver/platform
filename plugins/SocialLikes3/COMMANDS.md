# SocialLikes3 コマンド一覧

2026-09-23 時点のコード（`plugin.yml` と `command/` 配下）から書き出したもの。
「補完」は Tab キーで出る引数の候補。選択肢は入力中の文字で絞り込み、`<ID>` `[件数]` のような説明は引数が空のときだけ出る。「なし」のコマンドは何も出ない（オンラインプレイヤー名も出ない）。
管理者・スタッフ向けの機能は、すべて OP かどうかで判定する（権限ノードは使わない）。

## 建築を探す・飛ぶ

| コマンド              | 何ができるか                                                                                                | 使い方                                                                                                                                                                                                                                                                  | 使える人 | 補完                                                              |
| --------------------- | ----------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | ----------------------------------------------------------------- |
| `/sltp`               | SL看板（建築）へテレポートする                                                                              | `/sltp <ID>`<br>`/sltp next` `/sltp back`: 最後に `/sltp` で飛んだ建築の、次・前に新しく登録された建築へ<br>`/sltp unext` `/sltp uback`: 同じ作者の、次・前の建築へ<br>`/sltp new`: 直近に設置された看板か、宣伝された看板へ<br>`/sltp new <1〜10>`: n 番目に新しいもの | 全員     | `next` `back` `unext` `uback` `new` `<ID>`。`new` の次は `[1-10]` |
| `/sla`（`/alw`）      | `/sltp new` の短縮形。統合版で打ちやすい名前                                                                | `/sla [1-10]`                                                                                                                                                                                                                                                           | 全員     | `[1-10]`                                                          |
| `/slnear`             | 今いる場所から近い建築をチャットに並べる。クリックでその建築へ飛ぶ                                          | `/slnear [件数]`（省略時 5件）                                                                                                                                                                                                                                          | 全員     | `[件数]`                                                          |
| `/sllucky`            | まだいいねしていない他人の建築を、ランダムに1件案内する                                                     | `/sllucky`                                                                                                                                                                                                                                                              | 全員     | なし                                                              |
| `/vacanttp`（`/vtp`） | 周りに SL 看板が少ない場所（空き地）を探して飛ぶ。建築場所探し用                                            | `/vtp`: 今のワールドで探す<br>`/vtp <半径> [許容する看板数]`<br>`/vtp <バイオーム> [半径] [許容する看板数]`: そのバイオームで探す                                                                                                                                       | 全員     | ○                                                                 |
| `/slbuild`            | 全員の建築一覧の画面を開く                                                                                  | `/slbuild`                                                                                                                                                                                                                                                              | 全員     | なし                                                              |

| `/slmenu`             | SL のメニューを開く。全ての建築／名前から検索／プレイヤーの建築／フォロー建築一覧／旅行ガイドブックへ進める | `/slmenu`                                                                                                                                                                                                                                                               | 全員     | なし                                                              |

## 旅行ガイドブック

| コマンド                           | 何ができるか                                                  | 使える人                                                        | 補完                                  |
| ---------------------------------- | ------------------------------------------------------------- | --------------------------------------------------------------- | ------------------------------------- |
| `/slguide`                         | 公開中のガイドの一覧を開く                                    | 全員                                                            | `create` `edit` `<ID>`                |
| `/slguide <ID>`                    | そのガイドの本をもらう                                        | 全員                                                            | 同上                                  |
| `/slguide create`                  | 個人ガイドを作る                                              | ランク上限（OP は最大値）＋購入済み追加枠の冊数まで             | 同上                                  |
| `/slguide create official`         | 公式ガイドを作る。公式ガイドの編集・公開も OP のみ            | OP                                                              | `create` の次に `official`（OP のみ） |
| `/slguide edit`                    | 自分が編集できるガイドの一覧を開く                            | 全員                                                            | `create` `edit` `<ID>`                |
| 編集用ガイド一覧の「追加枠を買う」 | 1枠ずつポイントで購入（15秒以内の再確認が必要、払い戻しなし） | 全員。価格は `guidebook.extraSlotPrices` の順、以降は最後の価格 | なし                                  |
| `/slguide edit <ID>`               | そのガイドの編集用の本をもらう                                | 個人ガイドは作者・OP、公式ガイドは OP                           | `edit` の次に `<ID>`                  |

本の中のリンクから呼ばれる内部コマンド（手で打つことは想定していない。補完にも出さない）:
`editor` `add` `toggle` `describe` `comment` `move` `remove` `go` `delete-request` `delete-confirm` `slot-request` `slot-confirm`

## 看板

| コマンド           | 何ができるか                                                                         | 使い方                                              | 使える人                         | 補完                   |
| ------------------ | ------------------------------------------------------------------------------------ | --------------------------------------------------- | -------------------------------- | ---------------------- |
| `/slupdate`        | 移動した SL 看板の登録位置を更新する。実行後10秒以内に、移動した看板を右クリックする | `/slupdate`                                         | 全員                             | ○                      |
| `/slupdate region` | WorldEdit で選択した範囲の SL 看板を、まとめて更新する                               | `/slupdate region`                                  | 全員                             | ○                      |
| `/slsignget`       | SL 看板をアイテムとしてもう一度もらう。設置してから `/slupdate` で登録し直す         | `/slsignget <ID> [hanging]`（`hanging` で吊り看板） | 看板の持ち主・OP                 | `<ID>`、次に `hanging` |

## 補足

- 廃止したコマンド: `/lucky` と `/sldata lucky` は `/sllucky` へまとめた
- ほかのプラグインから呼ばれているコマンド: `/sltp`（DynamicProfile・OyasaiAdminTools のクリックリンク）、`/slbuild` `/sluser` `/slmenu` `/slnear` `/vtp`（OyasaiMenu）。名前を変えるときは、これらも直す
