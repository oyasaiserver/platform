# SocialVotes

看板に投票するプラグイン。看板を「SV看板」として登録し、グループにまとめて投票を集計する。

## 権限の方針（意図的な仕様）

次の操作は**権限・所有者の確認をしない**。誰でも実行できるのは仕様であり、不具合ではない。
コードに確認を足す前に、作者（サヒュヤ）に確認すること。

| 操作                                      | 実行できる人                           |
| ----------------------------------------- | -------------------------------------- |
| `/sv add <group>`（グループへ看板を追加） | 誰でも（他人のグループにも追加できる） |
| `/svupdate`（移動した看板の座標を更新）   | 誰でも                                 |
| `/svtp <id>`                              | 誰でも                                 |

所有者または OP に限るもの: `/sv startvote`・`/sv stopvote`・`/sv remove`、GUI のグループ編集。
OP のみ: `/sv allclear`・`/sv delhere`。

`paper-plugin.yml` の `socialvotes.admin`（default: op）は現在どのコマンドも参照していない。

## コマンド

| コマンド                                         | 内容                                                         |
| ------------------------------------------------ | ------------------------------------------------------------ |
| `/sv list [group]`                               | グループ一覧／グループ内の看板一覧                           |
| `/sv setgroup <name>`                            | 投票グループを作る（実行者が所有者）                         |
| `/sv add <group>`                                | 追加モードに入り、SV看板を右クリックしてグループへ入れる     |
| `/sv remove`                                     | 除外モードに入り、SV看板を右クリックしてグループから外す     |
| `/sv startvote <group>` / `/sv stopvote <group>` | 投票の開始・終了                                             |
| `/sv allclear <group>`                           | グループと所属看板をすべて削除（OP）                         |
| `/sv delhere`                                    | 足元の座標のSV看板を削除（OP）                               |
| `/svupdate`                                      | 更新モードに入り、新しい位置の看板を右クリックして座標を移す |
| `/svtp <id>`                                     | ID の看板へテレポート                                        |

追加・除外・更新モードは、看板以外をクリックすると解除される。

## 投票の操作

メインハンドで看板を**右クリック**したときだけ投票になる（左クリック・オフハンドは無視）。

## データ

SV看板とグループは `DataManager` が YAML に保存する。グループは看板を最大45個まで持つ。
