## 問い合わせ前の確認

問い合わせ前に以下を確認してください。

- [ ] [FAQ](users/faq.md) を読んだ
- [ ] `/bigwolf history` でペット状態を確認した
- [ ] サーバーを再ログインして解決しないか試した

---

## テンプレート（プレイヤー → 運営）

問い合わせ窓口（Discord等）に以下の内容をコピーして送ってください。

```
【OyasaiPets 問い合わせ】

■ プレイヤー名（Minecraft ID）:

■ 発生日時（わかる範囲で）:
例: 2026-03-07 20:30 ごろ

■ 問題の種類（該当するものを選ぶ）:
- [ ] ペットが消えた / 見つからない
- [ ] ペットを召喚できない
- [ ] コマンドが動かない
- [ ] トークンが返ってこない
- [ ] 交配が失敗した
- [ ] その他:

■ 問題の詳細（何をしようとして、何が起きたか）:


■ 実行したコマンド（覚えている範囲で）:


■ エラーメッセージ（表示された場合）:


■ `/bigwolf history` の出力（スクリーンショット or テキスト）:

```
