# OyasaiPets 用語集

| 項目 | 内容 |
|---|---|
| 対象読者 | 運営メンバー・プレイヤー |
| 対象バージョン | OyasaiPets v2.4.0 |
| 最終更新日 | 2026-03-07 |

---

## プレイヤー向け用語

| 用語 | 説明 |
|---|---|
| **ペット** | プレイヤーが所有・育成できる生き物エンティティ。スポーンエッグで召喚する |
| **スポーンエッグ** | ペットを召喚するためのアイテム。右クリックで召喚できる |
| **収納** | ペットをスポーンエッグの形に戻してインベントリに入れること |
| **展開** | スポーンエッグを使ってペットをワールドに出すこと |
| **ペット番号** | 各ペットに割り振られた一意の番号。`/bigwolf history` で確認できる |
| **レベル** | ペットの成長度。フードや遊びで上昇する。最大値は設定で変更可能 |
| **バリアント** | ペットの見た目の種類（例: オオカミなら black / ashen / rusty など） |
| **世代（Gen）** | 交配によって生まれたペットの世代数。世代が上がると能力にボーナスがある |
| **性質（気質）** | ペットの特性。「定型（typical）」と「非定型（atypical）」がある。非定型は能力が高い傾向 |
| **スキル** | ペットに乗った状態で左クリックすると発動する特殊能力。スキルブックで解放する |
| **トークン** | ペット購入・復活などに使うサーバーの通貨。TokenManager が管理する |
| **交配（ブリーディング）** | 同種のペット2匹から子供を生み出す機能。親の能力・バリアントが遺伝する |
| **復活（Revive）** | 死亡したペットをトークンを消費して生き返らせること |
| **放棄（Abandon）** | ペットを完全に手放すこと。取り消し不可 |
| **譲渡（Transfer）** | ペットを別のプレイヤーに所有権ごと渡すこと |

## 運営向け用語

| 用語 | 説明 |
|---|---|
| **ActivePetRegistry** | 現在展開中のペットエンティティを管理するインメモリのレジストリ |
| **PetDataManager** | プレイヤーのペットデータ（JSON）を読み書きするデータ管理クラス |
| **PetRegistry** | 公式ペット種別の仕様（速度・スケール・おもちゃ等）を定義するクラス |
| **BigWolfConfig** | `config.yml` から読み込まれた設定値を保持するオブジェクト |
| **ChildAISystem** | ペット（主に子供世代）の自律行動を制御するAIシステム |
| **TokenManager** | トークン経済を管理する外部プラグイン（必須依存） |
| **ショップMOB** | プレイヤーが右クリックするとペット購入GUIが開くNPCエンティティ |
| **Force Store** | OP が他プレイヤーのペットを強制的に収納する操作 |
| **PetStatus** | ペットの状態。`ALIVE`（展開中）、`STORED`（収納中）、`DEAD`（死亡）の3種 |
| **PetCategory** | ペットの移動カテゴリ。`LAND`（陸上）、`WATER`（水棲）、`FLYING`（飛行） |
| **スポーン卵（egg）** | 内部用語。スポーンエッグのこと |
| **Temperament（気質）** | 性質システムの内部表現。`typical` / `atypical` の2値 |
