## 基本コマンド

### `/bigwolf`

使用方法の説明を表示します。

### `/bigwolf <mob名> [variant]`

ペットを購入して直接召喚します。購入画面が表示され、ポイントを消費するとその場にペットがスポーンします。

**例**:

- `/bigwolf wolf` - 狼を購入
- `/bigwolf cat tabby` - トラ猫を購入
- `/bigwolf parrot red` - 赤いオウムを購入

### `/bigwolf storeall`

自分のペットを全て収納（アイテム化）します。

### `/bigwolf version`

プラグインのバージョン情報を表示します。

### `/bigwolf dead`

死亡したペットの一覧を表示します。

### `/bigwolf revive <ペット番号>`

死亡したペットを復活させます（50pt消費）。

### `/bigwolf history`

自分のペット履歴を表示します。

### `/bigwolf locate <ペット番号>`

ペットの最終位置を確認します。

## ペットの購入方法

### ステップ1: 購入コマンド

```
/bigwolf <mob名> [variant]
```

コマンドを実行すると購入確認画面が表示されます。

### ステップ2: 購入確認

**購入画面（GUIメニュー）**が表示されます：

- **左側**: 購入対象のペット情報（種類、価格）
- **中央（エメラルドブロック）**: 購入ボタン
- **右側（バリア）**: キャンセルボタン

### ステップ3: 購入完了

エメラルドブロックをクリックすると：

1. **ポイントが消費されます**（デフォルト: 100pt）
2. **ペットがその場に直接召喚されます**
3. **自動的にペットに乗ります**
4. メッセージが表示されます

### 💰 必要なポイント

- **ペット購入**: 100pt（デフォルト設定）
- **レベルアップ（フード）**: 100pt/回
- **スキルLv.1（咆哮の書）**: 50pt
- **スキルLv.2（突進の書）**: 100pt
- **スキルLv.3（極意の書）**: 150pt
- **ペット復活**: 50pt

## ペットの召喚と操作

### 購入時の召喚

ペットを購入すると、その場に直接召喚され、自動的に乗車状態になります。

### 収納ペットの召喚

収納したペット（スポーンエッグ）を**ブロックに右クリック**で召喚できます。

⚠️ **注意**:
- 同時に召喚できるペットは**3匹まで**です
- **自分が所有しているペットのみ**召喚できます（他人のペットは召喚不可）

### 基本操作

#### 🐾 ペットに乗る

ペットを**右クリック**すると乗車できます。

- **移動**: WASDキーで移動
- **ジャンプ**: スペースキー
- **スキル発動**: 左クリック（スキル習得後）

#### 📊 ステータス確認

ペットを**Shiftキー + 右クリック**でステータス画面を開きます。

#### 🏃 降りる

**Shiftキー**で降車します。

## ペットの育成

### レベルアップ

ペットに**魔法のペットフード**を与えるとレベルアップします。

1. **フードの入手**: OP（管理者）から配布
2. **使用方法**: フードを持ってペットを右クリック
3. **効果**: レベルが1上がり、ステータスが強化される
4. **コスト**: 100pt/回（自動で減算）

### レベルによる変化

レベルが上がると：

- 🐾 **サイズが大きくなる**
- ⚡ **移動速度が速くなる**
- 📈 **ステータスが向上**

**最大レベル**: 50

### 追加アイテム

#### ペットブラシ

ペットを撫でる（愛情表現）

- **効果**: 統計記録に加算
- **サウンド**: ブラッシング音

#### ペットのおやつ

ペットに与える

- **効果**: 体力回復
- **統計**: 記録される

#### おもちゃ

ペットと遊ぶ（フェッチ遊び）

- **使い方**: おもちゃを持って右クリックで投げる
- **効果**: ペットが取りに行く
- **統計**: 遊んだ回数が記録される

## スキルシステム

### スキルの種類

#### ⚡ Lv.1: 咆哮（Roar）

- **効果**: 周囲の敵をノックバック
- **範囲**: 半径10ブロック
- **使用**: ペットに乗って左クリック

#### 🏃 Lv.2: 突進（Dash）

- **効果**: 高速ダッシュで移動
- **速度**: 通常の2倍
- **持続**: 数秒間

#### 🕊️ Lv.3: 極意（Hover）

- **効果**: 空中でホバリング（飛行）
- **操作**: 上昇・下降・移動が可能
- **特殊**: 落下ダメージ無効

### スキルのアンロック方法

1. **スキルブックの入手**
   - OP（管理者）から配布される
   - 3種類: 咆哮の書、突進の書、極意の書

2. **アンロック手順**
   - スキルブックを持つ
   - ペットを右クリック
   - ポイントが消費される

3. **注意事項**
   - **順番に習得する必要があります**（Lv.1 → Lv.2 → Lv.3）
   - すでに習得済みのスキルは再度習得できません

### スキルの切り替え

ステータスGUI（Shift+右クリック）で「スキル設定」をクリックすると、習得済みスキルを切り替えられます。

### クールダウン

スキルには**5秒のクールダウン**があります。連続使用はできません。

## ペットのカスタマイズ

### ステータスGUI（Shift+右クリック）

ペットをShift+右クリックすると管理画面が開きます：

#### 📝 名前変更

- **位置**: 左上
- **操作**: クリックしてチャットで新しい名前を入力
- **制限**: 32文字まで

#### 🔇 サイレントモード

- **位置**: 右上
- **効果**: ペットの鳴き声をON/OFF
- **状態**: クリックで切り替え

#### ⚡ スキル設定

- **位置**: 中央上
- **操作**: クリックでスキルを切り替え
- **表示**: 現在のスキルと解放状況

#### 📊 ステータス

- **位置**: 中央
- **表示情報**:
  - フードレベル（現在/最大）
  - 育成コスト

#### 📈 遊んだ記録

- **位置**: 中央右
- **記録内容**:
  - 走行距離（メートル）
  - ジャンプ回数
  - おもちゃで遊んだ回数
  - なでた回数
  - おやつを与えた回数

#### 🎨 パーティクル設定

- **位置**: 左下
- **種類**: 複数のエフェクトから選択
- **切り替え**: クリックで変更

#### 📦 ペットをしまう

- **位置**: 中央下
- **効果**: ペットをアイテム化
- **保持**: すべてのデータが保存される

#### ❤️ 体力

- **位置**: 右下
- **表示**: 現在の体力/最大体力

## ペットの収納

### 個別収納

ステータスGUI（Shift+右クリック）→「ペットをしまう」

### 一括収納

```
/bigwolf storeall
```

自分のペットを全て収納します。

### 収納されるデータ

- ペットの種類とバリアント
- カスタム名
- フードレベル
- スキルレベルとアンロック状況
- 全統計データ（走行距離、ジャンプ回数等）
- カスタマイズ設定
- **オーナー情報**

### 復元方法

収納したペット（スポーンエッグ）を**ブロックに右クリック**で復元できます。

⚠️ **重要な注意事項**:
- ペットが3匹召喚済みの場合は復元できません
- **自分が所有しているペットのみ**復元できます
- 他人にスポーンエッグを渡しても、その人は使用できません

## ペットの復活

ペットが死亡した場合、ポイントを消費して復活させることができます。

### 死亡したペットの確認

```
/bigwolf dead
```

死亡したペット一覧と、復活に必要なコストが表示されます。

### ペットの復活

```
/bigwolf revive <ペット番号>
```

**例**: `/bigwolf revive 3`

- **コスト**: 50pt（設定で変更可能）
- **演出**: 上空からパーティクルとともにペットが降りてきます
- **データ**: 名前、スキル、統計情報などがすべて引き継がれます

### 復活時の注意

- ペットが3匹召喚済みの場合は復活できません
- ポイントが不足している場合は復活できません

---

## ペットの位置確認

ペットを見失った場合、最終位置を確認できます。

### 位置の記録タイミング

- ペットから**降りたとき**
- **ログアウト時**（全ペットの位置を記録）

### 位置の確認方法

```
/bigwolf locate <ペット番号>
```

**例**: `/bigwolf locate 1`

表示される情報:
- ワールド名
- 座標（X, Y, Z）
- 現在のステータス（生存/死亡/収納中）

### ペット履歴の確認

```
/bigwolf history
```

所有する全ペットの一覧とステータスを確認できます。

## よくある質問

### Q1: ペットが消えてしまいました

**A**: 以下を確認してください：

- `/bigwolf locate <番号>` で最終位置を確認できます
- サーバーの再起動やクラッシュ後はペットが消える可能性があります
- 事前に`/bigwolf storeall`で収納することをお勧めします

### Q2: ポイントが足りません

**A**: TokenManagerプラグインでポイントを入手してください。詳しくはサーバー管理者にお問い合わせください。

### Q3: ペットが3匹以上召喚できません

**A**: 仕様です。同時に召喚できるペットは3匹までです。他のペットを収納してから新しいペットを召喚してください。

### Q4: 他人からもらったペット（スポーンエッグ）が使えません

**A**: 仕様です。ペットは購入した本人のみが使用できます。譲渡はできません。

### Q5: スキルが使えません

**A**: 以下を確認してください：

- スキルブックでアンロック済みですか？
- ペットに乗っていますか？
- クールダウン中ではありませんか？（5秒）

### Q6: 他人のペットを操作できますか？

**A**: いいえ、できません。ペットは所有者のみが操作できます。

### Q7: ペットは死にますか？

**A**: はい、ペットは死亡する可能性があります。死亡した場合は `/bigwolf revive <番号>` で50ptを消費して復活できます。

### Q8: バリアント（色や模様）を変更できますか？

**A**: 購入時に指定したバリアントは変更できません。変更したい場合は新しいペットを購入してください。

### Q9: 死亡したペットのデータは消えますか？

**A**: いいえ、消えません。死亡したペットの名前、スキル、統計情報などはすべて保存され、復活時に引き継がれます。
