### ペット操作の経路マップ（現状）

```
ペット召喚
  ├─ エッグ右クリック
  └─ ショップ購入 → 即時召喚

ペット情報確認
  ├─ SHIFT+右クリック → ペット情報GUI（稼働中ペットのみ）
  ├─ /bigwolf history → クリック → /bigwolf detail
  └─ /bigwolf detail <番号>（テキスト）

ペット収納
  ├─ ペット情報GUI → スロット6
  └─ /bigwolf storeall（全収納）

ペット復活
  ├─ /bigwolf dead → テキスト表示 → 手動で /bigwolf revive <番号>
  └─ /bigwolf detail → クリックボタン → /bigwolf revive <番号>

餌やり
  ├─ ペットに右クリック（フードアイテム持参）
  └─ ペット情報GUI → スロット2

スキル変更
  ├─ ペットに右クリック（スキル本持参・解放）
  └─ ペット情報GUI → スロット3

放棄・譲渡
  └─ コマンドのみ（2回テキスト確認）

メインメニュー
  ├─ 全収納 ✅ 実際に実行
  ├─ 死亡一覧 ✅ 実際に実行
  ├─ 履歴 ✅ 実際に実行
  ├─ 交配 ✅ 実際に実行
  ├─ 復活 ❌ コマンド案内テキストを表示するだけ
  ├─ エッグ再取得 ❌ コマンド案内テキストを表示するだけ
  └─ 位置確認 ❌ コマンド案内テキストを表示するだけ
```

## 問題点

### 1. メインメニューのボタンが「案内テキスト」になっている
**復活・エッグ再取得・位置確認** の3つは、クリックしても「コマンドを使ってください」とテキストが出るだけ。GUIボタンを提供している意味がない。

### 2. 死亡ペット一覧（`/dead`）が非力
テキスト表示のみで、そこから復活するには番号を控えて手打ちコマンドが必要。

### 3. `history` / `dead` / `detail` の重複
- `/bigwolf dead` は死亡ペットの `/bigwolf history` サブセット
- `/bigwolf detail` は `/bigwolf history` からクリックで同等の情報が見られる
- 3コマンドが似たような情報を異なる形式で提供しており、「どれを使えばいいか」が分かりにくい

### 4. 操作の「場所」がバラバラ
- 稼働中ペット操作: SHIFT+右クリック（GUI）
- 収納/死亡ペット操作: テキストコマンド
- 統一された「マイペット一覧」が存在しない

### 5. 放棄・譲渡がテキストの2回確認
GUIで確認を取れば1ステップで済む上、誤操作も防げる。

### 6. ショップがメインメニューにない
`/bigwolf buy` のみアクセス可能。他の機能はメニューにあるのに不統一。

### 7. `/bigwolf list` がテキストのみ
ショップGUIを開けば同等の情報が視覚的に確認できるため冗長。

---

## 改善計画

### 方針
- **GUIをメインの操作場所にする**（コマンドはショートカット）
- **ペット一覧GUIを新設**して `history / dead / detail` を統合
- **メインメニューを完全に機能させる**（テキスト案内ボタンを廃止）
- **2回確認をGUIダイアログに統一**

### 変更②: マイペット一覧GUI（新設）

**概要**: 所有する全ペットを一覧表示するGUI。`/bigwolf history` の完全な後継。

**開き方**: メインメニュー → 「ペット一覧」 / `/bigwolf pets`（コマンド）

**サイズ**: 54スロット（6行）

**レイアウト**:
```
[ ペット一覧 - 全て/生存/収納/死亡 フィルタータブ ]
─────────────────────────────────────────────────────
[ ペット1 ][ ペット2 ][ ペット3 ][ ペット4 ][ ペット5 ]
[ ペット6 ][ ペット7 ][ ペット8 ][ ペット9 ][ペット10 ]
[ ...                                               ]
─────────────────────────────────────────────────────
[ « 前 ][ フィルター: 全て ][ ページ X/Y ][ 次 » ][ 閉じる ]
```

**フィルタータブ（1行目）**:
- スロット0: 「全て」
- スロット1: 「生存」（GREEN）
- スロット2: 「収納中」（YELLOW）
- スロット3: 「死亡」（RED）

**ペットスロット（2〜4行目, 最大36匹/ページ）**:

各スロットのアイテム:
- **素材**: 対応スポーンエッグ
- **表示名**: `#番号 種族名（バリアント）`（ステータスカラー）
- **Lore**:
  - 状態: 生存 / 収納中 / 死亡
  - レベル: X / Y
  - 名前（設定されている場合）
  - ──クリックで詳細──

ステータスによるアイコン色分け（エンチャントグロー等）:
- 生存: エンチャントあり（輝く）
- 収納中: 通常
- 死亡: グレーDye でガラスパネルに変更 or 暗色

**ナビゲーション（最終行）**:
- スロット45: 前ページ
- スロット49: フィルター切り替え（クリックで循環）
- スロット49 付近: ページ X/Y 表示
- スロット53: 閉じる

**ペットクリック → ペット詳細GUI（変更③）に遷移**

### 変更③: ペット詳細GUI（新設）

**概要**: `/bigwolf detail` のテキスト表示をGUIに格上げ。
現在の「ペット情報GUI（9スロット・稼働中のみ）」とは別物（全ステータス対応）。

**開き方**: ペット一覧GUI → ペットをクリック

**サイズ**: 54スロット（6行）

**レイアウト**:
```
[ 戻る ][ ペット名 #番号  種族 バリアント  状態 ]
─────────────────────────────────────────────────────
[ 基本情報  ] [ 記録      ] [  交配情報  ] [ 譲渡履歴 ]
[ Lv/スキル ]                [  死亡情報  ]
[ 最終位置  ]
─────────────────────────────────────────────────────
[ 復活する  ] [エッグ再取得] [  位置確認  ] [ 放棄する ]
（状態に応じてボタン表示/非表示）
```

**情報スロット（クリック不可、情報表示のみ）**:

| スロット | 表示情報 |
|---------|---------|
| 基本情報 | 種族・バリアント・名前・購入日 |
| 状態 | 生存/収納中/死亡（カラー） |
| レベル | フードLv / スキルLv / 解放Lv |
| 記録 | 距離・ジャンプ・おもちゃ・なでた・おやつ |
| 交配情報 | 世代・親ペット・交配回数（交配済みのみ） |
| 死亡情報 | 死亡日時・場所（死亡ペットのみ） |
| 最終位置 | ワールド・座標 |
| 譲渡履歴 | 履歴件数・最新記録 |

**アクションボタン（最終行）**:

| 状態 | 表示されるボタン |
|-----|---------------|
| ALIVE | 「収納する」「放棄する（→確認GUI）」「名前変更（suggestCommand）」|
| STORED | 「エッグ再取得（コスト表示）」「放棄する（→確認GUI）」「名前変更」 |
| DEAD | 「復活する（コスト表示）」 |
| 共通 | 「← 一覧に戻る」 |

### 変更④: 放棄・譲渡の確認をGUI化

**放棄確認GUI（新設）**:
- サイズ: 27スロット
- タイトル: 「本当に放棄しますか？」
- 中央: ペット情報表示
- 左: 「放棄する」（RED WOOL）→ クリックで即時実行
- 右: 「キャンセル」（GRAY）

これにより `/bigwolf abandon` の2回テキスト確認を廃止。

**譲渡確認GUI（新設）**:
- ペット詳細GUIに「譲渡する」ボタン追加
- クリック → テキストチャット入力へ誘導（suggestCommand）
- ※ 相手プレイヤー名入力が必要なため、GUIのみでは完結できないが、確認ダイアログはGUIで行う
